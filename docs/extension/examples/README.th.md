[← คู่มือส่วนขยาย](../th/README.md)

ปลั๊กอินสามตัวที่ **ใช้งานได้จริง** — แต่ละตัวถูกติดตั้งและรันกับ Killian 2 รุ่น alpha.169 (เรียกทุกคำสั่ง · เปิดแผง · บันทึกฉาก · กดคีย์ลัด · ปิดแล้วเปิดใหม่โดยไม่ต้องเริ่มโปรแกรมใหม่) ทั้งหน้าจอภาษาอังกฤษและภาษาไทย ก่อนถูกใส่ในคู่มือ

ทั้งสามตัวมี **ข้อความสองภาษา** (อังกฤษ/ไทย) เลือกตามภาษาของหน้าจอ — เป็นตัวอย่างของตารางข้อความใน [5.6](../th/05-ui-guidelines.md#56-หลายภาษา) · คอมเมนต์ในโค้ดเป็นภาษาอังกฤษ เพื่อให้นักพัฒนาทุกชาติอ่านได้

## ลองใช้

1. เปิด Killian 2 → เปิดผลงานทดสอบ (อย่าใช้ต้นฉบับจริงตอนทดลองปลั๊กอิน)
2. เปิดแผงปลั๊กอิน (`Ctrl+Alt+E`) → **⋯ → โฟลเดอร์ของผู้ใช้**
3. ก๊อป **ทั้งโฟลเดอร์** ของตัวอย่างที่ต้องการ (เช่น `word-count-on-save/`) ไปวางในโฟลเดอร์นั้น
4. กลับมาที่แผง → **โหลดใหม่** → การ์ดของปลั๊กอินขึ้นพร้อมรายการคำสั่ง
5. กดคำสั่งบนการ์ด หรือปุ่ม **คำสั่งจากปลั๊กอิน** บนแถบเครื่องมือ

ถอนออก: **ถอนออก** บนการ์ด (ทั้งสามตัวประกาศ `hotReload` — ไม่ต้องเริ่มโปรแกรมใหม่)

## ใช้เป็นจุดเริ่ม

ก๊อปโฟลเดอร์ แล้ว **เปลี่ยนชื่อโฟลเดอร์** (= ตัวตนของปลั๊กอิน — ดู [บทที่ 2](../th/02-anatomy.md)) แก้ `plugin.json` (`name` · `author` · `description` · `homepage`) แล้วเริ่มแก้ `main.js`

สิ่งที่ต้องเปลี่ยนเมื่อดัดแปลง:

- **คีย์ลัด** — ตัวอย่างใช้ `Ctrl+Shift+F8` / `F9`; ปลั๊กอินสองตัวที่จองคีย์เดียวกันจะแย่งกัน
- **ชื่อไฟล์ผลลัพธ์** (`Reports/manuscript-report.md`) และคีย์ของค่าตั้ง — ให้เป็นของปลั๊กอินคุณ
- **คำนำหน้าคลาส CSS** (`wcs-` · `ft-`) — ต้องไม่ชนกับปลั๊กอินอื่น
- ถ้าเพิ่มของที่สร้างเองนอก `k2` แล้วเก็บกวาดไม่ครบ ให้ **ถอด `"hotReload": true` ออก** — ประกาศเกินจริงทำให้ผู้ใช้ได้ของค้างโดยไม่มีคำเตือน

## ข้อจำกัดที่ตั้งใจให้เห็นในตัวอย่าง

- `word-count-on-save` ไม่เขียนผลลงแถบสถานะตอนบันทึก — ข้อความ "บันทึกแล้ว" ของโปรแกรมจะทับ ([4.1](../th/04-hooks-lifecycle.md#tabsave)) จึงแสดงในแผงแทน
- `manuscript-report` ถามว่าไฟล์มีไหมด้วย `listFiles` ก่อน `readFile` — ไฟล์ที่ไม่มีทำให้ `readFile` โยน error และ Log ขึ้นบรรทัดผิดพลาด ([3.6](../th/03-sdk-reference.md#36-ไฟล์ของผลงาน))
- `manuscript-report` นับจากไฟล์บนดิสก์ — ฉากที่แก้แล้วยังไม่บันทึกจะได้ตัวเลขของฉบับที่บันทึกล่าสุด ([6.2](../th/06-data-and-files.md#ไฟล์บนดิสก์-กับ-สิ่งที่ผู้ใช้เห็นในแท็บ))
- จำนวนคำใช้ `Intl.Segmenter` — ใกล้เคียงแต่ไม่จำเป็นต้องเท่ากับตัวนับคำของโปรแกรม
- `description` ใน `plugin.json` มีได้ภาษาเดียว (โปรแกรมยังไม่มีช่องคำอธิบายแยกภาษา) — ตัวอย่างจึงเขียนเป็นอังกฤษและบอกท้ายว่ารองรับภาษาอะไร
- รายงานของ `manuscript-report` แสดงค่าสถานะฉากตามที่เก็บในไฟล์ (สถานะตั้งต้นเก็บเป็นชื่อไทย) — ข้อมูลของผู้ใช้ไม่ถูกแปล
