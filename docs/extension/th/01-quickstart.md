# 1. เริ่มใน 10 นาที

**ภาษา:** ไทย · [English](../en/01-quickstart.md)

[← ภาพรวม](README.md) · ถัดไป: [2. กายวิภาคของปลั๊กอิน →](02-anatomy.md)

---

บทนี้พาเขียนปลั๊กอินตัวแรกตั้งแต่ไฟล์เปล่าจนทำงานในโปรแกรม: คำสั่งหนึ่งตัว · แผงหนึ่งแผง · ตัวรับเหตุการณ์หนึ่งตัว

**สิ่งที่ต้องมี**: Killian 2 รุ่น alpha.169 ขึ้นไป · ตัวแก้ข้อความ (VS Code · Notepad++ · อะไรก็ได้) · ความรู้ JavaScript พื้นฐาน
**ไม่ต้องมี**: Node.js · npm · เครื่องมือ build (จนกว่าปลั๊กอินจะใหญ่จนอยากแยกหลายไฟล์ — ดู [บทที่ 8](08-packaging-distribution.md))

## ขั้นที่ 0 — ทางลัด: ให้โปรแกรมสร้างให้

1. เปิดโปรเจกต์ใดก็ได้ (ปลั๊กอินถูกโหลดเมื่อเปิดผลงาน)
2. เปิดแผง **ปลั๊กอิน**: **มุมมอง → แผง → ปลั๊กอิน** (`Ctrl+Alt+E`)
3. ปุ่ม **⋯ → สร้างตัวอย่าง** → ตั้งชื่อ
4. ได้ปลั๊กอินที่ทำงานทันทีในโฟลเดอร์ของผู้ใช้ — การ์ดของมันมีปุ่มคำสั่ง **นับคำในฉากนี้** ให้กดลอง
5. **⋯ → โฟลเดอร์ของผู้ใช้** → เปิด `main.js` ไปแก้ → กลับมากด **โหลดใหม่**

ถ้าอยากเข้าใจทุกบรรทัด ทำขั้นที่ 1–6 ด้วยมือ

## ขั้นที่ 1 — สร้างโฟลเดอร์

เปิดโฟลเดอร์ปลั๊กอินของผู้ใช้ (แผงปลั๊กอิน → **⋯ → โฟลเดอร์ของผู้ใช้**):

| ระบบ | ที่อยู่ |
|---|---|
| Windows | `%APPDATA%\Killian 2\Plugins\` |
| macOS | `~/Library/Application Support/Killian 2/Plugins/` |
| Linux | `~/.config/Killian 2/Plugins/` |

สร้างโฟลเดอร์ใหม่ชื่อ `hello-k2` — **ชื่อโฟลเดอร์คือตัวตนของปลั๊กอิน** (ใช้อักษรอังกฤษตัวเล็ก ตัวเลข และขีด `-` จะปลอดภัยที่สุด)

## ขั้นที่ 2 — `plugin.json`

```json
{
  "name": "Hello K2",
  "entry": "main.js",
  "version": "0.1.0",
  "author": "ชื่อคุณ",
  "description": "ปลั๊กอินแรกของฉัน",
  "minAppVersion": "2.0.0-alpha.169",
  "hotReload": true
}
```

บันทึกเป็น UTF-8 · ไฟล์ต้องเป็น JSON ที่ถูกต้อง (ไม่มีจุลภาคเกินท้ายรายการ ไม่มีคอมเมนต์)

## ขั้นที่ 3 — `main.js` : คำสั่งแรก

```js
// main.js — ทั้งไฟล์คือสคริปต์ธรรมดา โปรแกรมส่งตัวแปร k2 มาให้หนึ่งตัว
k2.registerCommand('ทักทาย', () => {
  k2.setStatus('สวัสดีจาก ' + k2.pluginName + ' บน Killian ' + k2.appVersion);
});
```

กลับไปที่แผงปลั๊กอิน กด **โหลดใหม่** — การ์ด `hello-k2` ขึ้นสถานะ **ทำงานอยู่** พร้อมปุ่ม **ทักทาย** กดแล้วดูแถบสถานะมุมซ้ายล่าง

> **ไม่ขึ้น?** ดู [ขั้นที่ 7](#ขั้นที่-7--เมื่อมันไม่ทำงาน)

## ขั้นที่ 4 — อ่านและเขียนลงเอกสาร

```js
// นับตัวอักษรของฉากที่เปิดอยู่
k2.registerCommand('นับตัวอักษร', () => {
  const md = k2.getMarkdown();              // '' ถ้าไม่มีฉากเปิด
  k2.setStatus('ฉากนี้ยาว ' + md.length + ' ตัวอักษร');
});

// แทรกวันที่ตรงเคอร์เซอร์
k2.registerCommand('แทรกวันที่', () => {
  const ok = k2.insertText(new Date().toLocaleDateString());
  if (!ok) k2.setStatus('เปิดฉากก่อน');
});
```

บันทึกไฟล์ → **โหลดใหม่** → การ์ดมีสามคำสั่ง (โปรแกรมเห็นว่าไฟล์เปลี่ยน จึงถอดของเก่าออกแล้วรันใหม่)

## ขั้นที่ 5 — แผงของตัวเอง

```js
let host = null;
let saves = 0;

function draw() {
  if (!host) return;
  const box = document.createElement('div');
  // ใช้ตัวแปรสีของธีมเสมอ — ไม่ใช้สีตายตัว
  box.style.cssText = 'padding:12px; color:var(--fg); font-size:calc(13px * var(--ui-scale, 1))';
  box.textContent = 'บันทึกไปแล้ว ' + saves + ' ครั้งในรอบนี้';
  host.replaceChildren(box);                 // render ถูกเรียกซ้ำได้ → แทนทั้งก้อน
}

k2.registerPanel('counter', {
  title: 'ตัวนับการบันทึก',
  defaultSide: 'right',
  render: (h) => { host = h; draw(); },
});

k2.registerCommand('เปิดแผงตัวนับ', () => k2.showPanel('counter'));
```

**โหลดใหม่** → กดคำสั่ง **เปิดแผงตัวนับ** → แผงขึ้นมา ลากไปผนึก/ลอย/รวมแท็บได้เหมือนแผงในตัว

## ขั้นที่ 6 — ฟังเหตุการณ์ของโปรแกรม และเก็บกวาด

```js
k2.on('tab:save', (e) => {                   // e = { file, title, chars }
  saves++;
  draw();
  k2.log('saved ' + e.title + ' (' + e.chars + ' chars)');
});

// ถูกเรียกเมื่อปลั๊กอินถูกปิด ถอน หรือกำลังถูกแทนด้วยไฟล์รุ่นใหม่
k2.onUnload(() => { host = null; });
```

**โหลดใหม่** → เปิดฉาก พิมพ์อะไรสักหน่อย กด `Ctrl+S` → ตัวเลขในแผงเพิ่ม · บรรทัด `[plugin hello-k2] saved …` ขึ้นในแผง **บันทึก (Log)** (`Ctrl+Alt+9`)

ปลั๊กอินนี้ใช้แต่ของที่ลงทะเบียนผ่าน `k2` (คำสั่ง · แผง · ตัวรับเหตุการณ์) ซึ่งโปรแกรมถอนให้เองได้ครบ จึงประกาศ `"hotReload": true` ได้ — ผู้ใช้ปิด/ถอนแล้วไม่ต้องเริ่มโปรแกรมใหม่ ([บทที่ 4](04-hooks-lifecycle.md))

### ไฟล์ทั้งหมดรวมกัน

```js
// hello-k2/main.js
let host = null;
let saves = 0;

function draw() {
  if (!host) return;
  const box = document.createElement('div');
  box.style.cssText = 'padding:12px; color:var(--fg); font-size:calc(13px * var(--ui-scale, 1))';
  box.textContent = 'บันทึกไปแล้ว ' + saves + ' ครั้งในรอบนี้';
  host.replaceChildren(box);
}

k2.registerPanel('counter', { title: 'ตัวนับการบันทึก', defaultSide: 'right', render: (h) => { host = h; draw(); } });

k2.registerCommand('ทักทาย', () => k2.setStatus('สวัสดีจาก ' + k2.pluginName));
k2.registerCommand('นับตัวอักษร', () => k2.setStatus('ฉากนี้ยาว ' + k2.getMarkdown().length + ' ตัวอักษร'));
k2.registerCommand('แทรกวันที่', () => { if (!k2.insertText(new Date().toLocaleDateString())) k2.setStatus('เปิดฉากก่อน'); });
k2.registerCommand('เปิดแผงตัวนับ', () => k2.showPanel('counter'));

k2.on('tab:save', (e) => { saves++; draw(); k2.log('saved ' + e.title); });
k2.onUnload(() => { host = null; });
```

## ขั้นที่ 7 — เมื่อมันไม่ทำงาน

| อาการ | สาเหตุ | แก้ |
|---|---|---|
| ไม่มีการ์ดในแผงเลย | โฟลเดอร์ไม่ได้อยู่ใน `Plugins/` โดยตรง (ซ้อนชั้น) · ยังไม่ได้เปิดโปรเจกต์ · ยังไม่ได้กด **โหลดใหม่** | ตรวจที่อยู่: `Plugins/hello-k2/plugin.json` |
| การ์ดขึ้น **มีปัญหา** + ข้อความผิดพลาด | `plugin.json` ไม่ใช่ JSON ที่ถูก · โค้ดโยน error ตอนรัน · ไม่มีไฟล์ entry | อ่านข้อความบนการ์ด แก้ไฟล์ แล้วกด **เปิดใช้** (ปลั๊กอินที่พังถูกปิดอัตโนมัติ — **โหลดใหม่อย่างเดียวไม่พอ ต้องกดเปิดใช้**) |
| การ์ดขึ้น **รุ่นไม่พอ** | `minAppVersion` สูงกว่ารุ่นของโปรแกรม | ลดค่า หรืออัปเดตโปรแกรม |
| การ์ดขึ้น **รออนุญาต** | ปลั๊กอินอยู่ในโฟลเดอร์ของ *ผลงาน* | กดอนุญาต — หรือย้ายมาพัฒนาในโฟลเดอร์ของผู้ใช้ (ไม่ต้องอนุญาตซ้ำทุกครั้งที่แก้ไฟล์) |
| แก้โค้ดแล้วไม่เปลี่ยน | ยังไม่ได้บันทึกไฟล์ · ยังไม่ได้กด **โหลดใหม่** | — |
| คำสั่งกดแล้วเงียบ | โค้ดในคำสั่งโยน error | แผง **บันทึก (Log)** · หรือ DevTools ([บทที่ 11](11-debugging-testing.md)) |
| `import` / `require` ใช้ไม่ได้ | ไฟล์ถูกรันเป็นสคริปต์ธรรมดา | bundle เป็นไฟล์เดียว ([บทที่ 8](08-packaging-distribution.md#83-หลายไฟล์--typescript-bundle-เป็นไฟล์เดียว)) |
| `alert()` ไม่ขึ้น | `window.alert/prompt/confirm` ใช้ไม่ได้ในโปรแกรม | `k2.alertBox` · `k2.ask` · `k2.confirmBox` |
