## ภาพรวมใน 1 นาที

```
my-plugin/
├─ plugin.json      ← บอกชื่อ รุ่น และไฟล์ที่จะรัน
└─ main.js          ← สคริปต์ธรรมดา ได้รับตัวแปร k2 หนึ่งตัว
```

```js
// main.js
k2.registerCommand('สวัสดี', () => k2.setStatus('สวัสดีจากปลั๊กอิน'));
k2.on('tab:save', (e) => k2.log('บันทึก ' + e.title));
k2.onUnload(() => { /* เก็บกวาดของที่สร้างเอง */ });
```

- วางโฟลเดอร์ใน `<ข้อมูลผู้ใช้>/Plugins/` แล้วกด **โหลดใหม่** ในแผงปลั๊กอิน
- โค้ดรันใน **หน้าต่างของโปรแกรม** (Chromium) — ใช้ DOM API ได้ · ไม่มี Node.js · ไม่มี `import`/`require`
- แจกจ่ายด้วยการ push ขึ้น GitHub — ผู้ใช้วางลิงก์รีโปในแผงปลั๊กอินแล้วติดตั้งได้เลย

## ข้อเท็จจริงที่ต้องรู้ก่อนลงแรง

| เรื่อง | สถานะในรุ่น alpha.169 |
|---|---|
| ความเสถียรของ API | **alpha** — ของที่เขียนในเอกสารนี้จะพยายามคงไว้ แต่ยังไม่มีสัญญาความเข้ากันได้ย้อนหลัง ใช้ `minAppVersion` เสมอ |
| ระบบโมดูล | ไม่มี — ไฟล์เดียว รันด้วย `new Function('k2', โค้ด)` (หลายไฟล์ต้อง bundle ก่อน) |
| แซนด์บ็อกซ์ | **ไม่มี** — ปลั๊กอินรันด้วยสิทธิ์เต็มของหน้าต่างโปรแกรม ([บทที่ 7](07-security.md)) |
| ร้านปลั๊กอิน / การรีวิว | **ยังไม่มี** — แจกจ่ายผ่าน GitHub หรือไฟล์ zip ([บทที่ 9](09-store-submission.md)) |
| การอัปเดตอัตโนมัติของปลั๊กอิน | ยังไม่มี — ผู้ใช้ติดตั้งจากลิงก์เดิมทับ |
| แพ็กเกจ npm ของ SDK | ไม่มี — SDK คือตัวแปร `k2` ที่โปรแกรมส่งให้ตอนรัน (ชนิดข้อมูลอยู่ใน [`k2.d.ts`](../k2.d.ts)) |
| รายการบนแถบเมนูของระบบ | ปลั๊กอินเพิ่มไม่ได้ — คำสั่งอยู่ที่การ์ดในแผงปลั๊กอิน · ปุ่ม "คำสั่งจากปลั๊กอิน" บนแถบเครื่องมือ · คีย์ลัด |
| ค่าตั้งของปลั๊กอิน | เก็บ **ต่อผลงาน** (`project.khn.json`) — ระดับผู้ใช้ต้องใช้ `localStorage` เอง |

## แหล่งความจริงในซอร์ส

ถ้าเอกสารกับพฤติกรรมจริงไม่ตรงกัน ให้ถือซอร์สเป็นหลัก แล้วรายงานบั๊กของเอกสาร:

| เรื่อง | ไฟล์ |
|---|---|
| ตัวแปร `k2` | `pluginApi()` ใน `src/app.js` |
| ตัวโหลด · การอนุญาต · วงจรชีวิต | `loadPluginsNow()` · `unloadPlugin()` ใน `src/app.js` |
| ตรรกะ (manifest · ลายนิ้วมือ · แผนโหลดใหม่ · ปลั๊กอินตัวอย่าง) | `src/plugins/plugin-core.js` (unit test: `test/plugin-core.test.cjs`) |
| ติดตั้งจากลิงก์ | `src/plugins/plugin-install.js` + ช่อง `plugins:*` ใน `main.js` |
| แผงปลั๊กอิน | `src/plugins/plugin-panel.js` |
| เอกสารอ้างอิงฉบับย่อ (หน้าเดียว) | [`docs/plugin-dev.md`](../../plugin-dev.md) |

> **สำหรับผู้ดูแลโปรแกรม**: เมื่อเปลี่ยน API ของ `k2` ต้องแก้ `pluginApi()` · `PLUGIN_API_DOC` · `docs/plugin-dev.md` · [`03-sdk-reference.md`](03-sdk-reference.md) และ [`k2.d.ts`](../k2.d.ts) ในคอมมิตเดียวกัน
