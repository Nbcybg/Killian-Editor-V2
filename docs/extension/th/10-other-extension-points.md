## 10.1 ไฟล์ภาษา

### เพิ่มภาษาใหม่โดยไม่แตะโปรแกรม

1. ส่งออกต้นแบบ: **ส่งออก → ส่งออกภาษาเป็น CSV (key · ไทย · อังกฤษ)…**
2. แปลเป็นไฟล์สองคอลัมน์ชื่อ `k2_<รหัสภาษา>.csv` (เช่น `k2_ko.csv`)
3. วางในโฟลเดอร์ `languages` ที่โปรแกรมมองหา (ดูรายการจริงที่ **ตั้งค่า → ภาษา** · ปุ่ม **เปิดโฟลเดอร์ภาษา**)
4. เปิดโปรแกรมใหม่ → ภาษานั้นอยู่ในรายการ

### รูปแบบไฟล์

```csv
meta.code,ko
meta.name,Korean
meta.nativeName,한국어
meta.version,3
meta.author,ชื่อผู้แปล
ui.common.cancel,취소
ui.common.save,저장
"ui.app.confirmQuit","저장하지 않은 작업이 있습니다. ""종료""하시겠습니까?"
# บรรทัดที่ช่องแรกขึ้นต้นด้วย # = คอมเมนต์ของผู้แปล
```

| กติกา | รายละเอียด |
|---|---|
| คอลัมน์ | `คีย์,ข้อความ` — มีแถวหัว `key,text` ได้ (ไม่บังคับ) |
| การอ้างอิง | ช่องที่มี `,` `"` หรือขึ้นบรรทัดใหม่ ครอบด้วย `"…"` · `"` ข้างในเขียนเป็น `""` |
| การเข้ารหัส | UTF-8 (มี BOM ได้ — แนะนำ ถ้าจะเปิดด้วย Excel บน Windows) |
| แถว `meta.*` | `meta.code` (รหัสภาษา) · `meta.name` (ชื่ออังกฤษ) · `meta.nativeName` (ชื่อในภาษานั้น — แสดงในช่องเลือกภาษา) · `meta.version` · `meta.author` |
| ช่องว่าง | = ยังไม่แปล → ใช้ข้อความจากไฟล์ชั้นถัดไป |
| `{0}` `{1}` … | ตัวแทนค่า — ต้องคงไว้ (ย้ายตำแหน่งในประโยคได้) |
| `{0\|เอกพจน์\|พหูพจน์}` | รูปพหูพจน์ตามค่าของ `{0}`: `{0} {0\|page\|pages}` |
| `{sc:คำสั่ง}` | ถูกแทนด้วยคีย์ลัดปัจจุบันของคำสั่งนั้น เช่น `{sc:save}` — **ห้ามพิมพ์ชื่อปุ่มลงไปตรง ๆ** |
| ห้าม | แท็ก HTML · อีโมจิ/ไอคอนนำหน้าข้อความ · การเปลี่ยนชื่อคีย์ |

**ข้อความที่เป็นคำสั่งถึง AI** (คีย์ในตระกูล `ui.ai*`): แปลเนื้อได้ แต่ **ต้องคงโครง** — ชื่อช่องของ JSON ตัวอย่าง · บล็อกคำสั่ง · เครื่องหมาย `###` `@` ของบท · `{{ }}` — ไม่อย่างนั้นโปรแกรมอ่านคำตอบของ AI ไม่ออก

### ลำดับการซ้อนทับ

โปรแกรมต่อไฟล์ภาษาเดียวกันจากหลายที่ **คีย์แรกที่เจอชนะ**:

```
1. <ผลงาน>/languages/k2_<ภาษา>.csv        ← เฉพาะผลงานนี้
2. languages/ ข้างไฟล์โปรแกรม
3. <ข้อมูลผู้ใช้>/languages/k2_<ภาษา>.csv   ← ของผู้ใช้ ทุกผลงาน
4. ไฟล์ที่มากับโปรแกรม
```

ใช้ประโยชน์ได้สองแบบ:

- **แก้คำแปลบางคำ**: สร้างไฟล์ที่มีแค่คีย์ที่อยากเปลี่ยน วางในชั้นที่สูงกว่า — คีย์ที่เหลือใช้ของเดิม
- **ศัพท์เฉพาะของผลงาน**: วางใน `<ผลงาน>/languages/` เช่น เปลี่ยน "ฉาก" เป็น "ตอน" · "บท" เป็น "เควสต์" สำหรับโปรเจกต์เกม — ไปกับผลงาน และมีผลเฉพาะตอนเปิดผลงานนั้น (ซ้อนทับภาษาที่ผู้ใช้เลือกอยู่ ไม่ได้เปลี่ยนภาษา)

### ทดสอบและส่งเข้าโครงการ

- **ตั้งค่า → ภาษา → โหลดไฟล์ภาษาใหม่** อ่านไฟล์ของภาษาที่ใช้อยู่ใหม่โดยไม่ปิดโปรแกรม
- **เครื่องมือ → นำเข้าภาษาจาก CSV…** รวมตารางเข้ากับไฟล์ภาษาของผลงาน (รวมทับ ไม่ลบคีย์ที่ไม่มีในตาราง)
- ตรวจบนหน้าจอจริง: ช่องเลือก · ปุ่ม · ตาราง ที่ข้อความยาวอาจถูกตัด — ลองหน้าต่างกว้าง 1366 และ 1024
- ส่งให้ทุกคนได้ใช้: pull request เพิ่ม/แก้ไฟล์ใน `languages/` ของรีโป (อ่าน `AGENTS.md` หัวข้อไฟล์ภาษาก่อน — ทุกคีย์ต้องมีในทุกไฟล์ภาษา)

## 10.2 พจนานุกรมของตัวตรวจคำผิด

ตัวตรวจคำผิดออฟไลน์ (ไทย + อังกฤษ) รับคำเสริมสองทาง:

| ไฟล์ | รูปแบบ | มาจาก |
|---|---|---|
| `<ผลงาน>/dictionary.json` | `{ "words": ["คำ1", "คำ2"] }` | ผู้ใช้กดคลิกขวา → **เพิ่มลงพจนานุกรม** |
| `<ผลงาน>/Plugins/dictionaries/*.txt` | บรรทัดละคำ · `#` นำหน้า = คอมเมนต์ | คลังคำที่วางเอง |

```text
# ศัพท์ของโลกในเรื่อง "ปีศาจแห่งบางกอก"
ตะเกียงวิญญาณ
หมอผีดำ
Nazarena
```

- บันทึกเป็น UTF-8 · ชื่อไฟล์อะไรก็ได้ที่ลงท้าย `.txt` · มีได้หลายไฟล์ (แยกตามหมวด: ชื่อคน · ศัพท์เทคนิค · ภาษาถิ่น)
- โหลดตอนเปิดผลงาน — แก้ไฟล์แล้วเปิดผลงานใหม่
- คำสั้นไม่เกิน 2 ตัวอักษรและยาวเกิน 65 ตัวอักษรไม่ถูกตรวจอยู่แล้ว ไม่ต้องใส่
- `Plugins/dictionaries/` อยู่ในโฟลเดอร์ปลั๊กอินแต่ **ไม่ใช่ปลั๊กอิน** — ไม่มีโค้ด ไม่ต้องขออนุญาต
- แจกคลังคำ: ส่งไฟล์ `.txt` ให้ผู้ใช้วางเอง หรือให้ไปกับผลงาน

## 10.3 ทักษะและ Agent ของ AI

### ทักษะ (Skill) — คำสั่งประจำตัวของผู้ช่วย AI

ไฟล์มาร์กดาวน์ใน `<ผลงาน>/Skills/` ที่ผู้ใช้เปิด/ปิดได้รายเซสชันในแผงแชท:

```markdown
---
name: โทนการเขียน
description: บังคับโทนภาษาของเรื่องนี้
---
เขียนด้วยประโยคสั้น กระชับ ไม่ใช้คำฟุ่มเฟือย
ใช้คำสรรพนามตามที่ตัวละครใช้จริงในเรื่อง ห้ามเปลี่ยนเอง
ห้ามสรุปตอนจบให้ ถ้าผู้เขียนไม่ได้ขอ
```

| กติกา | |
|---|---|
| ที่อยู่ | `<ผลงาน>/Skills/<ชื่อ>.md` |
| หัวไฟล์ | ไม่บังคับ — `name` (ชื่อที่แสดง · ไม่มี = ชื่อไฟล์) · `description` |
| เนื้อ | คำสั่งเป็นภาษาคน — ถูกแนบไปกับคำขอเมื่อทักษะเปิดอยู่ และ AI ถูกบอกให้ทำตามอย่างเคร่งครัดเหนือคำแนะนำทั่วไป |
| เพดาน | ทักษะที่เปิดทั้งหมดรวมกันไม่เกิน **12,000 ตัวอักษร** ต่อคำขอ |
| ตัวตน | ชื่อไฟล์ (ไม่รวมนามสกุล) — เปลี่ยนชื่อไฟล์ = ทักษะตัวใหม่ (เซสชันที่เปิดตัวเก่าไว้จะไม่เห็น) |

เขียนทักษะที่ดี: สั้น · เจาะจง · เป็นกติกาที่ตรวจได้ ("บทพูดของโทระไม่เกินสองประโยค") ไม่ใช่ความปรารถนากว้าง ๆ ("เขียนให้ดี") · หนึ่งไฟล์หนึ่งเรื่อง เพื่อเปิด/ปิดแยกกันได้

**แจกชุดทักษะ**: โฟลเดอร์ของไฟล์ `.md` — ผู้รับวางใน `Skills/` ของผลงาน · ทักษะเป็นข้อความ ไม่ใช่โค้ด แต่ **เป็นคำสั่งถึง AI ที่อาจมีสิทธิ์แก้ไฟล์** (โหมดช่วยเขียน/ปลดล็อก) — อ่านก่อนใช้ทักษะจากคนอื่น

### Agent — บุคลิกและอ้างอิงสำหรับ Rewrite this

นิยามในกล่อง **ตั้งค่า AI** (เก็บใน `project.khn.json`): บุคลิก (สไตล์ · ธีม · โทน · แหล่งอ้างอิง · กฎ) + ไฟล์อ้างอิง `.txt` ซึ่งถูกก๊อปเข้า `<ผลงาน>/References/`

- อ้างอิงถูกส่งให้ AI เป็นตัวอย่าง/แนวคิดทุกครั้งที่ใช้ Agent นั้น (มีเพดานความยาวรวม — ไฟล์บนได้ก่อน)
- **System prompt ของผลงาน** (ตั้งที่เดียวกัน) ถูกวางนำหน้าทุกคำขอ AI ของทุกฟีเจอร์
- Agent ไปกับผลงาน — ส่งผลงานให้ทีม ทีมได้ Agent ชุดเดียวกัน (แต่ไม่ได้คีย์ API)

### คำสั่งสำหรับ AI รายเอนทิตี้

หน้า Wiki แต่ละหน้ามีส่วน **คำสั่งสำหรับ AI** (คู่ หัวข้อ — ข้อกำหนด) ที่ AI ยึดเมื่อเขียนถึงเอนทิตี้นั้น — เป็นจุดต่อขยายที่ละเอียดที่สุด ([คู่มือผู้ใช้ 6.2](../../manual/th/06-wiki-world.md#62-หน้าเอนทิตี้))

## 10.4 เทมเพลตของ Wiki

`<ผลงาน>/templates.json` กำหนดช่องข้อมูลของแต่ละหมวด — แก้ด้วยตัวแก้ข้อความได้เลย:

```json
{
  "version": 1,
  "templates": [
    {
      "id": "c0ffee00-0000-4000-8000-000000000001",
      "entityTypeKey": "characters",
      "name": "ตัวละคร — เกม RPG",
      "fields": [
        { "key": "Class",   "label": "อาชีพ",     "type": "String", "defaultValue": "" },
        { "key": "Level",   "label": "เลเวล",     "type": "Int",    "defaultValue": "" },
        { "key": "Playable","label": "เล่นได้",    "type": "Bool",   "defaultValue": "" },
        { "key": "Mentor",  "label": "อาจารย์",   "type": "EntityRef", "defaultValue": "" },
        { "key": "Bio",     "label": "ประวัติย่อ", "type": "Text",   "defaultValue": "" }
      ]
    }
  ]
}
```

| ช่อง | ความหมาย |
|---|---|
| `id` | รหัสไม่ซ้ำของเทมเพลต |
| `entityTypeKey` | ชื่อโฟลเดอร์ของหมวดใน `Wiki/` (`characters` · `locations` · `items` · `lore` · หมวดที่ตั้งเอง) |
| `name` | ชื่อที่ผู้ใช้เห็นตอนเลือก/เปลี่ยนเทมเพลต |
| `fields[].key` | ชื่อช่องในไฟล์เอนทิตี้ (`fields.<key>`) — **อย่าเปลี่ยนหลังมีข้อมูลแล้ว** (ข้อมูลเดิมจะกลายเป็น "ข้อมูลเพิ่มเอง") |
| `fields[].label` | ป้ายที่แสดง |
| `fields[].type` | `String` · `Text` · `Int` · `Bool` · `Date` · `Enum` · `EntityRef` |
| `fields[].defaultValue` | ค่าเริ่มต้น (ดูรูปของค่าจากเทมเพลตตั้งต้นที่โปรแกรมสร้างให้ในผลงานของคุณ) |

- หมวดหนึ่งมีได้หลายเทมเพลต — หน้าเอนทิตี้มีปุ่ม **เปลี่ยนเทมเพลต** (ข้อมูลเดิมถูกรักษา เพิ่มเฉพาะช่องที่ขาด)
- ช่องของเทมเพลตใช้เป็นตัวแปรตอนส่งออกได้: `{{โทระ.Class}}` · `[wiki:โทระ.Class]`
- ไฟล์มีช่อง `note` อธิบายโครงสร้างเพิ่มเติม (รวมบล็อก `profile` ของหัวการ์ดโปรไฟล์) — อ่านจากไฟล์ที่โปรแกรมสร้างให้ในผลงานของคุณ
- **แจกชุดเทมเพลต** (เช่น "ชุดสำหรับเกม RPG" · "ชุดนิยายสืบสวน"): ส่งไฟล์ `templates.json` — ผู้รับ **รวมก้อน `templates` เข้ากับของตัวเอง** (ไม่ใช่วางทับทั้งไฟล์ ถ้ามีเทมเพลตของตัวเองอยู่) · ใช้ `id` ใหม่ที่ไม่ซ้ำ
- แก้ไฟล์ขณะโปรแกรมเปิดอยู่: ปิดแล้วเปิดผลงานใหม่ · ไฟล์ต้องเป็น JSON ที่ถูกต้อง (สำรองก่อนแก้)

## 10.5 เวิร์กโฟลว์ส่งออก และโค้ดสั้น

### เวิร์กโฟลว์

ลำดับขั้นของการส่งออก (ตัดโน้ต · หัวบท · ตัวคั่นฉาก · แปลงเป็น HTML …) ตั้งที่ **ส่งออก → ปรับขั้นตอนเวิร์กโฟลว์ส่งออก…** และเก็บใน `project.khn.json → compileWorkflows` — รายการขั้นทั้งหมดที่ [คู่มือผู้ใช้ 9.2](../../manual/th/09-export-import-print.md#92-เวิร์กโฟลว์ส่งออก)

จุดต่อขยายในเวิร์กโฟลว์:

| จุด | ทำอะไรได้ |
|---|---|
| รูปแบบของขั้น **หัวบท** / **ชื่อฉาก** | ข้อความแม่แบบ ใช้ `{n}` `{title}` เช่น `## บทที่ {n} — {title}` |
| ขั้น **ตัวคั่นระหว่างฉาก** | ข้อความอะไรก็ได้ |
| ขั้น **เอาเฉพาะฉากที่สถานะ…** | กรองด้วยสถานะที่คุณตั้งเอง |
| ขั้น **แทนโค้ดสั้น** · **แก้ไขตัวแปร `{{ชื่อ}}`** | เนื้อหาที่ประกอบตอนส่งออก |
| ขั้น **สคริปต์ JavaScript เอง** | แปลงข้อความด้วยโค้ดของคุณ — [4.5](04-hooks-lifecycle.md#45-ตะขออื่นนอกปลั๊กอิน) |

เวิร์กโฟลว์ไปกับผลงาน — ทำ "โปรเจกต์แม่แบบ" ที่มีเวิร์กโฟลว์ของสำนักพิมพ์/สตูดิโอไว้ แล้วให้ทีมเริ่มจากสำเนาของมัน

### โค้ดสั้นและตัวแปร

ผู้ใช้ประกอบเนื้อหาที่เปลี่ยนตามบริบทได้โดยไม่เขียนโค้ด:

| ไวยากรณ์ | แทนด้วย | เมื่อ |
|---|---|---|
| `[title]` `[chapter]` `[date:iso]` `[words]` … | ค่าของบริบทที่กำลังส่งออก | ขั้น "แทนโค้ดสั้น" · ชื่อไฟล์ส่งออก · ช่องของ Wiki/แชท/คอมเมนต์ |
| `[wiki:ชื่อ.ช่อง]` · `[field:ช่อง]` · `[relation:บทบาท]` | ข้อมูลจาก Wiki | เช่นกัน |
| `{{ชื่อ}}` · `{{ชื่อ.ช่อง}}` | ชื่อ/ค่าช่องของเอนทิตี้ | ขั้น "แก้ไขตัวแปร {{ชื่อ}} จาก Wiki" |
| `${PAGE}` `${TITLE}` … (หรือชื่อไทย `${หน้า}`) | ตัวแปรของหัวกระดาษ | หัวกระดาษของบทภาพยนตร์ |

รายการเต็ม: [คู่มือผู้ใช้ 4.13](../../manual/th/04-writing-novel.md#413-โค้ดสั้น-และตัวแปรจาก-wiki) · ทะเบียนโค้ดสั้นอยู่ในซอร์ส (`src/shortcode.js`) — **เพิ่มโค้ดสั้นใหม่ต้องแก้ซอร์สของโปรแกรม** (pull request) ปลั๊กอินเพิ่มไม่ได้ในรุ่นนี้

## 10.6 ธีมสี

ธีมถูกสร้างตอน build โปรแกรม — **เพิ่มธีมต้องแก้ซอร์สแล้ว build** ผู้ใช้วางไฟล์ธีมเพิ่มในตัวพกพาไม่ได้ในรุ่นนี้

สำหรับผู้ที่ build จากซอร์ส หรืออยากส่งธีมเข้าโครงการ:

1. เพิ่มก้อนใน `renderer/themes/themes.json`:

   ```json
   { "id": "ocean-night", "mode": "dark",
     "name": { "th": "ทะเลยามค่ำ", "en": "Ocean Night" },
     "colors": { "bg": "#0b1d2e", "fg": "#e6f1ff",
                 "accent": "#ff7a59", "accentHi": "#ffd166", "link": "#6ec1ff" } }
   ```

2. `node build.js` — ตัวสร้างคำนวณสีที่เหลือจาก 5 สีหลัก เขียนไฟล์ CSS · ลงทะเบียน · เพิ่มป้ายชื่อในไฟล์ภาษาทุกไฟล์
3. `node tools/run-unit.cjs theme` — ตรวจตัวแปรครบ · คอนทราสต์ผ่าน · ไม่แตะสีกระดาษ
4. เปิดโปรแกรม → ตั้งค่า → ทั่วไป → ธีมสี

| ช่อง | |
|---|---|
| `id` | a–z 0–9 และขีด · ไม่ซ้ำ |
| `mode` | `dark` หรือ `light` |
| `colors` | บังคับ 5 สี: `bg` `fg` `accent` `accentHi` `link` · เสริม: `side` `bar` `border` `dim` `sel` |
| `vars` | ทับตัวแปรทีละตัว เช่น `{ "--chip": "#334455" }` |
| `group: "a11y"` | ธีมช่วยการมองเห็น (โผล่เป็นปุ่มในหน้าการช่วยการเข้าถึง) — ต้องใส่ `status` (สีเตือน/อันตรายที่แยกออกได้) |

กติกาที่ธีมต้องผ่าน: **ไม่เปลี่ยนสีของหน้ากระดาษ** (ธีมแต่งแค่เปลือกโปรแกรม) · สีตัวหนังสือถูกดันคอนทราสต์ให้ผ่านเกณฑ์อัตโนมัติ · คู่มือเต็มใน `renderer/themes/README.md`

> ปลั๊กอิน **ไม่ควร** ทำ "ธีม" ด้วยการฉีด CSS ทับตัวแปรของโปรแกรม — กระทบสีกระดาษ/คอนทราสต์ที่โปรแกรมรับประกัน และพังเมื่อโปรแกรมเปลี่ยนชื่อตัวแปร

## 10.7 ของที่ส่งออก/นำเข้าเป็นชุดได้

| ของ | ส่งออก/นำเข้าที่ | ไฟล์ |
|---|---|---|
| **ชุดสถานะฉาก** + สี | ไฟล์ → ตั้งค่า → จัดการสถานะฉาก → ส่งออก… / นำเข้า… | `.json` (นำเข้า = รวมกับของเดิม) |
| **ชุดสีของ Story Network** | ตั้งค่า → ผังความสัมพันธ์ → บันทึกเป็นชุดใหม่ | เก็บกับผลงาน |
| **การจัดวางแผง** | ส่งออก → ส่งออกการจัดวางแผง (JSON)… | `.json` (สำหรับอ้างอิง/รายงานปัญหา) |
| **เรื่องของ Story Starter** | แผง Story Starter → ส่งออก/นำเข้า | `.zip` (โฟลเดอร์เดียวพกพาได้) |
| **ผู้ให้บริการ AI** (ไม่รวมคีย์ข้ามเครื่อง) | ตั้งค่า AI → บันทึกเป็นของฉัน / ใช้ผู้ให้บริการของฉัน | เก็บในเครื่อง |
| **พรีเซ็ตชื่อไฟล์ส่งออก** | ศูนย์รวมการส่งออก → บันทึกเป็นพรีเซ็ต | ค่าของผู้ใช้ |
| **กระดานวางแผน** | กระดาน → ส่งออก JSON | `.json` |
| **ทั้งผลงาน** (รวมทุกอย่างข้างบนที่เป็นของผลงาน) | ส่งออก → ทั้งโปรเจกต์เป็น ZIP… | `.zip` |

**"ชุดเริ่มต้น" สำหรับทีม/ชุมชน**: วิธีที่ครบที่สุดคือทำ **โปรเจกต์แม่แบบ** — ผลงานเปล่าที่ตั้ง เทมเพลต Wiki · สถานะ · เวิร์กโฟลว์ · ทักษะ AI · พจนานุกรม · คำแปลเฉพาะ · (ปลั๊กอินของผลงาน ถ้าจำเป็น) ไว้แล้ว ส่งออกเป็น ZIP ให้คนอื่นนำเข้าแล้วเริ่มงาน

## 10.8 เลือกจุดต่อขยายให้ถูก

| อยากได้ | ใช้ |
|---|---|
| ศัพท์ของโปรแกรมให้ตรงกับงาน (ฉาก → เควสต์) | ไฟล์ภาษาของผลงาน |
| เลิกขีดแดงชื่อเฉพาะ | พจนานุกรม |
| AI เขียนตามสไตล์ของเรื่อง | ทักษะ · Agent · System prompt · คำสั่งรายเอนทิตี้ |
| ช่องข้อมูลตัวละครแบบของตัวเอง | เทมเพลต Wiki |
| ไฟล์ส่งออกหน้าตาเฉพาะ | เวิร์กโฟลว์ (+ ขั้น JavaScript) · ตั้งค่ารูปแบบ |
| สถานะงานของทีม | ชุดสถานะฉาก |
| คำสั่งใหม่ · แผงใหม่ · งานอัตโนมัติเมื่อบันทึก · ต่อบริการภายนอก | **ปลั๊กอิน** |
| รูปแบบส่งออกใหม่ในศูนย์ส่งออก · โค้ดสั้นใหม่ · ธีม · ฟีเจอร์ในตัวแก้ไข | แก้ซอร์สของโปรแกรม (pull request) |
