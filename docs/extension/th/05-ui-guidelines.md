# 5. หน้าตาและการใช้งาน

**ภาษา:** ไทย · [English](../en/05-ui-guidelines.md)

[← 4. ตะขอและวงจรชีวิต](04-hooks-lifecycle.md) · [ภาพรวม](README.md) · ถัดไป: [6. ทำงานกับไฟล์และข้อมูลของผลงาน →](06-data-and-files.md)

---

ปลั๊กอินที่ดีดูเหมือนเป็นส่วนหนึ่งของโปรแกรม: ตามธีม · ตามขนาด UI ที่ผู้ใช้ตั้ง · ใช้คีย์บอร์ดได้ · ไม่รบกวนการเขียน

## 5.1 หลักใหญ่ 6 ข้อ

1. **พื้นที่เขียนเป็นของนักเขียน** — อย่าโผล่อะไรขึ้นมาเองระหว่างพิมพ์ (กล่อง · แผง · ของลอย) ทุกอย่างเกิดจากผู้ใช้สั่ง
2. **ห้ามแตะ DOM ของตัวแก้ไข** (`.ProseMirror` และลูกหลาน) — ตัวจัดหน้าวัดจาก DOM จริง ใส่คลาส/element/สไตล์เข้าไป = การตัดหน้าเพี้ยนทั้งเอกสาร และของที่ใส่หายเมื่อเอกสารถูกวาดใหม่
3. **ใช้ตัวแปรสีของธีม** — โปรแกรมมีธีม 28 ชุด (มืด/สว่าง/คอนทราสต์สูง/ตาบอดสี/ขาวดำ) สีตายตัวจะอ่านไม่ออกในบางธีม
4. **ขนาดคูณ `var(--ui-scale, 1)`** — ผู้ใช้ย่อ/ขยาย UI ได้ 75–200%
5. **ข้อความจากผู้ใช้/ไฟล์/เครือข่าย ใส่ด้วย `textContent` เสมอ** — ห้าม `innerHTML`
6. **ทำตัวแบบโปรแกรมเดสก์ท็อป ไม่ใช่หน้าเว็บ** — ไม่มีรูปมือบนปุ่ม · ข้อความ UI ลากเลือกไม่ได้ · ไม่มีอนิเมชันเด้ง

## 5.2 ตัวแปรสีของธีม

ตัวแปรตั้งที่ `<body>` (คลาส `theme-<id>`) — ใช้ได้กับทุก element ของปลั๊กอินที่อยู่ในหน้า และเปลี่ยนตามเองเมื่อผู้ใช้เปลี่ยนธีม

### พื้นผิว

| ตัวแปร | ใช้เป็น |
|---|---|
| `--bg` | พื้นหลักของพื้นที่ทำงาน |
| `--side` | พื้นแผงข้าง |
| `--bar` | พื้นแถบเครื่องมือ / แถบสถานะ |
| `--panel-head` | หัวแผง |
| `--input-bg` | ช่องกรอก |
| `--sunken` | พื้นจม — บล็อกโค้ด · กล่องผลลัพธ์ · ทูลทิป |
| `--chip` | พื้นป้ายชื่อ (pill) |
| `--hover` | พื้นตอนชี้ปุ่ม |
| `--hover-soft` | พื้นตอนชี้แถวในรายการ |
| `--sel` | พื้นของสิ่งที่ถูกเลือก |
| `--curline` | พื้นบรรทัด/แถวปัจจุบัน |
| `--border` | เส้นขอบทั่วไป |

### ตัวหนังสือ

| ตัวแปร | ใช้เป็น |
|---|---|
| `--fg` | ตัวหนังสือหลัก |
| `--bright` | ตัวหนังสือที่เด่นที่สุด (หัวข้อ) |
| `--dim` | ตัวหนังสือรอง / คำอธิบาย |
| `--muted-strong` | ข้อความรองที่ต้องอ่านออกบนพื้นเข้ม |
| `--link` | ลิงก์ / ชื่อที่คลิกได้ |

### สีเน้นและสีความหมาย

| ตัวแปร | ใช้เป็น | ตัวหนังสือบนพื้นนี้ |
|---|---|---|
| `--accent` | สีเน้นหลัก (ปุ่มยืนยัน) | **`--on-accent`** |
| `--accent-hi` | สีเน้นรอง (ไฮไลต์ · สิ่งที่เปิดอยู่) | **`--on-accent-hi`** |
| `--st-warn` | คำเตือน | — |
| `--st-danger` | อันตราย / ข้อผิดพลาด | — |
| `--danger-soft` | พื้นปุ่มอันตรายตอนชี้ | — |
| `--find-hit` | ไฮไลต์ผลค้นหา | — |

กติกา:

- **จับคู่พื้นกับตัวหนังสือให้ถูก**: ตัวหนังสือบน `--accent` ต้องเป็น `--on-accent` (ไม่ใช่ `--fg` หรือ `#fff`)
- ใส่ค่าสำรองเสมอ: `color: var(--fg, #ddd)`
- **อย่าบอกสถานะด้วยสีอย่างเดียว** — เพิ่มไอคอนหรือข้อความ (มีธีมตาบอดสีและขาวดำ)
- ต้องการสีโปร่ง/ผสม ใช้ `color-mix()` จากตัวแปร: `background: color-mix(in srgb, var(--accent) 18%, transparent)`
- **ห้ามแตะตัวแปรตระกูล `--paper-*`** และสีของหน้ากระดาษ — หน้ากระดาษไม่ตามธีม
- ห้ามเขียนทับตัวแปรของธีม (`body { --bg: … }`) — เป็นของผู้ใช้

### ตัวอย่างการ์ด

```css
.wcs-card {
  background: var(--side, #222);
  color: var(--fg, #ddd);
  border: 1px solid var(--border, #444);
  border-radius: calc(8px * var(--ui-scale, 1));
  padding: calc(10px * var(--ui-scale, 1)) calc(12px * var(--ui-scale, 1));
  font-size: calc(13px * var(--ui-scale, 1));
}
.wcs-card h3 { color: var(--bright, #fff); font-size: calc(14px * var(--ui-scale, 1)); margin: 0 0 6px; }
.wcs-card .wcs-sub { color: var(--dim, #999); }
.wcs-btn {
  background: var(--accent); color: var(--on-accent);
  border: 0; border-radius: calc(6px * var(--ui-scale, 1));
  padding: calc(4px * var(--ui-scale, 1)) calc(10px * var(--ui-scale, 1));
  cursor: default;                              /* ไม่ใช้รูปมือ */
}
.wcs-btn:hover { filter: brightness(1.08); }    /* เปลี่ยนสีเล็กน้อย — ห้ามขยับ/ขยายตอนชี้ */
.wcs-btn:active { filter: brightness(0.92); }   /* ปุ่มต้องมีสภาพกดลง */
.wcs-btn:focus-visible { outline: 2px solid var(--accent-hi); outline-offset: 2px; }
```

## 5.3 ขนาด ระยะ และตัวอักษร

- ขนาดทุกอย่างคูณ `var(--ui-scale, 1)`: `font-size: calc(13px * var(--ui-scale, 1))`
- ขนาดอ้างอิงของโปรแกรม: ข้อความทั่วไป 13px · หัวข้อในแผง 14px · คำอธิบาย 12px
- **อย่าตั้ง `font-family`** — สืบทอดจากโปรแกรม (สแตกของโปรแกรมรวมฟอนต์ไทยและฟอนต์ไอคอนไว้แล้ว) ถ้าต้องตั้งจริง ให้ลงท้ายด้วย `var(--thai-net)`
- ตัวเลขที่เปลี่ยนค่าบ่อย (ตัวจับเวลา · ตัวนับ): `font-variant-numeric: tabular-nums` กันกว้างขยับ
- ทดสอบที่ขนาด UI 75% · 100% · 125% · 200% และภาษาที่คำยาว (เยอรมัน · ฝรั่งเศส)

## 5.4 แผงของปลั๊กอิน

```js
k2.registerPanel('main', {
  title: 'ชื่อสั้น ๆ',
  icon: 'chart',
  defaultSide: 'right',
  render: (host) => { /* … */ },
});
```

- **แผงแคบได้ถึง ~200px** (ผนึกข้าง) และกว้างได้เต็มจอ (ลอย/ฉีก) — เลย์เอาต์ต้องยืดหยุ่น: ใช้ flex/grid + `min-width: 0` · ข้อความยาวตัดด้วย `overflow: hidden; text-overflow: ellipsis`
- ใช้ **container query** ถ้าต้องเปลี่ยนเลย์เอาต์ตามความกว้างของแผง (ไม่ใช่ media query ของหน้าต่าง):

  ```css
  .myplug-root { container: myplug / inline-size; }
  @container myplug (max-width: 320px) { .myplug-row { flex-direction: column; } }
  ```
- เนื้อแผงเลื่อนได้เองเมื่อยาวเกิน — ไม่ต้องทำแถบเลื่อนซ้อน
- **สถานะว่าง** ต้องบอกว่าทำอะไรต่อ: ข้อความสั้น + ปุ่ม ("ยังไม่มีข้อมูล — กดเพื่อสแกน") ไม่ใช่ผืนว่าง
- หัวแผง (ชื่อ · ปุ่มพับ/ลอย/ปิด) เป็นของโปรแกรม — อย่าทำหัวซ้ำในเนื้อ
- `render` ถูกเรียกซ้ำ: เก็บสภาพในตัวแปรของปลั๊กอิน วาดใหม่ทั้งก้อนด้วย `host.replaceChildren(...)`
- งานที่รอ I/O: วาดโครงก่อน แล้วเติมข้อมูลเมื่อได้ — อย่าล้างแผงแล้วปล่อยว่างระหว่างรอ

## 5.5 คีย์บอร์ดและการเข้าถึง

- ใช้ element ที่ถูกชนิด: `<button>` สำหรับปุ่ม · `<input>`/`<select>` สำหรับช่อง — **ไม่ใช่ `<div onclick>`** (กดด้วยคีย์บอร์ดไม่ได้ · โปรแกรมอ่านจอไม่รู้ว่าเป็นปุ่ม)
- ปุ่มไอคอนล้วนต้องมี `title` (ทูลทิป) และ `aria-label`
- ช่องกรอกที่ไม่มีป้ายข้าง ๆ ต้องมี `placeholder` หรือ `aria-label`
- มีวงโฟกัสที่มองเห็น (`:focus-visible`) · ลำดับ `Tab` ตามลำดับที่เห็น
- จับปุ่มด้วย **`e.code`** (`'KeyW'` · `'BracketRight'`) ไม่ใช่ `e.key` — แป้นไทยให้ `e.key` เป็นอักษรไทย (ปุ่มที่ไม่ขึ้นกับแป้น เช่น `Enter` `Escape` `ArrowUp` `Delete` ใช้ `e.key` ได้)
- **`Esc` ต้องยกเลิกได้** — กล่อง · เมนู · การลากที่กำลังทำ
- ของประดับที่ทับจอ: `aria-hidden="true"` + `pointer-events: none`
- เคารพ `prefers-reduced-motion`: อนิเมชันเป็นของเสริม ปิดได้

  ```css
  @media (prefers-reduced-motion: reduce) { .myplug-anim { animation: none; transition: none; } }
  ```
- ของที่วาดทับจอต้องซ่อนตอนพิมพ์: `@media print { .myplug-overlay { display: none; } }`
- คอนทราสต์ของข้อความกับพื้น ≥ 4.5:1 — ได้ฟรีเมื่อจับคู่ตัวแปรธีมถูก

## 5.6 หลายภาษา

โปรแกรมมี 7 ภาษา แต่ `k2` **ยังไม่มีตัวช่วยแปลข้อความของปลั๊กอิน** — ทำตารางเอง:

```js
// ภาษาของหน้าจอ = <html lang="…"> (โปรแกรมตั้งให้หลังโหลดภาษา)
const LANG = (document.documentElement.lang || 'th').slice(0, 2);
const STR = {
  th: { count: 'นับคำฉากนี้', words: (n) => n + ' คำ', empty: 'ยังไม่มีข้อมูล' },
  en: { count: 'Count words in this scene', words: (n) => n + (n === 1 ? ' word' : ' words'), empty: 'No data yet' },
};
const T = STR[LANG] || STR.en;                 // ภาษาที่ไม่มี → อังกฤษ

k2.registerCommand(T.count, () => k2.setStatus(T.words(count())));
```

- ผู้ใช้เปลี่ยนภาษาแล้วโปรแกรมเริ่มใหม่ — อ่านภาษาครั้งเดียวตอนรันก็พอ
- วันที่/ตัวเลข: `new Intl.DateTimeFormat(document.documentElement.lang)` · `Number#toLocaleString(lang)`
- เรียงชื่อที่คนอ่าน: `new Intl.Collator(lang).compare`
- ตัดคำไทย: `new Intl.Segmenter(undefined, { granularity: 'word' })` — อย่านับคำด้วย `split(' ')`
- **ข้อมูลที่เขียนลงไฟล์ห้ามแปล** — เก็บรหัส (`'done'`) แล้วแปลตอนแสดง ไม่ใช่เก็บ "เสร็จ"/"Done"
- **อย่าเทียบเงื่อนไขกับข้อความบนจอ** ของโปรแกรม (`textContent === 'บันทึก'`) — เปลี่ยนภาษาแล้วพังเงียบ

## 5.7 CSS ของปลั๊กอิน

```js
const style = document.createElement('style');
style.dataset.plugin = k2.pluginName;
style.textContent = `
  .wcs-card { … }
`;
document.head.append(style);
k2.onUnload(() => style.remove());             // สไตล์ที่ฉีดเองต้องถอนเอง
```

| ทำ | ห้าม |
|---|---|
| ตั้งชื่อคลาสมีคำนำหน้าของปลั๊กอิน (`.wcs-…`) | คลาสลอย ๆ (`.card` `.row` `.btn`) — ชนกับโปรแกรม/ปลั๊กอินอื่น |
| เขียนกฎเฉพาะ element ของตัวเอง | กฎที่จับ element ของโปรแกรม (`button { … }` · `.k-panel { … }` · `body { … }`) |
| ใช้สไตล์อินไลน์สำหรับของชิ้นเดียว | `!important` |
| | พึ่งคลาสภายในของโปรแกรม (`.k-…`) เพื่อหน้าตา — เปลี่ยนได้ทุกรุ่น |
| | `transform` ใน `:hover` (การ์ดลอย/ขยายตอนชี้) |
| | `scroll-behavior: smooth` |
| | โหลดฟอนต์/CSS/รูปจากอินเทอร์เน็ต — โปรแกรมทำงานออฟไลน์ |

คลาสของโปรแกรมที่ใช้ได้ (มีเจตนาให้ของภายนอกใช้): **`k-selectable`** — ใส่บนเนื้อหาอ่านอย่างเดียวที่ผู้ใช้ควรลากเลือก/คัดลอกได้ (ผลลัพธ์ · รายงาน · log) เพราะข้อความ UI ลากเลือกไม่ได้โดยปริยาย

## 5.8 ไอคอน

- `registerPanel({ icon })` รับ **ชื่อไอคอนของโปรแกรม** (ทะเบียน `icons/glyphs.csv` — ชุด Material Design จาก Nerd Fonts) เช่น `chart` `note` `timer` `book` `book-open` `image` `chat` `map` `user` `group` `tag` `search` `cog` `bug` `export` `refresh` `plus` `extension` · ชื่อที่ไม่มี = ไม่มีไอคอน
- ในเนื้อแผง: ใช้ SVG อินไลน์ของคุณเอง (`fill="currentColor"` เพื่อให้ตามสีตัวหนังสือ) หรือข้อความ
- **อย่าใช้อีโมจิเป็นไอคอนของ UI** — แสดงต่างกันตามระบบและไม่ตามธีม
- อย่าคัดลอกอักขระไอคอนของโปรแกรมไปใช้ตรง ๆ — เป็นอักขระของฟอนต์ภายใน เปลี่ยนชุดไอคอนแล้วกลายเป็นกล่อง

## 5.9 ข้อความถึงผู้ใช้

| ช่องทาง | ใช้เมื่อ |
|---|---|
| `k2.setStatus(text)` | ผลของสิ่งที่ผู้ใช้เพิ่งสั่ง — บรรทัดเดียว หายเอง |
| ในแผงของปลั๊กอิน | ข้อมูลที่อยู่นาน · ผลลัพธ์ · ข้อผิดพลาดของงานในแผงนั้น |
| `k2.confirmBox` | ก่อนทำสิ่งที่ย้อนไม่ได้หรือเขียนทับ |
| `k2.ask` | ต้องการข้อความหนึ่งช่องจากผู้ใช้ |
| `k2.log` | รายละเอียดสำหรับไล่ปัญหา — ผู้ใช้ทั่วไปไม่เห็นเว้นแต่เปิดแผง Log |

- เขียนให้คนอ่าน: "สร้างรายงานไม่สำเร็จ — เปิดผลงานก่อน" ไม่ใช่ "Error: root is null"
- บอกผลทั้งตอนสำเร็จและตอนล้ม — อย่าเงียบ
- งานที่นานกว่า ~1 วินาที: บอกว่ากำลังทำ และถ้าเป็นไปได้ให้ยกเลิกได้
- อย่าใส่คีย์ลัดเป็นข้อความตายตัวในคำอธิบายของคำสั่งโปรแกรม (ผู้ใช้ตั้งใหม่ได้ และ macOS ใช้ `⌘`)

## 5.10 รายการตรวจหน้าตา

- [ ] ธีมมืด (K2) · ธีมสว่าง (K2 สว่าง) · คอนทราสต์สูง — อ่านออกทุกธีม
- [ ] ขนาด UI 75% และ 200% — ไม่ล้น ไม่ถูกตัด
- [ ] แผงที่ความกว้าง ~220px และแบบลอยกว้าง — ใช้งานได้ทั้งคู่
- [ ] ใช้ได้ด้วยคีย์บอร์ดอย่างเดียว · เห็นวงโฟกัส
- [ ] ไม่มีอะไรโผล่เองตอนโหลดหรือระหว่างพิมพ์
- [ ] ไม่มี element/คลาส/สไตล์ของปลั๊กอินใน `.ProseMirror`
