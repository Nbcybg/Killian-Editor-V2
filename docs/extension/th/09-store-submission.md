# 9. การเผยแพร่ และ "ร้านปลั๊กอิน"

## 9.1 สถานะปัจจุบัน — อ่านก่อน

> **Killian 2 รุ่น alpha.169 ยังไม่มีร้านปลั๊กอิน (store / marketplace) ไม่มีทะเบียนกลาง ไม่มีกระบวนการส่งตรวจ (submission / review) และไม่มีการอัปเดตปลั๊กอินอัตโนมัติ**

สิ่งที่ **มีอยู่จริง** ในรุ่นนี้:

| มี | ไม่มี |
|---|---|
| ติดตั้งจากลิงก์ GitHub / ลิงก์ zip ในแผงปลั๊กอิน | หน้ารายการปลั๊กอินให้เลือกในโปรแกรม |
| การยืนยันก่อนติดตั้ง + คำเตือนเรื่องสิทธิ์ | การค้นหาปลั๊กอินจากในโปรแกรม |
| การอนุญาตปลั๊กอินที่มากับผลงาน | การรีวิว/รับรองจากผู้ดูแลโปรแกรม |
| การ์ดแสดง รุ่น · ผู้เขียน · คำอธิบาย | คะแนน · รีวิว · จำนวนดาวน์โหลด |
| | การลงนาม/ยืนยันตัวผู้เขียน |
| | การแจ้งเตือนและติดตั้งอัปเดตอัตโนมัติ |
| | ระบบซื้อขาย/ใบอนุญาตใช้งาน |

ดังนั้นบทนี้แบ่งเป็นสองส่วนที่แยกกันชัด:

- **9.2–9.6** — วิธีเผยแพร่ปลั๊กอิน **วันนี้** ให้คนหาเจอ ติดตั้งได้ และเชื่อถือได้ (ทำได้จริงทั้งหมด)
- **9.7** — **รายการความพร้อม** ที่ปลั๊กอินควรผ่าน เผื่อวันที่มีรายการทางการ · เป็นแนวปฏิบัติที่ดีอยู่แล้วในตัว **ไม่ใช่กระบวนการที่มีอยู่จริง และไม่ใช่คำมั่นว่าจะมีร้าน**

## 9.2 เผยแพร่วันนี้: 5 ขั้น

### ขั้นที่ 1 — ทำรีโปให้ติดตั้งได้ในลิงก์เดียว

ตาม [บทที่ 8](08-packaging-distribution.md): `plugin.json` + ไฟล์ที่รันได้อยู่ใน branch หลัก · ชื่อรีโป/โฟลเดอร์ = ชื่อปลั๊กอิน
ทดสอบ: เปิด Killian บนโปรไฟล์สะอาด → แผงปลั๊กอิน → **ติดตั้งจากลิงก์** → วางลิงก์รีโป → ต้องขึ้น "ทำงานอยู่"

### ขั้นที่ 2 — เขียนหน้าแรกของรีโป (README)

คนส่วนใหญ่ตัดสินใจจาก 10 วินาทีแรก — บนสุดของ README ต้องมี:

1. **หนึ่งประโยค** ว่าปลั๊กอินทำอะไร
2. **ภาพหน้าจอ** หรือ GIF สั้น ๆ
3. **ลิงก์ติดตั้ง** ในบล็อกโค้ด (คัดลอกง่าย) + ขั้นตอน 3 บรรทัด
4. **สิทธิ์และข้อมูล**: อ่านอะไร เขียนอะไร ใช้เครือข่ายไหม
5. **รุ่น Killian ที่รองรับ**

แม่แบบเต็มที่ [9.5](#95-แม่แบบ-readme-ของปลั๊กอิน)

### ขั้นที่ 3 — ทำให้ค้นเจอบน GitHub

เพราะยังไม่มีทะเบียนกลาง การค้นเจอพึ่งข้อมูลของรีโป:

| ตั้งค่า | แนะนำ |
|---|---|
| **ชื่อรีโป** | ขึ้นต้นด้วย `k2-` หรือ `killian2-` เช่น `k2-word-count` — เห็นแล้วรู้ว่าเป็นปลั๊กอินของ Killian 2 |
| **Description** ของรีโป | "Killian 2 plugin — <ทำอะไร>" |
| **Topics** | `killian2-plugin` (แท็กกลางที่แนะนำให้ทุกคนใช้เพื่อให้ค้นรวมกันได้) + `killian2` · `writing-tools` · หัวข้อของปลั๊กอิน |
| **Website** | ลิงก์เอกสาร/หน้าสาธิต (ถ้ามี) |
| **License** | เลือกจากรายการของ GitHub — ขึ้นป้ายบนหน้ารีโป |

ผู้ใช้ค้นได้ที่ `https://github.com/topics/killian2-plugin`

### ขั้นที่ 4 — ออกรุ่นอย่างเป็นระเบียบ

```bash
# 1) แก้ version ใน plugin.json และเขียน CHANGELOG.md
# 2) build (ถ้ามี) แล้ว commit ผล build
git add -A
git commit -m "Release 1.3.0"
git tag v1.3.0
git push && git push --tags
```

แล้วสร้าง **GitHub Release** จาก tag นั้น ใส่บันทึกการเปลี่ยนแปลง:

```markdown
## 1.3.0

### เพิ่ม
- แผงสรุปจำนวนคำรายบท

### แก้
- นับคำผิดเมื่อฉากเป็นบทภาพยนตร์

### รองรับ
- Killian 2 alpha.169 ขึ้นไป

### อัปเดต
แผงปลั๊กอิน → ติดตั้งจากลิงก์ → `https://github.com/you/k2-word-count` → ยืนยันเขียนทับ
```

ผู้ใช้ที่กด Watch → Releases จะได้อีเมลจาก GitHub — นี่คือ "การแจ้งเตือนอัปเดต" ที่มีในวันนี้

### ขั้นที่ 5 — บอกต่อ

- ใส่ลิงก์รีโปในช่อง `homepage` ของ `plugin.json` (แสดงว่ามาจากไหน และผู้ใช้ตามไปรายงานปัญหาได้)
- แชร์ในชุมชนนักเขียน/คนทำเกมที่คุณอยู่ พร้อมลิงก์ติดตั้งและภาพหน้าจอ
- ปัญหาและคำขอของปลั๊กอิน: เปิด **Issues ของรีโปคุณเอง** — บอกใน README

> **อย่าเปิด Issue ในรีโปของ Killian 2 เพื่อโปรโมตหรือขอให้ลงรายการปลั๊กอิน** — Issue ของโครงการใช้ติดตามบั๊กที่รายงานจากในโปรแกรม และตามนโยบายของรีโป Issue ที่เปิดจากภายนอกจะถูกปิดอัตโนมัติ
> ต้องการเสนอสิ่งที่ต้องแก้ในตัวโปรแกรม (เช่น API ที่ขาด): ใช้ **ช่วยเหลือ → รายงานบั๊ก…** ในโปรแกรม หรือเปิด pull request

## 9.3 ชื่อ และการไม่ทำให้เข้าใจผิด

- ชื่อปลั๊กอินและรีโป **บอกว่าทำอะไร** ไม่ใช่บอกว่าเป็นใคร: `k2-word-count` ดีกว่า `k2-super-tools`
- **อย่าใช้ชื่อ/โลโก้ที่ทำให้เข้าใจว่าเป็นของทางการ** ("Killian Official …") — เขียนว่า "ปลั๊กอินสำหรับ Killian 2 โดย <คุณ>"
- อย่าใช้ชื่อซ้ำกับปลั๊กอินที่มีอยู่ (ค้น topic ก่อน) — ชื่อโฟลเดอร์ซ้ำ = ติดตั้งทับของคนอื่น
- ชื่อผลิตภัณฑ์อื่นที่เอ่ยถึง (รูปแบบไฟล์ · บริการ) เป็นเครื่องหมายการค้าของเจ้าของ — เอ่ยถึงเพื่อบอกความเข้ากันได้เท่านั้น

## 9.4 Manifest ที่พร้อมสำหรับรายการแนะนำ

โปรแกรมอ่าน 8 ช่องของ `plugin.json` ([2.2](02-anatomy.md#22-pluginjson)) และ **มองข้ามช่องอื่น** — คุณจึงใส่เมทาดาทาเพิ่มได้โดยไม่กระทบการทำงาน ช่องด้านล่างเป็น **ข้อเสนอของคู่มือนี้** เพื่อให้ปลั๊กอินอธิบายตัวเองได้ครบในไฟล์เดียว (เครื่องมือดัชนีของชุมชนในอนาคตอ่านได้) — **โปรแกรมรุ่นนี้ไม่ได้ใช้**

```json
{
  "name": "นับคำตอนบันทึก",
  "entry": "main.js",
  "version": "1.3.0",
  "author": "ชื่อคุณ",
  "description": "บอกจำนวนคำทุกครั้งที่บันทึก และมีแผงสรุปรายบท",
  "minAppVersion": "2.0.0-alpha.169",
  "homepage": "https://github.com/you/k2-word-count",
  "hotReload": true,

  "id": "k2-word-count",
  "repository": "https://github.com/you/k2-word-count",
  "license": "MIT",
  "keywords": ["สถิติ", "นับคำ", "stats"],
  "languages": ["th", "en"],
  "permissions": {
    "reads": ["เนื้อของฉากที่เปิดอยู่", "ไฟล์ทะเบียนของผลงาน"],
    "writes": [],
    "network": []
  }
}
```

| ช่องเสนอ | ความหมาย |
|---|---|
| `id` | ตัวตนถาวร = ชื่อโฟลเดอร์ที่ติดตั้ง |
| `repository` · `license` | ที่มาและสัญญาอนุญาต |
| `keywords` · `languages` | สำหรับค้นหา · ภาษาที่ UI ของปลั๊กอินรองรับ |
| `permissions` | **คำประกาศ** ของผู้เขียนว่าปลั๊กอินอ่าน/เขียน/ติดต่ออะไร — โปรแกรม **ไม่บังคับใช้** (ไม่มีแซนด์บ็อกซ์) มีค่าเป็นคำสัญญาต่อผู้ใช้ที่ตรวจได้จากซอร์ส |

## 9.5 แม่แบบ README ของปลั๊กอิน

````markdown
# นับคำตอนบันทึก (k2-word-count)

ปลั๊กอินสำหรับ [Killian 2](https://github.com/Nbcybg/Killian-Editor-V2) — บอกจำนวนคำทุกครั้งที่บันทึก และมีแผงสรุปรายบท

![ภาพหน้าจอ](docs/screenshot.png)

## ติดตั้ง

1. เปิด Killian 2 → **มุมมอง → แผง → ปลั๊กอิน**
2. กด **ติดตั้งจากลิงก์** แล้ววาง:

   ```
   https://github.com/you/k2-word-count
   ```
3. ยืนยัน — ปลั๊กอินเริ่มทำงานทันที

รองรับ Killian 2 **alpha.169 ขึ้นไป** · รุ่นปัจจุบันของปลั๊กอิน: **1.3.0** ([บันทึกการเปลี่ยนแปลง](CHANGELOG.md))

## ใช้งาน

| คำสั่ง | คีย์ลัด | ทำอะไร |
|---|---|---|
| นับคำฉากนี้ | Ctrl+Shift+F8 | แสดงจำนวนคำของฉากที่เปิดอยู่บนแถบสถานะ |
| เปิดแผงนับคำ | — | เปิดแผงสรุป |

คำสั่งอยู่ที่การ์ดของปลั๊กอินในแผงปลั๊กอิน และปุ่ม "คำสั่งจากปลั๊กอิน" บนแถบเครื่องมือ

## สิทธิ์และข้อมูล

- **อ่าน**: เนื้อของฉากที่เปิดอยู่
- **เขียน**: ไม่เขียนไฟล์
- **เครือข่าย**: ไม่ใช้
- **เก็บค่า**: จำนวนคำของการบันทึกล่าสุด — ต่อผลงาน (ใน `project.khn.json`)
- ปิด/ถอนได้ทันทีโดยไม่ต้องเริ่มโปรแกรมใหม่

## อัปเดต / ถอน

- **อัปเดต**: ติดตั้งจากลิงก์เดิมอีกครั้ง แล้วยืนยันเขียนทับ
- **ถอน**: ปุ่ม "ถอนออก" บนการ์ด · ค่าที่ปลั๊กอินเก็บใน `project.khn.json` ไม่ถูกลบ (ไม่มีผลถ้าไม่ได้ติดตั้ง)

## ปัญหาและคำขอ

เปิด Issue ที่รีโปนี้ พร้อมบอกรุ่นของ Killian 2 (ดูที่แถบชื่อของหน้าต่าง) รุ่นของปลั๊กอิน และข้อความจากแผง **บันทึก (Log)** ที่ขึ้นต้นด้วย `[plugin k2-word-count]`

## พัฒนา

```bash
npm install
npm run build        # → word-count/main.js
```

## สัญญาอนุญาต

MIT — ดู [LICENSE](LICENSE)
````

## 9.6 ดูแลหลังปล่อย

| เรื่อง | แนวทาง |
|---|---|
| Killian ออกรุ่นใหม่ | ทดสอบปลั๊กอินกับรุ่นใหม่ (อ่าน CHANGELOG ของโปรแกรม — API ช่วง alpha เปลี่ยนได้) แล้วอัปเดตบรรทัด "รองรับ" ใน README |
| ปลั๊กอินพังกับรุ่นใหม่ | ออกรุ่นแก้ + ขยับ `minAppVersion` ถ้าใช้ API ใหม่ · บอกใน README ว่ารุ่นไหนของปลั๊กอินใช้กับ Killian รุ่นไหน |
| รายงานบั๊กจากผู้ใช้ | ขอ: รุ่นทั้งสอง · ขั้นตอนทำซ้ำ · บรรทัดใน Log · **อย่าขอไฟล์ต้นฉบับของเขา** ถ้าไม่จำเป็น |
| เลิกดูแล | เขียนไว้บนสุดของ README · ตั้งรีโปเป็น archived — ผู้ใช้ควรรู้ว่าไม่มีการแก้ช่องโหว่แล้ว |
| โอนให้คนอื่นดูแล | โอนรีโป (GitHub เปลี่ยนเส้นทางลิงก์เดิมให้) — **ชื่อรีโป/โฟลเดอร์ต้องคงเดิม** |
| ช่องโหว่ความปลอดภัย | ออกรุ่นแก้ทันที · ระบุใน Release ว่ารุ่นไหนได้รับผล · ผู้ใช้ต้องอัปเดตเอง จึงต้องบอกให้ชัด |

## 9.7 รายการความพร้อม (เกณฑ์ที่แนะนำ)

> รายการนี้เป็น **การรับรองตัวเอง** ของผู้เขียน — ใช้ตรวจปลั๊กอินก่อนประกาศว่า "พร้อมให้คนทั่วไปใช้" และเป็นเกณฑ์ที่สมเหตุผลสำหรับรายการแนะนำใด ๆ ที่ชุมชนหรือผู้ดูแลอาจทำขึ้นในอนาคต **ยังไม่มีใครตรวจรายการนี้แทนคุณ**

### ก. ตัวตนและเมทาดาทา

- [ ] ชื่อโฟลเดอร์/รีโปเป็น `kebab-case` อักษรอังกฤษ ไม่ซ้ำกับปลั๊กอินที่รู้จัก และจะไม่เปลี่ยน
- [ ] `plugin.json` ครบ: `name` · `version` (semver) · `author` · `description` · `minAppVersion` · `homepage`
- [ ] มี `LICENSE` · `README.md` (ตามแม่แบบ) · `CHANGELOG.md`
- [ ] ทุกรุ่นมี tag `vX.Y.Z` ตรงกับ `version`

### ข. ติดตั้งและถอน

- [ ] ติดตั้งจากลิงก์รีโปได้บนโปรไฟล์สะอาด ในครั้งเดียว
- [ ] ซิปที่ถูกติดตั้ง < 1 MB (ไม่มี `node_modules` · สื่อใหญ่)
- [ ] ติดตั้งทับรุ่นก่อนหน้าแล้วทำงานต่อ · ข้อมูลเดิมอ่านได้
- [ ] ถอนแล้วไม่เหลือผลต่อโปรแกรม · README บอกว่าทิ้งข้อมูลอะไรไว้

### ค. ขอบเขตและความปลอดภัย ([บทที่ 7](07-security.md))

- [ ] ใช้เฉพาะ `k2` — ไม่แตะของภายในของโปรแกรมบน `window` ไม่พึ่ง DOM/คลาสของโปรแกรม
- [ ] ไม่เขียนทับไฟล์งานของผู้ใช้ · ไม่อ่าน `ai-key.json`
- [ ] ไม่ติดต่อเครือข่ายโดยผู้ใช้ไม่ได้สั่ง · ไม่มี telemetry · ไม่โหลดโค้ดมารัน
- [ ] ข้อความที่ไม่น่าเชื่อถือทุกจุดผ่าน `textContent` / `text:`
- [ ] ไม่มีความลับในซอร์ส · ความลับของผู้ใช้อยู่ใน `localStorage` เท่านั้น
- [ ] โค้ดที่ติดตั้ง **อ่านได้** (ไม่ minify/obfuscate) และตรงกับซอร์สในรีโป
- [ ] README มีหัวข้อ "สิทธิ์และข้อมูล" ที่ตรงกับโค้ดจริง

### ง. พฤติกรรมในโปรแกรม

- [ ] ไม่มีอะไรโผล่เองตอนโหลดหรือระหว่างพิมพ์
- [ ] ไม่แตะ DOM ของตัวแก้ไข
- [ ] ไม่ทำให้โปรแกรมหน่วง: ไม่มีงานซิงก์ยาว · ไม่มี observer บน DOM ของโปรแกรม · ตัวจับเวลา ≥ 1 วินาที
- [ ] ทำงานถูกเมื่อ: ไม่มีผลงานเปิด · ไม่มีเอกสารเปิด · แท็บเป็น Wiki · เปลี่ยนผลงาน · ผลงานใหญ่
- [ ] ข้อผิดพลาดถูกบอกผู้ใช้เป็นภาษาคน และจดรายละเอียดลง Log
- [ ] ประกาศ `hotReload` เฉพาะเมื่อเก็บกวาดครบจริง (ทดสอบตาม [11.3](11-debugging-testing.md#113-ตรวจว่าเก็บกวาดครบ))
- [ ] คีย์ลัดไม่ชนกับของโปรแกรม และทุกคีย์ลัดมีคำสั่งคู่กัน

### จ. หน้าตาและการเข้าถึง ([บทที่ 5](05-ui-guidelines.md))

- [ ] อ่านออกในธีมมืด · สว่าง · คอนทราสต์สูง
- [ ] ตามขนาด UI 75–200%
- [ ] ใช้ได้ด้วยคีย์บอร์ด · มีวงโฟกัส · ปุ่มไอคอนมีป้าย
- [ ] ไม่บอกสถานะด้วยสีอย่างเดียว
- [ ] ข้อความอย่างน้อยไทยและอังกฤษ (ตามภาษาของหน้าจอ)

### ฉ. ความเข้ากันได้และการดูแล

- [ ] ทดสอบกับ Killian 2 รุ่นล่าสุด และรุ่นที่ระบุใน `minAppVersion`
- [ ] ทดสอบบน Windows (และ macOS/Linux ถ้าทำได้) — โดยเฉพาะทางไฟล์และคีย์ลัด
- [ ] ข้อมูลที่เก็บมีเลขรุ่น และมีตัวแปลงจากรุ่นเก่า
- [ ] มีช่องทางรายงานปัญหา และผู้เขียนตอบ

## 9.8 ทำไมยังไม่มีร้าน (ข้อเท็จจริงของรุ่นนี้)

ร้านปลั๊กอินที่ปลอดภัยต้องมีของหลายอย่างที่ระบบปลั๊กอินรุ่นนี้ยังไม่มี — ระบุไว้เพื่อให้ผู้เขียนเข้าใจข้อจำกัด **ไม่ใช่แผนงานหรือคำมั่น**:

| ที่ต้องมี | สถานะในรุ่น alpha.169 |
|---|---|
| ขอบเขตสิทธิ์ที่บังคับใช้ได้ (แซนด์บ็อกซ์) | ไม่มี — ปลั๊กอินรันด้วยสิทธิ์เต็มของหน้าต่าง |
| การยืนยันว่าไฟล์ที่ติดตั้งคือไฟล์ที่ผู้เขียนปล่อย (ลงนาม/checksum) | ไม่มี |
| ตัวตนของปลั๊กอินที่แยกจากชื่อโฟลเดอร์ | ไม่มี — ชื่อโฟลเดอร์คือตัวตน |
| การตรวจและแจ้งอัปเดต | ไม่มี |
| API ที่ประกาศความเสถียร | ยังเป็น alpha |
| ที่เก็บค่าตั้งระดับผู้ใช้สำหรับปลั๊กอิน | ไม่มี (ค่าตั้งและการเปิด/ปิดจำต่อผลงาน) |

ระหว่างนี้ ความน่าเชื่อถือของปลั๊กอินมาจากสิ่งที่ผู้เขียนทำเอง: ซอร์สที่อ่านได้ · README ที่บอกตรง · ประวัติรุ่นที่เป็นระเบียบ · การตอบปัญหา
