# ภาคผนวก D — โครงโฟลเดอร์และรูปแบบไฟล์

**ภาษา:** ไทย · [English](../en/D-file-formats.md)

[← กลับสารบัญคู่มือ](README.md)

> ใช้กับรุ่น **2.0.0-alpha.170** · โปรเจกต์ของ Killian เป็นโฟลเดอร์ของไฟล์ข้อความล้วน (`.md` + `.json`) — เอกสารนี้อธิบายสิ่งที่คุณจะเห็นเมื่อเปิดโฟลเดอร์ด้วยตัวจัดการไฟล์
> ไฟล์ที่ทำเครื่องหมาย ⚠ เป็นไฟล์ทะเบียนที่โปรแกรมดูแลเอง — **แก้ด้วยมือได้แต่ต้องระวัง** (ปิดโปรแกรมก่อน และสำรองไว้) ถ้าทำพัง ใช้ **เครื่องมือ → ตรวจสุขภาพโปรเจกต์**

## โครงโฟลเดอร์ของโปรเจกต์

```
นิยายของฉัน/                          ← โฟลเดอร์โปรเจกต์
├─ project.khn.json                ⚠ ตัวโปรเจกต์: ชื่อ · ค่าตั้งของผลงาน · เวิร์กโฟลว์ · ดัชนีต่าง ๆ
├─ templates.json                     เทมเพลตของหมวด Wiki (แก้เองได้)
├─ dictionary.json                    คำที่เพิ่มลงพจนานุกรมของโปรเจกต์
├─ ai-key.json                        คีย์ API ของผู้ให้บริการ AI — ห้ามแชร์
├─ maps.json · timeline.json          แผนที่ · เหตุการณ์บนเส้นเวลา
│
├─ เล่มหนึ่ง/                          ← เล่ม (ชื่อโฟลเดอร์ = ชื่อเล่ม)
│   ├─ section.json                ⚠ ข้อมูลของเล่ม (รหัส · ชื่อ · ลำดับ · ร่างหลัก)
│   ├─ roster.json                    หน้ารายชื่อตัวละครของเล่ม
│   └─ Draft/
│       └─ default/                ← ฉบับร่าง
│           ├─ draft.json          ⚠ รายการบท (ลำดับ · ชื่อ · โฟลเดอร์)
│           ├─ scenes.json         ⚠ รายการฉากของแต่ละบท (ดัชนี)
│           └─ Chapters/
│               └─ บทที่หนึ่ง/        ← โฟลเดอร์ของบท
│                   ├─ ฉากเปิด.md    ← ฉาก (เนื้อเรื่อง + คุณสมบัติในหัวไฟล์)
│                   └─ …
│
├─ Memos/                             บันทึกช่วยจำ (.md)
├─ Wiki/
│   ├─ characters/  locations/  items/  lore/  <หมวดที่ตั้งเอง>/
│   │   └─ โทระ.json                 เอนทิตี้หนึ่งหน้า
├─ Images/                            คลังรูป (+ images.json ดัชนี/อัลบั้ม/แท็ก)
├─ Fonts/                             ไฟล์ฟอนต์ที่นำเข้าไว้กับโปรเจกต์
├─ Models/                            โมเดล 3 มิติของ Story Network
├─ Planners/                          กระดานวางแผน (ไฟล์ .json ต่อใบ)
├─ Branches/                          แผนของผังแตกสาย
├─ FloorPlans/                        ผังพื้นที่
├─ OnSet/                             ฉบับเดิมของ "ฉากมีปัญหา"
├─ Starters/                          เรื่องของ Story Starter (โฟลเดอร์ต่อเรื่อง)
├─ Sessions/                          เซสชันแชท AI
├─ Analysis/ · Dialogues/             ผล AI วิเคราะห์ · เซสชันห้องซ้อมบท
├─ Skills/                            ทักษะของ AI (.md ที่คุณเขียน)
├─ References/                        ไฟล์อ้างอิงของ Agent
├─ Research/                          ข้อมูลค้นคว้า (ไม่ถูกสำรองอัตโนมัติ)
├─ languages/                         คำแปลเฉพาะผลงานนี้ (k2_<ภาษา>.csv)
├─ Plugins/                           ปลั๊กอินของผลงาน + Plugins/dictionaries/*.txt
│
├─ Snapshots/                         ประวัติเวอร์ชันของไฟล์
├─ .k2history/                        ประวัติการทำงาน (ย้อนกลับ)
├─ Recycle/                           ถังขยะ
```

ชื่อโฟลเดอร์ชั้นบนต่อไปนี้ **สงวนไว้ให้โปรแกรม** ตั้งเป็นชื่อเล่มไม่ได้ (ไม่สนตัวพิมพ์):
`Wiki` `Bible` `Images` `Memos` `Research` `Snapshots` `.k2history` `Plugins` `Recycle` `Sessions` `Starters` `Planners` `Branches` `FloorPlans` `OnSet` `References` `Models` `Backups` `Draft` `languages` `Analysis` `Dialogues` `Fonts` `Skills` `.git`

**โฟลเดอร์ไหนลบได้โดยงานไม่หาย**: `Snapshots/` `.k2history/` `Backups/` `Recycle/` (เสียแค่ความสามารถย้อนกลับ/กู้คืน) · `Sessions/` `Analysis/` `Dialogues/` (เสียประวัติแชท/ผลวิเคราะห์)

## ไวยากรณ์ของไฟล์ฉาก (`.md`)

ไฟล์ฉากมีสามส่วน: **หัวไฟล์** · **เนื้อเรื่อง** · **บล็อกคอมเมนต์** (ถ้ามี)

```markdown
---
title: ตลาดเก่ายามค่ำ
type: scene
format: prose
pov: โทระ
synopsis: โทระเจอแมวดำที่ตลาดเก่า และได้ยินเสียงเรียกชื่อตัวเองจากตรอกมืด
tags: [เปิดเรื่อง]
modified: 2026-10-11T16:18:31.844Z
appVersion: 2.0.0-alpha.170
revision: 2
---
ค่ำคืนนั้น โทระยืนอยู่ที่ตลาดเก่า…

<!-- k2-comments
…ข้อมูลเธรดคอมเมนต์ของฉากนี้ (โปรแกรมเขียนเอง)…
-->
```

### หัวไฟล์ (frontmatter)

| คีย์ | ความหมาย |
|---|---|
| `title` | ชื่อฉาก |
| `type` | `scene` หรือ `memo` |
| `format` | `prose` (นิยาย) หรือ `screenplay` (บทภาพยนตร์) |
| `synopsis` · `pov` · `emotion` · `conflict` | เรื่องย่อ · ผู้เล่า · อารมณ์ · ความขัดแย้ง |
| `note` · `futureNote` | โน้ตของนักเขียน |
| `tags` | `[แท็ก1, แท็ก2]` |
| `storyDate` | เวลาในเรื่อง (ข้อความอิสระ) |
| `isFlashback` · `isFlashforward` | ธงย้อนอดีต/ไปอนาคต |
| `modified` · `appVersion` · `revision` | โปรแกรมเขียนเอง |

คุณสมบัติ "หนัก" ข้างบนมี **หัวไฟล์เป็นแหล่งความจริง** — `scenes.json` เป็นแค่ดัชนี แก้หัวไฟล์จากนอกโปรแกรมแล้วใช้ **เครื่องมือ → ซิงก์คุณสมบัติฉากจากไฟล์ .md**

### เนื้อเรื่อง — โหมดนิยาย

| เขียน | ได้ |
|---|---|
| `**ข้อความ**` | **ตัวหนา** |
| `*ข้อความ*` | *ตัวเอียง* |
| `***ข้อความ***` | ตัวหนา + เอียง |
| `_ข้อความ_` | ขีดเส้นใต้ ⚠ (ต่างจากมาร์กดาวน์ทั่วไปที่เป็นตัวเอียง) |
| `~~ข้อความ~~` | ขีดฆ่า |
| `^ข้อความ^` | ตัวยก |
| `~ข้อความ~` | ตัวห้อย |
| `<span style="color:#rrggbb">ข้อความ</span>` | สีตัวอักษร |
| `# ` … `###### ` | หัวข้อระดับ 1–6 |
| `> ข้อความ` | คำพูดยกมา |
| `- ข้อ` หรือ `* ข้อ` | รายการหัวข้อย่อย |
| `1. ข้อ` | รายการตัวเลข |
| `---` (บรรทัดเดี่ยว) | เส้นคั่น |
| ` ``` ` … ` ``` ` | บล็อกโค้ด |
| `\` ท้ายบรรทัด | ขึ้นบรรทัดใหม่ในย่อหน้าเดิม |
| `<!--pagebreak-->` (บรรทัดเดี่ยว) | บังคับขึ้นหน้าใหม่ |
| `<!--align:center-->` | การจัดหน้าของย่อหน้า (`left` `center` `right` `justify`) — โปรแกรมเขียนให้ |
| `![คำบรรยาย](Images/a.png)` (ทั้งบรรทัด) | รูปประกอบ |
| `![คำบรรยาย](Images/a.png "fit=page w=60% r=8")` | ตัวเลือกของรูป: `fit=page` เต็มหน้า · `w=` ความกว้าง % (1–100) · `r=` ขอบมน px (0–200) |
| `ข้อความ ![](Images/i.png "h=2") ข้อความ` | รูปกลางย่อหน้า — `h=` ความสูงเป็นจำนวนบรรทัด |
| `[[ชื่อ]]` · `[[ชื่อ\|ข้อความที่แสดง]]` | ลิงก์ไปหน้า Wiki |
| `[title]` `[date:iso]` … | โค้ดสั้น (แทนค่าตอนส่งออก) · `[[title]]` = ตัวอักษรจริง |
| `{{ชื่อ.ฟิลด์}}` | ตัวแปรจาก Wiki (แทนค่าตอนส่งออก) |
| `[ข้อความไทย]` | ทางเลือกของเรื่องแตกสาย |
| `%%…%%` · `<!-- … -->` | คอมเมนต์ในเนื้อ (ตัดออกได้ตอนส่งออก) |

เครื่องหมายที่จับคู่ไม่ได้ (เช่น `*` ตัวเดียว) คงเป็นตัวอักษรธรรมดา ย่อหน้าคั่นด้วยบรรทัดว่าง

### เนื้อเรื่อง — โหมดบทภาพยนตร์

หนึ่งบรรทัด = หนึ่ง element ระบุด้วยรหัสนำหน้า:

```markdown
### EXT. ท่าน้ำ - กลางคืน

หมอกลงจัด โทระยืนอยู่ปลายท่า

@โทระ
((กระซิบ))
ออกมาเถอะ ฉันรู้ว่าแกอยู่ตรงนั้น

@หมอผีดำ (O.S.)
เด็กร้านขนมปัง… มาไกลบ้านเกินไปแล้ว

! CLOSE ON ตะเกียงวิญญาณ

>> CUT TO:
```

| รหัส | element |
|---|---|
| `### ` | หัวฉาก |
| (ไม่มีรหัส) | บรรยาย — หรือบทพูด ถ้าอยู่ใต้ตัวละคร |
| `@ชื่อ` · `@ชื่อ (V.O.)` | ตัวละคร (+ ส่วนเสริม) |
| `((ข้อความ))` | วงเล็บ (ต้องอยู่ติดใต้ตัวละคร) |
| `>> ` | ทรานซิชันออก (ชิดขวา) |
| `<< ` | ทรานซิชันเข้า (ชิดซ้าย) |
| `! ` (มีวรรค) | ช็อต |
| `#### ` | ฉากย่อย |
| `$intercut ` | สลับฉาก |
| `$act ` | ตอน (ตัวแบ่งองก์) |
| `---` | ขึ้นหน้าใหม่ |
| `/// ` | โน้ต |
| `= ` | สรุป |
| `# ` · `## ` · `##### ` | โครง 1 · 2 · 3 |
| `$contl ` · `$contr ` | ต่อเนื่อง (ซ้าย/ขวา) |
| `![alt](src)` | รูป |

- บรรทัดว่างคั่นบล็อก — บทพูดจบที่บรรทัดว่าง
- `!ข้อความ` (ไม่มีวรรค) = บังคับเป็นบรรยาย
- รหัสของ Killian v1 (`.หัวฉาก` · `>ทรานซิชัน` · `$shot ` · `$sub ` · `$in `) ยังอ่านได้ และถูกบันทึกกลับด้วยรหัสใหม่

## ไฟล์ทะเบียนของเล่ม

**`section.json`** — หนึ่งไฟล์ต่อเล่ม

```json
{ "guid": "s1", "title": "เล่มหนึ่ง", "order": 1, "folderName": "เล่มหนึ่ง", "primaryDraft": "default" }
```

**`draft.json`** — รายการบทของฉบับร่าง

```json
{ "chapters": [
  { "guid": "c1", "title": "ตลาดยามค่ำ", "order": 1, "folderName": "ตลาดยามค่ำ",
    "status": "Outline", "act": "I", "date": "", "isFavorite": false }
] }
```

**`scenes.json`** — รายการฉาก จัดกลุ่มตามรหัสบท

```json
{ "chapters": { "c1": [
  { "id": "sc1", "title": "ตลาดเก่ายามค่ำ", "order": 1, "fileName": "ตลาดเก่ายามค่ำ.md",
    "status": "ตรวจแล้ว", "wordCount": 1800,
    "choices": [ { "text": "ตามแมวไป", "nextSceneId": "sc3" } ] }
] } }
```

| ของ | ตัวตน (ไม่เปลี่ยน) | ลำดับ | ชื่อบนดิสก์ |
|---|---|---|---|
| เล่ม | `guid` ใน section.json | `order` | ชื่อโฟลเดอร์ = `folderName` |
| บท | `guid` ใน draft.json | `order` | `folderName` |
| ฉาก | `id` ใน scenes.json | `order` | `fileName` |

- **ลำดับอยู่ในช่อง `order` ไม่ได้อยู่ในชื่อไฟล์**
- `choices` = ทางเลือกของเรื่องแตกสาย (`nextSceneId` ชี้ `id` ของฉากปลายทาง)
- ค่าสถานะ (`status`) เก็บเป็นข้อความตามที่ตั้งไว้ ไม่แปลตามภาษาของหน้าจอ

## Wiki และ `templates.json`

**เอนทิตี้** — `Wiki/<หมวด>/<ชื่อ>.json`

```json
{
  "name": "โทระ",
  "entityTypeKey": "characters",
  "aliases": ["เจ้าหนูร้านขนมปัง"],
  "tags": ["ตัวเอก"],
  "fields": { "Age": "19", "Role": "ผู้ช่วยร้านขนมปัง" },
  "relationships": [
    { "targetName": "แคสซี่", "role": "คนรัก", "type": "romantic" }
  ],
  "images": []
}
```

- `entityTypeKey` = ชื่อโฟลเดอร์ของหมวดใน `Wiki/`
- ประเภทความสัมพันธ์ (`type`): `family` (ครอบครัว) · `romantic` (คนรัก) · `ally` (พันธมิตร) · `rival` (คู่แข่ง) · `enemy` (ศัตรู) · `mentor` (ผู้สอน/อาจารย์) · `acquaintance` (รู้จัก) · `neutral` (เป็นกลาง) · `custom` (อื่น ๆ) — `role` คือข้อความบทบาทอิสระที่แสดงบนเส้น
- หน้าเอนทิตี้ยังเก็บ: หัวข้อข้อความยาว · ช่องที่เพิ่มเอง · คำสั่งสำหรับ AI · โค้ดสั้น · รูป (ชื่อไฟล์ + คำบรรยาย)

**`templates.json`** — เทมเพลตของแต่ละหมวด

```json
{
  "version": 1,
  "templates": [
    { "id": "…", "entityTypeKey": "characters", "name": "ตัวละคร — ค่าเริ่มต้น",
      "fields": [
        { "key": "Age",      "label": "อายุ",     "type": "String", "defaultValue": "" },
        { "key": "Birthday", "label": "วันเกิด",  "type": "Date",   "defaultValue": "" }
      ] }
  ]
}
```

ชนิดของช่อง (`type`): `String` `Text` `Int` `Bool` `Date` `Enum` `EntityRef` — แก้ไฟล์นี้ด้วยโปรแกรมแก้ข้อความได้เลย เพิ่ม/ลบ/แก้ช่องและหัวข้อได้ทุกจุด

## ไฟล์อื่นที่ควรรู้จัก

| ไฟล์ | รูปแบบ | หมายเหตุ |
|---|---|---|
| `project.khn.json` ⚠ | JSON: `title` · `type: "killian-project"` · `settings` (ค่าของผลงาน + ค่าของปลั๊กอิน `settings.plugins`) · `goals` · `ai` (ผู้ให้บริการ **ไม่รวมคีย์** · Agent) · `compileWorkflows` · `backlinks` · `wordHistory` · `navMarks` · `explorer` (ดาว/หมุด/ล็อกของของที่ไม่มีหัวไฟล์) · `titlePages` … | โฟลเดอร์ที่มีไฟล์นี้ = โปรเจกต์ |
| `ai-key.json` | คีย์ API ต่อ Credential | **ห้ามแชร์/คอมมิต** · ไม่อยู่ในชุดสำรองและ ZIP ของโปรแกรม |
| `dictionary.json` | `{ "words": ["คำ", …] }` | คำที่เพิ่มลงพจนานุกรม |
| `Plugins/dictionaries/*.txt` | บรรทัดละคำ · `#` = คอมเมนต์ | คลังคำเสริมของตัวตรวจคำผิด |
| `Skills/*.md` | มาร์กดาวน์ (+ หัวไฟล์ `name` `description` ไม่บังคับ) | ทักษะของ AI |
| `languages/k2_<ภาษา>.csv` | `คีย์,ข้อความ` | คำแปลเฉพาะผลงาน |
| `Recycle/…` + `.k2restore.json` | ไฟล์ที่ลบ + ใบกู้คืน | ใบกู้คืนบอกว่าของมาจากไหน |
| `<ชื่อ>.unreadable-<เวลา>.json` | สำเนาของไฟล์ JSON ที่อ่านไม่ออก | โปรแกรมสร้างเมื่อเจอไฟล์เสีย — เปิดดู/ซ่อมมือได้ |

## ความเข้ากันได้
