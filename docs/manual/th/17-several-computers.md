# 17. ใช้หลายเครื่อง (Google Drive · iCloud · Dropbox · OneDrive)

**ภาษา:** [English](../en/17-several-computers.md) · ภาษาไทย

โปรเจกต์ของ Killian คือโฟลเดอร์ธรรมดาที่มีไฟล์ `.md` กับ `.json` โปรแกรมไม่มีเซิร์ฟเวอร์ของตัวเอง ถ้าจะเขียนทั้งบนโน้ตบุ๊กและคอมตั้งโต๊ะ ให้เก็บโฟลเดอร์โปรเจกต์ไว้ในโฟลเดอร์ที่บริการซิงก์คัดลอกระหว่างเครื่องให้อยู่แล้ว

## 17.1 ย้ายโปรเจกต์เข้าโฟลเดอร์ที่ซิงก์

1. ติดตั้งโปรแกรมซิงก์ที่เลือกบน **ทุกเครื่อง** และเข้าสู่ระบบด้วยบัญชีเดียวกัน

| บริการ | โฟลเดอร์อยู่ที่ไหน | ค่าที่ต้องตั้ง |
|---|---|---|
| Google Drive สำหรับเดสก์ท็อป | `My Drive` (เป็นไดรฟ์บน Windows · อยู่แถบข้างของ Finder บน macOS) | เลือก **Mirror files** หรือคลิกขวาที่โฟลเดอร์โปรเจกต์ → **การเข้าถึงแบบออฟไลน์ → ใช้งานแบบออฟไลน์ได้** |
| iCloud Drive | macOS: Finder → iCloud Drive · Windows: โปรแกรม iCloud สำหรับ Windows | macOS: ปิด **เพิ่มประสิทธิภาพพื้นที่จัดเก็บ Mac** หรือคลิกขวาที่โฟลเดอร์ → **เก็บไว้ที่ดาวน์โหลด** |
| Dropbox | โฟลเดอร์ `Dropbox` | คลิกขวาที่โฟลเดอร์ → **ทำให้พร้อมใช้งานออฟไลน์** |
| OneDrive | โฟลเดอร์ `OneDrive` | คลิกขวาที่โฟลเดอร์ → **เก็บไว้บนอุปกรณ์นี้เสมอ** |

   โปรแกรมอ่านและเขียนไฟล์บนดิสก์ตรง ๆ ไฟล์จึงต้องอยู่ในเครื่องจริง ไม่ใช่ไฟล์ที่ "อยู่บนคลาวด์อย่างเดียว"

2. ปิด Killian (หรือเปิดโปรเจกต์อื่น) เพื่อไม่ให้มีอะไรกำลังเขียนลงโฟลเดอร์
3. ในโปรแกรมจัดการไฟล์ **ย้าย** โฟลเดอร์โปรเจกต์ทั้งโฟลเดอร์เข้าไปในโฟลเดอร์ที่ซิงก์
4. ใน Killian: **ไฟล์ → เปิดโปรเจกต์…** แล้วเลือกโฟลเดอร์ที่ที่อยู่ใหม่ รายการ *โปรเจกต์ล่าสุด* จะจำที่อยู่ใหม่ให้

## 17.2 เปิดที่อีกเครื่อง

1. รอให้โปรแกรมซิงก์บอกว่าซิงก์เสร็จแล้ว (มีเครื่องหมายถูกที่ไอคอนโฟลเดอร์)
2. **ไฟล์ → เปิดโปรเจกต์…** → เลือกโฟลเดอร์เดียวกันในโฟลเดอร์ที่ซิงก์

หลักง่าย ๆ: **เปิดทีละเครื่อง** ปิดโปรแกรม (หรือเปิดโปรเจกต์อื่น) ก่อนลุกจากเครื่อง และรอให้ซิงก์เสร็จก่อนเปิดที่อีกเครื่อง

## 17.3 "โปรเจกต์นี้ยังเปิดอยู่ที่เครื่องอื่น"

ระหว่างที่เปิดโปรเจกต์ Killian จะเก็บไฟล์เล็ก ๆ `.k2lock.json` ไว้ในโฟลเดอร์โปรเจกต์ บอกว่าเครื่องไหนกำลังเปิดอยู่ และอัปเดตทุกสองนาที โปรแกรมซิงก์จะพาไฟล์นี้ไปที่เครื่องอื่นด้วย

ถ้าเปิดโปรเจกต์ที่อีกเครื่องขณะที่เครื่องแรกยังเปิดค้าง Killian จะเตือนก่อน

- **ยกเลิก** — กลับไปปิดโปรแกรมที่เครื่องนั้น รอซิงก์ แล้วค่อยเปิดใหม่
- **เปิดต่อที่นี่** — ใช้เมื่อรู้ว่าเครื่องนั้นปิดไปแล้ว หรือปิดโปรเจกต์แล้วแต่ยังซิงก์ไม่ทัน

ล็อกจะถูกลบเมื่อเปิดโปรเจกต์อื่นหรือปิดโปรแกรม ถ้าเครื่องดับหรือพักเครื่องไปทั้งที่ยังเปิดโปรเจกต์ ล็อกของเครื่องนั้นจะหมดอายุเองใน 10 นาที หลังจากนั้น Killian จะแค่ขึ้นข้อความสั้น ๆ ว่าครั้งล่าสุดโปรเจกต์เปิดอยู่ที่เครื่องไหน เพื่อเตือนให้ตรวจว่าซิงก์ครบแล้ว

ไฟล์ล็อกไม่ถูกใส่ใน ZIP ที่ส่งออกหรือในชุดสำรอง

## 17.4 เมื่อบริการซิงก์ทำสำเนาไว้

ถ้าฉากเดียวกันถูกแก้ทั้งสองเครื่องก่อนจะซิงก์ บริการซิงก์จะเก็บไว้ทั้งสองฉบับ แล้วเปลี่ยนชื่อฉบับหนึ่ง เช่น

| บริการ | หน้าตาของสำเนา |
|---|---|
| Dropbox | `ฝน (conflicted copy).md` · `ฝน (Laptop's conflicted copy 2026-10-23).md` |
| Google Drive | `ฝน (1).md` |
| OneDrive | `ฝน-LAPTOP.md` |
| iCloud | `ฝน 2.md` |
| Syncthing | `ฝน.sync-conflict-20261023-101500-ABCDEFG.md` |

สำเนาแบบนี้ไม่ขึ้นใน Explorer เอง เพราะไม่มีบทไหนอ้างถึง **เครื่องมือ → ตรวจสุขภาพโปรเจกต์** จะหาเจอและบอกว่าเป็นสำเนาของฉากไหน วิธีจัดการ

1. ในกล่องตรวจสุขภาพ ติ๊กสำเนานั้นแล้วกด **ซ่อมรายการที่เลือก** สำเนาจะกลายเป็นฉากข้างฉากต้นฉบับ
2. เปิดทั้งสองฉากเทียบกัน (แยกจอ) แล้วเก็บข้อความที่ต้องการไว้ในฉากใดฉากหนึ่ง
3. ลบอีกฉากทิ้ง (ไปอยู่ในถังขยะ ยังกู้คืนได้)

## 17.5 อ่านหรือแก้เล็กน้อยบนมือถือ

ตอนนี้ Killian ยังไม่มีแอปบนมือถือ แต่ฉากเป็นไฟล์ Markdown ธรรมดา แอป Markdown ที่เปิดโฟลเดอร์จากบริการซิงก์ได้ (เช่น Obsidian หรือ iA Writer) จึงอ่านและแก้ได้ ใช้หลักเดียวกัน คือปิด Killian ที่คอมก่อน แล้วเมื่อกลับมา Killian จะเห็นไฟล์ที่ถูกแก้เอง (ดู [10.7 เมื่อไฟล์ถูกแก้จากนอกโปรแกรม](10-history-backup.md#107-เมื่อไฟล์ถูกแก้จากนอกโปรแกรม)) แก้แค่ข้อความ อย่าเปลี่ยนชื่อหรือย้ายไฟล์บนมือถือ

## 17.6 ควรรู้

- ประวัติเวอร์ชัน (`.k2history`) และชุดสำรอง (`Backups`) อยู่ในโฟลเดอร์โปรเจกต์ จึงถูกซิงก์ไปด้วยและกินพื้นที่บนคลาวด์ ถ้าพื้นที่ไม่พอ ลดค่า **ตั้งค่า → บันทึกและสำรอง → จำนวนเวอร์ชันอัตโนมัติสูงสุด**
- แชร์โปรเจกต์ให้ *คนอื่น* ผ่านโฟลเดอร์แชร์ก็ใช้หลักเดียวกัน แต่เปิดได้ทีละคน ถ้าทำงานกับบรรณาธิการที่ใช้ Word ดู [ทำงานกับบรรณาธิการผ่าน Word](04-writing-novel.md#ทำงานกับบรรณาธิการผ่าน-word)
