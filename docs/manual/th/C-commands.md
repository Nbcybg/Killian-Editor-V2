# ภาคผนวก C — คำสั่งทั้งหมด

**ภาษา:** ไทย · [English](../en/C-commands.md)

> สร้างจากข้อมูลของโปรแกรมรุ่น **2.0.0-alpha.release.2** (ภาษาไทย · ค่าเริ่มต้น) — ชื่อเมนูและคีย์ลัดบนเครื่องของคุณอาจต่างไปตามภาษาที่เลือกและคีย์ลัดที่ตั้งเอง
> บน macOS: `Ctrl` = `⌘` · `Alt` = `⌥`

[← กลับสารบัญคู่มือ](README.md)

ทุกอย่างที่กดได้ในโปรแกรม (เมนู · ปุ่ม · คีย์ลัด · ปุ่มลอย) เรียก "คำสั่ง" ตัวเดียวกัน ตารางนี้คือทะเบียนคำสั่งทั้งหมดพร้อมคำอธิบายที่โปรแกรมแสดงในทูลทิป

- **รหัสคำสั่ง** คือชื่อภายในของคำสั่ง — เห็นได้ในบันทึกการทำงาน (Log) บรรทัด `cmd:` และใช้อ้างอิงเวลารายงานบั๊ก
- รหัสที่มี `:` คือคำสั่งพร้อมค่า เช่น `zoom:1` = ซูมเข้าหนึ่งขั้น · `toggle-panel:kanban` = เปิด/ปิดแผง Kanban
- คำสั่งที่ช่องคีย์ลัดว่าง = ไม่มีคีย์ลัดตั้งต้น (เรียกจากเมนูหรือปุ่ม)
- รหัสขึ้นต้น `ui:` คือปุ่มบนแถบที่ไม่มีรายการในเมนู

## สร้างของใหม่

| รหัสคำสั่ง | คีย์ลัดตั้งต้น | ทำอะไร |
|---|---|---|
| `chapter` | `Ctrl+Alt+1` | สร้างบทใหม่ในเล่มที่เลือก แล้วเปิดให้เริ่มเขียนทันที บทคือกล่องที่รวมหลายฉากไว้ด้วยกัน |
| `character` | `Ctrl+Alt+3` | สร้างหน้าตัวละครใหม่ใน Wiki จากเทมเพลตของหมวดตัวละคร ไว้จดข้อมูลที่ต้องอ้างอิงระหว่างเขียน |
| `location` | `Ctrl+Alt+4` | สร้างหน้าสถานที่ใหม่ใน Wiki จากเทมเพลตของหมวดสถานที่ ไว้จดบรรยากาศและรายละเอียดของฉากหลัง |
| `memo` | `Ctrl+Alt+5` | สร้างบันทึกช่วยจำ (Memo) ในโปรเจกต์ ไว้จดไอเดีย ข้อมูลค้นคว้า หรือสิ่งที่ยังไม่รู้จะใส่ตรงไหน โดยไม่ปนกับต้นฉบับ |
| `new-entity:characters` |  | สร้างหน้าตัวละครใหม่ใน Wiki จากเทมเพลตของหมวดตัวละคร |
| `new-entity:items` |  | สร้างหน้าสิ่งของใหม่ใน Wiki เช่น อาวุธ ของวิเศษ หรือของสำคัญที่ตัวละครถือครอง |
| `new-entity:locations` |  | สร้างหน้าสถานที่ใหม่ใน Wiki จากเทมเพลตของหมวดสถานที่ |
| `new-entity:lore` |  | สร้างหน้าตำนานหรือความรู้ของโลกในเรื่องใน Wiki เช่น ประวัติศาสตร์ ศาสนา หรือกฎของเวทมนตร์ |
| `quick-note` | `Ctrl+Shift+Q` | จดความคิดที่เพิ่งผุดขึ้นไว้ก่อนโดยไม่ต้องออกจากฉากที่กำลังเขียน โน้ตทั้งหมดรวมอยู่ในแผงสมุดโน้ต |
| `scene` | `Ctrl+Alt+2` | สร้างฉากใหม่ในบทที่เลือก ฉากคือหน่วยเล็กที่สุดของเรื่อง แต่ละฉากเป็นไฟล์ .md ของตัวเอง |
| `scratchpad` |  | เปิดสมุดโน้ตด่วนสำหรับจดความคิดชั่วคราว ไม่ปนกับต้นฉบับ |
| `new-entity` |  | สร้างหน้า Wiki ใหม่ในหมวดที่เลือก จากเทมเพลตของหมวดนั้น |

| `ai-summary` |  | ให้ AI สรุปเนื้อหาของทั้งโปรเจกต์ ใช้ทบทวนเรื่องหรือเตรียมเรื่องย่อ |
| `ai-title` |  | ให้ AI เสนอชื่อเรื่องจากเนื้อหา เลือกแล้วตั้งเป็นชื่อโปรเจกต์ได้ทันที |
| `ai-world` |  | ให้ AI ช่วยสร้างรายละเอียดโลกของเรื่อง เช่น ภูมิศาสตร์ วัฒนธรรม และประวัติ แล้วบันทึกเป็นหน้า Wiki ได้ |
