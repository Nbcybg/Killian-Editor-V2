## โครงของผลงาน

| คำ | ความหมาย | ดูเพิ่ม |
|---|---|---|
| **โปรเจกต์ / ผลงาน** (Project) | โฟลเดอร์หนึ่งใบที่มีไฟล์ `project.khn.json` — งานหนึ่งเรื่องทั้งชุด | [1](01-getting-started.md) |

| **ฉบับร่าง** (Draft) | สำเนาโครงของเล่มสำหรับลองแก้ · เล่มหนึ่งมี "ร่างหลัก" หนึ่งร่าง | [3.9](03-project-structure.md#39-ฉบับร่าง-draft) |
| **บท** (Chapter) | กล่องรวมฉาก | |
| **ฉาก** (Scene) | หน่วยเล็กที่สุดของเรื่อง = ไฟล์ `.md` หนึ่งไฟล์ | |
| **Memo / บันทึกช่วยจำ** | ไฟล์โน้ตของโปรเจกต์ที่ไม่ใช่ต้นฉบับ | [3.11](03-project-structure.md#311-memo) |
| **หัวไฟล์** (Frontmatter) | ส่วน `--- … ---` ต้นไฟล์ `.md` ที่เก็บคุณสมบัติของฉาก | [D](D-file-formats.md) |
| **ไฟล์ทะเบียน** | `section.json` `draft.json` `scenes.json` — บอกลำดับและชื่อของเล่ม/บท/ฉาก | [D](D-file-formats.md) |

| **สถานะ** (Status) | ขั้นของฉาก เช่น โครงร่าง · กำลังเขียน · เขียนเสร็จ · ตรวจแล้ว · เก็บถาวร | [3.6](03-project-structure.md#36-สถานะฉาก) |
| **องก์** (Act) | ช่วงใหญ่ของเรื่อง — เป็นคุณสมบัติของบท | |
| **เวลาในเรื่อง** (Story date) | เมื่อไรในโลกของเรื่อง (ไม่ใช่วันที่จริง) — ใช้วางฉากบนเส้นเวลา | |
