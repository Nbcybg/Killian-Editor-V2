## 16.1 ขั้นแรกเมื่อมีอะไรผิดปกติ

1. **อ่านแถบสถานะ** — ข้อความผิดพลาดค้างอยู่ที่นั่นจนมีข้อความใหม่
2. **เปิดแผงบันทึก (Log)** `Ctrl+Alt+9` — กรองระดับ "ผิดพลาด"
3. **บันทึกงาน** (`Ctrl+Alt+S`) ถ้ายังบันทึกได้ แล้วปิด-เปิดโปรแกรมใหม่
4. ถ้าเกี่ยวกับหน้าตา/แผง: **มุมมอง → แผง → รีเซ็ตการจัดวางแผงทั้งหมด**
5. ถ้าเกี่ยวกับไฟล์/โครงของโปรเจกต์: **เครื่องมือ → ตรวจสุขภาพโปรเจกต์**
6. ถ้าติดตั้งปลั๊กอินไว้: ปิดปลั๊กอินแล้วลองอีกครั้ง
7. ยังไม่หาย: **ช่วยเหลือ → รายงานบั๊ก…**

## 16.2 เปิดโปรแกรม / เปิดโปรเจกต์

| อาการ | สาเหตุและทางแก้ |
|---|---|
| Windows เตือนว่าไม่รู้จักผู้เผยแพร่ | กด More info → Run anyway (เมื่อโหลดจากหน้า Releases ทางการ) |
| macOS บอกว่าเปิดไม่ได้เพราะไม่รู้จักนักพัฒนา | ตัวโปรแกรมยังไม่ได้ลงนาม — คลิกขวาที่ไอคอน → Open → Open |
| เปิดช้าในครั้งแรก | ตัวพกพาแตกตัวเองลงโฟลเดอร์ชั่วคราวทุกครั้ง (~380 MB) — ตรวจที่ว่างของไดรฟ์ที่เก็บ `%TEMP%` |
| โปรเจกต์ขึ้นว่า **เปิดไม่ได้** บนหน้าแรก | โฟลเดอร์ถูกย้าย/ลบ/ไดรฟ์ไม่ได้ต่อ — เปิดด้วย **เปิดโปรเจกต์…** จากที่อยู่ใหม่ แล้ว **เอาออกจากรายการ** อันเก่า |
| "ไม่พบไฟล์โปรเจกต์ (project.khn.json)" | เลือกโฟลเดอร์ผิดชั้น — ต้องเลือกโฟลเดอร์ที่มีไฟล์ `project.khn.json` อยู่ข้างในโดยตรง |
| เปิดแล้วโปรแกรมบอกว่าไฟล์ทะเบียนอ่านไม่ออก | ไฟล์ JSON เสีย (ซิงก์ครึ่งไฟล์ · แก้มือพลาด) — โปรแกรมเก็บสำเนา `…unreadable-<เวลา>.json` ไว้ · กู้จาก `Backups/` หรือแผงประวัติการทำงาน |
| เปิดมาแล้วเป็นภาษาที่ไม่ได้เลือก | **ตั้งค่า → ภาษา** เลือกใหม่แล้วเริ่มโปรแกรมใหม่ (ภาษาเป็นค่าของผู้ใช้ ไม่ใช่ของโปรเจกต์) |
| แท็บที่เคยเปิดไม่กลับมา | ไฟล์ของแท็บนั้นถูกย้าย/เปลี่ยนชื่อตอนโปรแกรมปิดอยู่ — เปิดใหม่จาก Explorer |

## 16.3 หน้าจอและแผง

| อาการ | ทางแก้ |
|---|---|
| แผงหาย | **มุมมอง → แผง** เลือกแผงนั้น · หรือ `Ctrl+\` (อาจเผลอซ่อนทุกแผง) · หรือดูว่าแผงถูกฉีกไปเป็นหน้าต่างแยก (ปิดหน้าต่างนั้นเพื่อเอากลับ) |
| จัดแผงจนสับสน | **มุมมอง → แผง → รีเซ็ตการจัดวางแผงทั้งหมด** |
| แถบรูปแบบลอยหาย/ไปอยู่ที่แปลก ๆ | `Ctrl+Shift+/` เรียกมาที่เมาส์ · คลิกขวาที่หูจับ → รีเซ็ตทั้งหมด |
| แถบรูปแบบจางจนมองไม่เห็น | `Ctrl+Shift+'` วนความจางกลับเป็น 100% |
| ลากแถบรูปแบบไม่ได้ | ถูกล็อกอยู่ — `Ctrl+Shift+=` |
| ปุ่มบนแถบเครื่องมือหาย | **ตั้งค่า → แถบเครื่องมือ** → ติ๊กคืน หรือ **คืนค่าเริ่มต้น** · หน้าต่างแคบ = ดูในปุ่ม » |
| ปุ่มลอย + หาย | **มุมมอง → ปุ่มลอยมุมขวาล่าง (FAB)** |
| ตัวหนังสือของโปรแกรมเล็ก/ใหญ่ไป | **มุมมอง → ขนาด UI** (คนละอย่างกับซูมหน้ากระดาษ) |
| หน้ากระดาษเล็ก/ใหญ่ไป | `Ctrl+Shift+0` รีเซ็ตซูม · หรือ **พอดีความกว้างหน้ากระดาษ** |
| เห็นรหัส `###` `@` `>>` ในบท | **มุมมอง → ซ่อนรหัสนำหน้าบรรทัด** |
| ไม่เห็นฉากบางฉากใน Explorer | มีตัวกรองค้างอยู่ (ชิปสถานะ/แท็ก/ช่องกรอง) — ล้างตัวกรอง · ฉากสถานะ **เก็บถาวร** ถูกซ่อน: กดปุ่มเก็บถาวร · เลือกฉบับร่างผิดร่าง |
| ไอคอนเป็นกล่องสี่เหลี่ยม | ปิด-เปิดโปรแกรมใหม่ · ถ้ายังเป็น รายงานบั๊กพร้อมบอกว่าเห็นที่ไหน |
| โหมด 3D ของ Story Network ไม่ขึ้น/กระตุก | การ์ดจอ/ไดรเวอร์ไม่รองรับ WebGL — ใช้โหมด 2D |

## 16.4 การเขียน

| อาการ | ทางแก้ |
|---|---|
| คีย์ลัดไม่ทำงาน | ดูค่าปัจจุบันที่ **ช่วยเหลือ → ปุ่มลัดทั้งหมด…** (อาจถูกตั้งใหม่) · โปรแกรมอื่นของเครื่องอาจจองปุ่มนั้น (เช่น `Ctrl+Alt+…` ของการ์ดจอ/แป้นพิมพ์บางรุ่น) — ตั้งปุ่มใหม่ที่ ตั้งค่า → ปุ่มลัด |
| `Ctrl+Tab` ไม่สลับแท็บ | เคอร์เซอร์อยู่ในบทภาพยนตร์ (ที่นั่นใช้วน element) — ใช้ `Ctrl+PageDown` |
| คำไทยถูกขีดแดงทั้งที่ถูก | คลิกขวา → **เพิ่มลงพจนานุกรม** · คำเฉพาะจำนวนมาก: วางไฟล์คำใน `Plugins/dictionaries/` |
| ไม่มีเส้นขีดคำผิดเลย | **ตั้งค่า → ตัวแก้ไข → ตรวจคำผิด** และ **ใช้พจนานุกรมของโปรแกรม** ต้องเปิดทั้งคู่ |
| ชื่อจาก Wiki ไม่ถูกไฮไลต์ | **ตั้งค่า → ตัวแก้ไข → จับชื่อ Wiki อัตโนมัติ** · ชื่อต้องตรงกับชื่อหรือ "ชื่ออื่น" ของเอนทิตี้ |
| กล่อง SmartType เด้งชื่อที่ไม่ต้องการ | `Esc` ปิด · ชื่อที่จำผิด: **บทภาพยนตร์ → จัดการ SmartType** |
| แก้ฉากไม่ได้ | ฉาก (หรือบท/เล่มของมัน) ถูก **ล็อก** — ปลดล็อกจากคลิกขวา · หรือกำลังดู "ฉบับเดิม" ของฉากมีปัญหา (`Ctrl+Alt+Shift+O` กลับฉบับแก้ไข) |
| บรรยายในบทกลายเป็นชื่อตัวละคร/บทพูด | ดูชนิดที่ช่องเลือก element แล้วเปลี่ยนด้วย `Ctrl+2` (บรรยาย) · ตรวจตัวเลือก **บรรทัดถัดจากบทพูด = บทพูดต่อ** |
| จำนวนหน้าในบทไม่อัปเดต | เปิดมุมมอง **จัดหน้า** · หรือเปิด **ปรับหน้าใหม่อัตโนมัติ** (ตั้งค่า → รูปแบบบทภาพยนตร์) |
| วรรณยุกต์/สระไทยลอยหรือซ้อน | เปลี่ยนฟอนต์ไทยที่ **ตั้งค่า → ฟอนต์ตามภาษา** เป็นฟอนต์ที่รองรับไทยครบ |
| รูปไม่ขึ้น | ไฟล์รูปถูกย้าย/ลบออกจาก `Images/` — กู้จากถังขยะ หรือแทรกรูปใหม่ |

## 16.5 บันทึกและไฟล์

| อาการ | ทางแก้ |
|---|---|
| บันทึกไม่ผ่าน | อ่านข้อความบนแถบสถานะ — ดิสก์เต็ม · ไฟล์ถูกโปรแกรมอื่นล็อก (แอนตี้ไวรัส/ซิงก์) · ไม่มีสิทธิ์เขียน · งานยังอยู่ในแท็บ ลองใหม่ได้ |
| ถามว่าจะ "บันทึกทับ" หรือ "ใช้ฉบับบนดิสก์" | ไฟล์ถูกแก้จากนอกโปรแกรมขณะคุณมีงานค้าง — เลือกฉบับที่ต้องการ (ไม่แน่ใจ: **บันทึกเป็น…** ไฟล์ใหม่ก่อน) |
| ลบผิด | หมวด **ถังขยะ** ใน Explorer → กู้คืน |
| แก้ผิดแล้วบันทึกไปแล้ว | คลิกขวาที่ฉาก → **ประวัติเวอร์ชัน…** → กู้คืน |
| แทนที่/ย้าย/ลบผิดทั้งชุด | แผง **ประวัติการทำงาน** (`Ctrl+Alt+H`) → ย้อนมาที่จุดก่อนหน้า |
| โปรเจกต์พังทั้งโฟลเดอร์ | กู้จาก `Backups/<วันที่>/` ([10.6](10-history-backup.md#106-ชุดสำรองของโปรเจกต์)) หรือ ZIP ที่เก็บไว้ |
| แก้ไฟล์จากโปรแกรมอื่นแล้ว Killian ไม่เห็น | กด **รีเฟรช** บนแผงโปรเจกต์ · คุณสมบัติฉาก: **เครื่องมือ → ซิงก์คุณสมบัติฉากจากไฟล์ .md** |
| วางไฟล์ `.md` เข้าโฟลเดอร์บทเองแล้วไม่ขึ้นในต้นไม้ | **ตรวจสุขภาพโปรเจกต์** → ผูกกลับเป็นฉากในบทนี้ |
| ป้ายเตือนปัญหาโปรเจกต์บนแถบสถานะ | คลิกป้าย → ตรวจสุขภาพโปรเจกต์ → ซ่อมรายการที่เลือก |

## 16.6 ส่งออกและพิมพ์

| อาการ | ทางแก้ |
|---|---|
| อักษรไทยใน PDF เป็น `?` หรือหาย | ตั้งฟอนต์ไทย (`.ttf`/`.otf`) ที่ **ตั้งค่า → ฟอนต์ตามภาษา** |
| PDF ไม่มีเลขหน้า/หัวกระดาษ/หน้าปก | ติ๊กใน **ตัวเลือก PDF** ของศูนย์ส่งออก — และต้องตั้งหน้าปก/หัวกระดาษไว้ก่อนที่เมนู **บทภาพยนตร์** |
| ปลายทาง FDX / PDF ลายน้ำ กดไม่ได้ | ใช้ได้เฉพาะเอกสารที่เป็นบทภาพยนตร์ — ตรวจ **ชนิดเอกสาร** |
| ไฟล์ส่งออกมีโน้ต/Memo ติดไป | เปิดขั้น **ตัดโน้ต (memo) ออก** / **ไม่รวม element ตามประเภท** ในเวิร์กโฟลว์ |
| โค้ดสั้น `[title]` ไม่ถูกแทน | เปิดขั้น **แทนโค้ดสั้น** ในเวิร์กโฟลว์ · ชื่อโค้ดพิมพ์ผิดจะคงเป็นข้อความเดิม |
| จำนวนหน้าที่พิมพ์ไม่ตรงกับ PDF | คำสั่งพิมพ์ใช้ตัวตัดหน้าของระบบ — ต้องการตรงเป๊ะให้ส่งออก PDF แล้วพิมพ์ไฟล์นั้น ([9.6](09-export-import-print.md#96-พิมพ์)) |
| นำเข้าบทแล้วรูปแบบเพี้ยน | ดูตัวอย่างก่อนนำเข้า · หลังนำเข้าใช้ **บทภาพยนตร์ → ตรวจทั้งบท** ไล่แก้ชนิด element |

## 16.7 คำถามที่พบบ่อย

**งานของฉันเก็บไว้ที่ไหน ต้องมีบัญชีไหม**
ในโฟลเดอร์โปรเจกต์บนเครื่องของคุณ เป็นไฟล์ `.md` และ `.json` ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ ไม่มีการอัปโหลด

**ถ้าเลิกใช้ Killian งานจะเป็นยังไง**
เปิดไฟล์ `.md` ด้วยโปรแกรมแก้ข้อความใดก็ได้ — หรือส่งออกเป็น DOCX / EPUB / PDF / Markdown ก่อน

**ใช้กับ Dropbox / OneDrive / Google Drive / iCloud ได้ไหม**
ได้ — วางโฟลเดอร์โปรเจกต์ในโฟลเดอร์ซิงก์ แต่เปิดทีละเครื่องและรอซิงก์เสร็จก่อนเปิดอีกเครื่อง

**ทำงานร่วมกันหลายคนพร้อมกันได้ไหม**
ไม่มีการแก้ไขพร้อมกันแบบเรียลไทม์ — ทางที่ใช้ได้คือ Git (ไฟล์เป็นข้อความ รวมงานได้) หรือส่งโปรเจกต์/ZIP ให้กันแล้วใช้คอมเมนต์และประวัติเวอร์ชัน

**ใช้บนมือถือ/แท็บเล็ตได้ไหม**
ไม่ได้ — เป็นโปรแกรมเดสก์ท็อป (Windows · macOS · Linux) แต่ไฟล์ `.md` เปิดอ่าน/แก้ด้วยแอป Markdown บนมือถือได้ (กลับมาแล้วกดรีเฟรช)

**ต้องต่ออินเทอร์เน็ตไหม**
ไม่ต้อง ยกเว้นเรียก AI · ตรวจ/โหลดอัปเดต · ส่ง/ดูรายงานบั๊ก · ติดตั้งปลั๊กอินจากลิงก์ · คำพ้องออนไลน์ (ถ้าเปิด)

**AI เห็นงานทั้งหมดของฉันไหม**
ไม่ — เห็นเฉพาะสิ่งที่ส่งไปในคำขอนั้น ซึ่งคุณกำหนดด้วย "ระดับการเข้าถึง" และไปยังผู้ให้บริการที่คุณตั้งเองเท่านั้น ไม่ตั้งค่า AI = ไม่มีอะไรถูกส่ง

**เปิดโปรเจกต์ของ Killian v1 ได้ไหม / กลับไปใช้ v1 ได้ไหม**
ได้ทั้งสองทาง — รูปแบบไฟล์เข้ากันได้ (ของใหม่ที่ v1 ไม่มี เช่น กระดาน ผัง จะถูกมองข้ามใน v1)

**เล่มหนึ่งควรมีกี่ฉาก ไฟล์ใหญ่ได้แค่ไหน**
ไม่มีเพดานตายตัว — แบ่งฉากให้เล็ก (หนึ่งเหตุการณ์ต่อหนึ่งฉาก) จะได้ประโยชน์จาก Kanban · เส้นเวลา · ประวัติเวอร์ชันมากกว่าไฟล์ยาวไฟล์เดียว · โปรแกรมยังไม่ได้ทดสอบกับโปรเจกต์ขนาดใหญ่มากอย่างเป็นระบบ

**เปลี่ยนฟอนต์ ขนาดกระดาษ ระยะขอบ ทีหลังได้ไหม**
ได้ทุกเมื่อ — เป็นค่าการแสดงผล/จัดหน้า ไม่ได้เขียนลงเนื้อไฟล์ฉาก

**ตั้งค่าของฉันย้ายไปเครื่องใหม่ยังไง**
ก๊อปโฟลเดอร์ข้อมูลผู้ใช้ (`settings.json` · `Plugins/` · `languages/`) ไปที่เดียวกันบนเครื่องใหม่ ([1.7](01-getting-started.md#17-ข้อมูลของโปรแกรมอยู่ที่ไหน)) · ค่าของผลงานไปกับโฟลเดอร์โปรเจกต์อยู่แล้ว

**ล้างค่าตั้งทั้งหมดกลับเป็นโรงงาน**
ปิดโปรแกรม → เปลี่ยนชื่อโฟลเดอร์ข้อมูลผู้ใช้ (เก็บไว้เผื่อ) → เปิดโปรแกรมใหม่ · งานในโฟลเดอร์โปรเจกต์ไม่ถูกกระทบ

**โปรแกรมเก็บข้อมูลการใช้งานของฉันไหม**
ไม่ — ไม่มี telemetry บันทึกการทำงานอยู่ในเครื่องของคุณ และรายงานบั๊กถูกส่งเฉพาะเมื่อคุณกดส่ง
