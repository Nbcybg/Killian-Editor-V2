# คู่มือนักพัฒนาปลั๊กอิน Killian 2

> ใช้กับ Killian 2 รุ่น **alpha.169 ขึ้นไป** (วงจรชีวิต `onUnload` · `hotReload` · เหตุการณ์ของโปรแกรม เริ่มมีที่รุ่นนี้)
> แหล่งความจริงของ API = `pluginApi()` ใน `src/app.js` · ตรรกะ = `src/plugins/plugin-core.js` (มี unit test)
> ในโปรแกรม: แผง **ปลั๊กอิน** → **สิ่งที่ปลั๊กอินทำได้** แสดงรายการ API ชุดเดียวกันนี้

ปลั๊กอิน = โฟลเดอร์หนึ่งใบที่มีไฟล์ `plugin.json` กับไฟล์ JavaScript หนึ่งไฟล์
โปรแกรมส่งตัวแปร **`k2`** ให้ไฟล์นั้นหนึ่งตัว — ทุกอย่างที่ปลั๊กอินทำกับโปรแกรมได้อยู่ในตัวแปรนี้

---

## 1. เริ่มใน 2 นาที

1. เปิดแผง **ปลั๊กอิน** (เมนู มุมมอง → แผง → ปลั๊กอิน)
2. ปุ่ม **⋯ → สร้างตัวอย่าง** → ตั้งชื่อ → ได้ปลั๊กอินที่ทำงานทันที
3. ปุ่ม **⋯ → โฟลเดอร์ของผู้ใช้** → แก้ `main.js`
4. กลับมาที่แผง กด **โหลดใหม่** — โปรแกรมรันเฉพาะปลั๊กอินที่ไฟล์เปลี่ยน

ดูข้อผิดพลาด: เมนู ช่วยเหลือ → คอนโซลนักพัฒนา (`Ctrl+Shift+\``) และแผง **บันทึกการทำงานของโปรแกรม (Log)** (`k2.log()` เขียนที่นั่น)

---

## 2. ที่อยู่ของปลั๊กอิน

| ที่ | โฟลเดอร์ | ใช้เมื่อ | ต้องขออนุญาตก่อนรัน |
|---|---|---|---|
| ของผู้ใช้ | `<ข้อมูลผู้ใช้ของโปรแกรม>/Plugins/<ชื่อ>/` (Windows: `%APPDATA%\Killian 2\Plugins\`) | ใช้ได้ทุกผลงานบนเครื่องนี้ | ไม่ — ผู้ใช้ติดตั้งเองกับมือ |
| ของผลงาน | `<ผลงาน>/Plugins/<ชื่อ>/` | ติดไปกับโฟลเดอร์ผลงาน (ก๊อป/ซิปผลงานแล้วปลั๊กอินไปด้วย) | **ใช่** — ดูข้อ 8 |

- ชื่อซ้ำกันทั้งสองที่ → **ของผลงานชนะ** และของผู้ใช้ชื่อนั้นไม่ถูกรันเลย
- `Plugins/dictionaries/` ถูกสงวนไว้ให้คลังคำของตัวตรวจคำผิด ไม่ใช่ปลั๊กอิน
- **ชื่อโฟลเดอร์คือตัวตนของปลั๊กอิน** (ใช้เป็นกุญแจของค่าตั้ง · ชื่อคีย์ลัด · id ของแผง) — เปลี่ยนชื่อโฟลเดอร์ = ปลั๊กอินตัวใหม่

## 3. `plugin.json`

```json
{
  "name": "นับคำ",
  "entry": "main.js",
  "version": "1.0.0",
  "author": "ชื่อคุณ",
  "description": "นับคำในฉากที่เปิดอยู่",
  "minAppVersion": "2.0.0-alpha.169",
  "homepage": "https://github.com/you/k2-wordcount",
  "hotReload": true
}
```

| ช่อง | จำเป็น | ความหมาย |
|---|---|---|
| `name` | แนะนำ | ชื่อที่อ่านง่าย (ไม่มี = ใช้ชื่อโฟลเดอร์) |
| `entry` | ไม่ | ไฟล์ที่ถูกรัน ค่าเริ่มต้น `main.js` · ห้ามชี้ออกนอกโฟลเดอร์ (`..` / ทางเต็ม) |
| `version` · `author` · `description` · `homepage` | ไม่ | แสดงบนการ์ดในแผงปลั๊กอิน |
| `minAppVersion` | ไม่ | รุ่นโปรแกรมขั้นต่ำ — ต่ำกว่านี้ไม่รัน และการ์ดบอกว่าต้องใช้รุ่นใหม่กว่า |
| `hotReload` | ไม่ | `true` = ปลั๊กอินเก็บกวาดของตัวเองครบใน `k2.onUnload` → ปิด/ถอน/แก้โค้ดได้โดย **ไม่ต้องเริ่มโปรแกรมใหม่** (ดูข้อ 6) |

ไฟล์ `plugin.json` ต้องเป็น JSON ที่อ่านได้ — อ่านไม่ออก = ถือว่าปลั๊กอินพัง (ถูกปิดอัตโนมัติ)

## 4. โค้ดถูกรันยังไง

```js
new Function('k2', <เนื้อไฟล์ entry>)(k2)
```

- **ไฟล์เดียว เป็นสคริปต์ธรรมดา** — ใช้ `import` / `require` ไม่ได้ (ต้องการหลายไฟล์ ให้ bundle เป็นไฟล์เดียวก่อน เช่น esbuild `--format=iife`)
- รันในหน้าต่างของโปรแกรม (Chromium) — ใช้ DOM API ได้ทั้งหมด · **ไม่มี Node.js** (`fs` · `path` · `process` ไม่มี)
- ต้องการ `await` ที่ระดับบน ให้ครอบ: `(async () => { … })();`
- ตัวแปรระดับบนของไฟล์เป็นของปลั๊กอินตัวเอง (อยู่ในฟังก์ชัน) ไม่ชนกับตัวอื่น
- **โยน error ตอนรัน = ปลั๊กอินถูกปิดอัตโนมัติ** (กันโปรแกรมเปิดไม่ขึ้นในรอบหน้า) — ผู้ใช้กด "เปิดใช้" กลับได้หลังแก้ไฟล์
- โค้ดถูกรัน **ครั้งเดียวต่อรุ่นของไฟล์**: กดโหลดใหม่โดยไฟล์ไม่เปลี่ยน = ไม่รันซ้ำ

## 5. ตัวแปร `k2` — รายการเต็ม

### ข้อมูล

| | |
|---|---|
| `k2.pluginName` | ชื่อโฟลเดอร์ของปลั๊กอินนี้ |
| `k2.appVersion` | รุ่นของโปรแกรม เช่น `"2.0.0-alpha.169"` |
| `k2.projectRoot()` | ทางเต็มของผลงานที่เปิดอยู่ · `null` = ยังไม่เปิดผลงาน |

### คำสั่ง · เมนู · คีย์ลัด

| | |
|---|---|
| `k2.registerCommand(label, fn)` | เพิ่มคำสั่ง — โผล่บนการ์ดของปลั๊กอินในแผง และในปุ่ม **คำสั่งจากปลั๊กอิน** บนแถบเครื่องมือ (ปุ่มโผล่เมื่อมีปลั๊กอินลงทะเบียนคำสั่งไว้ · แถบแคบ = อยู่ในปุ่ม » ท้ายแถบ) |
| `k2.addMenuItem(label, fn)` | ชื่อเดิมของ `registerCommand` (ทำงานเหมือนกัน) |
| `k2.registerShortcut(id, code, ctrl, shift, fn)` | จองคีย์ลัด · `code` = `KeyboardEvent.code` (**ปุ่มกายภาพ** เช่น `'KeyK'` · `'F9'` · `'BracketRight'` — ทำงานทุกภาษาแป้นพิมพ์) · `ctrl` ค่าเริ่มต้น `true` (⌘ บน macOS) · คืนชื่อช่อง `plugin:<ชื่อ>:<id>` |
| `k2.menuPopup(items, x, y)` | เปิดเมนูป๊อปอัป · `items` = `[{ label, click }, '-', …]` |

เลือกคีย์ที่โปรแกรมยังไม่ใช้ (ดู เมนู ช่วยเหลือ → ปุ่มลัดทั้งหมด) — คีย์ชนกับคำสั่งของโปรแกรม คำสั่งของโปรแกรมชนะ

### ตัวแก้ไข

| | |
|---|---|
| `k2.getMarkdown()` | มาร์กดาวน์ของฉากที่เปิดอยู่ (ทั้งนิยายและบทภาพยนตร์) · ไม่มีฉากเปิด = `''` |
| `k2.insertText(text)` | แทรกข้อความที่เคอร์เซอร์ + ทำเครื่องหมายว่ายังไม่บันทึก · คืน `false` ถ้าไม่มีตัวแก้ไข |
| `k2.getEditorView()` | `EditorView` ของ ProseMirror (หรือ `null`) — อ่าน `view.state.doc` / `view.state.selection` หรือ `view.dispatch(tr)` เองได้ |

> ห้ามแก้ DOM ใน `.ProseMirror` ตรง ๆ (ใส่คลาส/element/สไตล์) — ตัวจัดหน้าวัดจาก DOM จริง จะเพี้ยนทั้งเอกสาร และของที่ใส่จะหายเมื่อ ProseMirror วาดใหม่
> แก้เนื้อหาให้ผ่าน transaction เท่านั้น

### แผง

```js
const pid = k2.registerPanel('stats', {
  title: 'สถิติของฉัน',        // ชื่อบนหัวแผง
  icon: 'chart',               // ชื่อไอคอนจาก icons/glyphs.csv (ไม่ใส่ = ไอคอนปลั๊กอิน)
  defaultSide: 'right',        // 'left' | 'right' | 'bottom'
  closable: true, floatable: true,
  render: (host) => { host.textContent = 'สวัสดี'; },   // วาดเนื้อแผงลง host
});
k2.showPanel('stats');   k2.hidePanel('stats');
```

- แผงของปลั๊กอินผนึก/ลอย/รวมเป็นแท็บได้เหมือนแผงในตัว · id จริง = `plugin-<ชื่อ>-<id>`
- `render` ถูกเรียกซ้ำได้ (แผงถูกวาดใหม่เมื่อย้าย/พับ) — เขียนให้เรียกซ้ำแล้วได้ผลเดิม (`host.replaceChildren(…)`)
- ปลั๊กอินถูกปิด/ถอน → แผงถูกปิดและถอนทะเบียนให้เอง

### เหตุการณ์

```js
const off = k2.on('tab:save', (e) => k2.log('บันทึก ' + e.file));
off();                         // เลิกฟัง (หรือ k2.off('tab:save', fn))
k2.emit('myplugin:hello', { n: 1 });   // ส่งถึงปลั๊กอินตัวอื่น
k2.on('*', (payload, event) => …);     // ฟังทุกเหตุการณ์
```

**เหตุการณ์ของโปรแกรม**

| ชื่อ | เมื่อ | ข้อมูล |
|---|---|---|
| `project:open` | เปิดผลงานและโหลดปลั๊กอินของผลงานนั้นเสร็จ | `{ root, title }` |
| `project:close` | กำลังจะปิดผลงาน (ยังอ่านไฟล์ได้) | `{ root }` |
| `tab:activate` | สลับไปแท็บอื่น | `{ file, title, kind }` · `kind` = `'prose'` · `'screenplay'` · `'wiki'` · `'other'` |
| `tab:save` | บันทึกฉากลงดิสก์สำเร็จ | `{ file, title, chars }` |
| `plugins:loaded` | ตัวโหลดปลั๊กอินทำงานเสร็จหนึ่งรอบ | `{ loaded: [ชื่อ…] }` |

- ตัวรับที่โยน error ไม่กระทบตัวรับอื่น (ถูกจดลงบันทึกการทำงาน)
- ตั้งชื่อเหตุการณ์ของตัวเองแบบมีคำนำหน้า (`<ชื่อปลั๊กอิน>:<เรื่อง>`) กันชนกับปลั๊กอินอื่น
- ตัวรับที่ลงผ่าน `k2.on` ถูกถอนให้เองเมื่อปลั๊กอินถูกปิด/ถอน

### ไฟล์ (เฉพาะในโฟลเดอร์ผลงาน)

| | |
|---|---|
| `await k2.readFile(rel)` | อ่านเป็นข้อความ UTF-8 · ไม่มีผลงานเปิด/ทางไม่ผ่าน = `null` |
| `await k2.writeFile(rel, text)` | เขียนข้อความ (เขียนแบบ atomic) |
| `await k2.listDirs(rel)` · `await k2.listFiles(rel, ext)` | รายชื่อโฟลเดอร์ / ไฟล์ (กรองนามสกุลได้ เช่น `'.md'`) |

- `rel` = ทางสัมพัทธ์จากรากผลงาน ใช้ `/` คั่น · มี `..` = ถูกปฏิเสธ
- **ข้อความเท่านั้น** — ไฟล์ไบนารี (รูป · zip) ผ่านทางนี้ไม่ได้ (ไบต์จะเสีย)
- ไฟล์งานของผู้ใช้ (`.md` · `scenes.json` · `draft.json`) มีกติกาเฉพาะ (คิวเขียน · แท็บที่เปิดค้าง) — **อย่าเขียนทับเอง** ถ้าฉากนั้นเปิดอยู่ให้แก้ผ่าน `getEditorView()` · ปลั๊กอินควรเก็บข้อมูลของตัวเองในโฟลเดอร์ของตัวเอง เช่น `Plugins/<ชื่อ>/data.json` หรือไฟล์ใหม่ของตัวเองในผลงาน

### ค่าตั้งของปลั๊กอิน

| | |
|---|---|
| `k2.getSettings(key, def)` | อ่านค่า · ไม่ส่ง `key` = ได้ทั้งก้อน (สำเนา) |
| `k2.setSettings(key, value)` · `k2.setSettings({ a: 1, b: 2 })` | เขียนค่า (รวมกับของเดิม) |

เก็บใน `project.khn.json → settings.plugins[<ชื่อโฟลเดอร์>]` = **ค่าเป็นของผลงาน** (คนละผลงานคนละค่า) · เก็บได้เฉพาะของที่แปลงเป็น JSON ได้
ต้องการค่าที่ใช้ร่วมทุกผลงาน ให้ใช้ `localStorage` ด้วยคีย์ที่มีชื่อปลั๊กอินนำหน้า

### หน้าจอ

| | |
|---|---|
| `k2.setStatus(text)` | ข้อความบนแถบสถานะ (หายเองในไม่กี่วินาที) |
| `await k2.ask(title, { value, placeholder })` | กล่องถามข้อความ → สตริง หรือ `null` เมื่อยกเลิก |
| `await k2.confirmBox(title, okLabel)` | กล่องยืนยัน → `true` / `false` |
| `await k2.alertBox(text)` | กล่องแจ้ง |
| `k2.log(...args)` | เขียนลงบันทึกการทำงานของโปรแกรม (ขึ้นต้นด้วย `[plugin <ชื่อ>]`) |

`window.alert` · `window.prompt` · `window.confirm` **ใช้ไม่ได้** ใน Electron — ใช้สามตัวข้างบนแทน

### เครือข่าย

```js
const r = await k2.fetch('https://api.example.com/x', { method: 'POST', headers: {…}, body: JSON.stringify(…) });
// r = { ok, status, body, error? }   — body เป็นข้อความเสมอ (แปลงเอง: JSON.parse(r.body))
```

วิ่งผ่านตัวโปรแกรม (ไม่ติด CORS) · **ไม่โยน error** — เน็ตล้ม/หมดเวลา = `ok:false` พร้อม `error` · ข้อความเท่านั้น (โหลดไฟล์ไบนารีไม่ได้)

### เก็บกวาด

| | |
|---|---|
| `k2.onUnload(fn)` | `fn(why)` ถูกเรียกเมื่อปลั๊กอินถูกปิด (`'remove'`) หรือกำลังถูกแทนด้วยไฟล์รุ่นใหม่ (`'reload'`) · ลงได้หลายตัว เรียกย้อนลำดับ |

## 6. วงจรชีวิต และ "ต้องเริ่มโปรแกรมใหม่ไหม"

เมื่อปลั๊กอินถูก **ปิด · ถอน · แก้ไฟล์แล้วโหลดใหม่ · ติดตั้งทับ · เปลี่ยนผลงาน** โปรแกรมทำสิ่งนี้ตามลำดับ:

1. เรียก `k2.onUnload` ของปลั๊กอิน
2. ถอนของที่ลงทะเบียนผ่าน `k2` ให้เอง: คำสั่ง · คีย์ลัด · แผง · ตัวรับเหตุการณ์

สิ่งที่โปรแกรม **มองไม่เห็น** คือของที่โค้ดทำเอง — `setInterval` · `addEventListener` บน `window`/`document` · element ที่แปะเข้าหน้าจอ · สไตล์ที่ฉีดเข้า `<head>` · ตัวแปรบน `window`
ของพวกนี้จะค้างอยู่จนกว่าหน้าต่างจะถูกโหลดใหม่ ดังนั้น:

| ปลั๊กอิน | เมื่อถูกปิด/ถอน/แก้ |
|---|---|
| ประกาศ `"hotReload": true` | ออกทันที ไม่มีคำเตือน — **ผู้เขียนรับรองเองว่า `onUnload` เก็บกวาดครบ** |
| ไม่ประกาศ (ค่าเริ่มต้น) | แผงปลั๊กอินขึ้นแถบ **"ต้องเริ่มโปรแกรมใหม่เพื่อถอดปลั๊กอินออกให้หมด"** พร้อมปุ่มเริ่มใหม่ และมีข้อความลอยแจ้งทันที |

- **ติดตั้ง/เปิดใช้ครั้งแรกไม่ต้องเริ่มโปรแกรมใหม่** ทุกกรณี
- ถ้า `onUnload` โยน error โปรแกรมถือว่าเก็บกวาดไม่ครบ → แจ้งให้เริ่มใหม่แม้จะประกาศ `hotReload`
- ปุ่ม "เริ่มโปรแกรมใหม่" ถามเรื่องงานที่ยังไม่บันทึกก่อนเสมอ (กล่องเดียวกับตอนออกจากโปรแกรม)

**แบบที่ถูกของปลั๊กอิน `hotReload`**

```js
const onKey = (e) => { if (e.code === 'F8') k2.setStatus('F8'); };
window.addEventListener('keydown', onKey);
const timer = setInterval(tick, 60000);
const style = document.head.appendChild(Object.assign(document.createElement('style'), { textContent: '.mine{…}' }));

k2.onUnload(() => {
  window.removeEventListener('keydown', onKey);
  clearInterval(timer);
  style.remove();
});
```

## 7. หน้าตาให้เข้ากับโปรแกรม

- ใช้ตัวแปรสีของธีม ไม่ใช้สีตายตัว: `--bg` · `--side` · `--bar` · `--border` · `--fg` · `--dim` · `--bright` · `--accent` · `--accent-hi` · `--on-accent` · `--hover` · `--sel` · `--st-warn` · `--st-danger`
  (ธีมมี 20 กว่าชุด ทั้งมืด/สว่าง/คอนทราสต์สูง — สีตายตัวจะอ่านไม่ออกในบางธีม)
- ขนาดตัวอักษรคูณ `var(--ui-scale, 1)` เพื่อให้ตามการย่อ/ขยาย UI ของผู้ใช้
- ข้อความของ UI ลากเลือกไม่ได้โดยปริยาย — เนื้อหาที่ผู้ใช้ควรคัดลอกได้ ใส่คลาส `k-selectable`
- ปุ่ม/แถวใช้ `cursor:default` (ไม่ใช้รูปมือ) — โปรแกรมทำตัวแบบโปรแกรมเดสก์ท็อป ไม่ใช่หน้าเว็บ
- ข้อความจากผู้ใช้/ไฟล์ ใส่ด้วย `textContent` เสมอ ห้าม `innerHTML`
- ตั้งชื่อคลาส CSS ให้มีคำนำหน้าของปลั๊กอิน (`.wc-…`) — คลาสลอย ๆ ชนกับของโปรแกรมได้

## 8. ความปลอดภัยและการอนุญาต

ปลั๊กอิน **รันด้วยสิทธิ์เต็มของหน้าต่างโปรแกรม** (อ่าน/เขียนไฟล์ผ่านโปรแกรมได้) ผู้ใช้ต้องเชื่อผู้เขียน

- **ปลั๊กอินของผลงาน ไม่ถูกรันจนกว่าผู้ใช้จะกด "อนุญาตปลั๊กอินของโปรเจกต์นี้"** ในแผงปลั๊กอิน (การ์ดขึ้นสถานะ "รออนุญาต")
  - อนุญาต "ชุดไฟล์ชุดนี้" ไม่ใช่ "ผลงานนี้ตลอดไป" — โปรแกรมจำลายนิ้วมือของ `plugin.json` + ไฟล์ entry ของทุกตัวในชุด
  - มีใครเพิ่ม/แก้ปลั๊กอินในโฟลเดอร์ผลงานทีหลัง (ซิงก์ · แตกซิปทับ · **รวมถึงตอนคุณแก้ไฟล์เองระหว่างพัฒนา**) → ต้องอนุญาตใหม่
  - การอนุญาตเก็บในเครื่องของผู้ใช้ ไม่ได้อยู่ในผลงาน (ผู้ส่งผลงานแก้เองไม่ได้)
  - ถอนตัวหนึ่งออกจากชุดที่อนุญาตแล้ว = ตัวที่เหลือยังได้รับอนุญาตต่อ
- **พัฒนาในโฟลเดอร์ของผู้ใช้สะดวกกว่า** (ไม่ต้องอนุญาตซ้ำทุกครั้งที่แก้ไฟล์) แล้วค่อยย้ายเข้าผลงานเมื่อเสร็จ
- คีย์ API/รหัสผ่าน: อย่าเก็บใน `setSettings` (ลงไฟล์ผลงานซึ่งผู้ใช้ส่งต่อให้คนอื่น) — ให้ผู้ใช้กรอกแล้วเก็บใน `localStorage`

## 9. แจกจ่าย: ติดตั้งจากลิงก์

ผู้ใช้กด **ติดตั้งจากลิงก์** ในแผงปลั๊กอินแล้ววางลิงก์ — รับรูปแบบ:

```
https://github.com/user/repo                       (ลอง branch main แล้ว master)
https://github.com/user/repo/tree/dev              (ระบุ branch)
https://github.com/user/repo/tree/dev/plugins/abc  (โฟลเดอร์ย่อยในรีโป)
user/repo                                          (ทางลัด)
https://example.com/anything.zip                   (ไฟล์ zip ตรง ๆ)
```

กติกาของรีโป/ซิป:

- ต้องมี `plugin.json` — โปรแกรมเลือกตัวที่ **อยู่ตื้นที่สุด** เป็นรากของปลั๊กอิน (วางไว้รากรีโปได้เลย)
- ชื่อโฟลเดอร์ปลายทาง = ชื่อโฟลเดอร์ที่ `plugin.json` อยู่ (อยู่ราก = ชื่อรีโป ตัด `-main`/`-master` ท้ายออก)
- ซิปใหญ่สุด **25 MB**
- ไม่ติดตั้ง: `.git` · `.github` · `node_modules` · `__MACOSX` · `.DS_Store` · `Thumbs.db`
- ติดตั้งลง **โฟลเดอร์ของผู้ใช้** เสมอ · ก่อนเขียนไฟล์ ผู้ใช้เห็นชื่อโฟลเดอร์ + จำนวนไฟล์ + คำเตือนเรื่องสิทธิ์ แล้วต้องกดยืนยัน
- ติดตั้งทับชื่อเดิม = ถามยืนยันอีกครั้ง

**ถอน** = ปุ่ม "ถอนออก" บนการ์ด → ลบโฟลเดอร์ทิ้งถาวร (ถามยืนยันก่อน) · ค่าตั้งของปลั๊กอินในไฟล์ผลงานไม่ถูกลบ

## 10. ตัวอย่างครบชุด — "นับคำตอนบันทึก"

`plugin.json`

```json
{ "name": "นับคำตอนบันทึก", "entry": "main.js", "version": "1.0.0",
  "description": "บอกจำนวนคำทุกครั้งที่บันทึก และมีแผงสรุป",
  "minAppVersion": "2.0.0-alpha.169", "hotReload": true }
```

`main.js`

```js
const seg = new Intl.Segmenter(undefined, { granularity: 'word' });   // ตัดคำไทยได้
const count = (md) => { let n = 0; for (const s of seg.segment(md)) if (s.isWordLike) n++; return n; };

let last = k2.getSettings('last', null);      // { file, words } ของการบันทึกครั้งล่าสุด
let host = null;

function draw() {
  if (!host) return;
  host.replaceChildren();
  const box = document.createElement('div');
  box.style.cssText = 'padding:12px; color:var(--fg); font-size:calc(13px * var(--ui-scale, 1))';
  box.textContent = last ? last.words + ' คำ — ' + last.file.split(/[\\/]/).pop() : 'ยังไม่มีการบันทึก';
  host.append(box);
}

k2.registerPanel('summary', { title: 'นับคำ', defaultSide: 'right', render: (h) => { host = h; draw(); } });

k2.on('tab:save', (e) => {
  last = { file: e.file, words: count(k2.getMarkdown()) };
  k2.setSettings('last', last);
  k2.setStatus('บันทึกแล้ว · ' + last.words + ' คำ');
  draw();
});

k2.registerCommand('นับคำฉากนี้', () => k2.setStatus(count(k2.getMarkdown()) + ' คำ'));
k2.registerShortcut('count', 'F8', true, true, () => k2.setStatus(count(k2.getMarkdown()) + ' คำ'));   // Ctrl+Shift+F8

k2.onUnload(() => { host = null; });          // ไม่มีของนอก k2 ให้เก็บ — ประกาศ hotReload ได้
```

## 11. รายการตรวจก่อนแจก

- [ ] `plugin.json` อ่านเป็น JSON ได้ · มี `version` · `minAppVersion` ตรงกับ API ที่ใช้
- [ ] ปิดแล้วเปิดใหม่จากแผง → ทำงานเหมือนเดิม ไม่มีของซ้ำสองชุด
- [ ] ถ้าประกาศ `hotReload`: หลังปิด ไม่มีตัวจับเวลา/ตัวฟัง/element ของปลั๊กอินเหลืออยู่ (ดูในคอนโซลนักพัฒนา)
- [ ] ลองทั้งธีมมืดและธีมสว่าง + ขนาด UI 125%
- [ ] ลองตอนยังไม่เปิดผลงาน (`k2.projectRoot()` เป็น `null` · `readFile` คืน `null`)
- [ ] ไม่มีคีย์ลับ/ทางไฟล์ของเครื่องคุณอยู่ในรีโป
- [ ] ติดตั้งจากลิงก์รีโปของตัวเองบนโปรแกรมสะอาด ๆ ได้จริง

## 12. ข้อจำกัดที่รู้อยู่

- ไฟล์เดียว ไม่มีระบบโมดูล · ไม่มี Node.js · อ่าน/เขียนได้เฉพาะข้อความในโฟลเดอร์ผลงาน
- การปิด/เปิดปลั๊กอิน และค่าของ `setSettings` **จำต่อผลงาน** (อยู่ใน `project.khn.json`) ยังไม่มีที่เก็บระดับผู้ใช้
- เมนูของระบบ (แถบเมนูบนสุด) เพิ่มรายการจากปลั๊กอินไม่ได้ — คำสั่งของปลั๊กอินอยู่ที่การ์ดในแผง · ปุ่ม "คำสั่งจากปลั๊กอิน" บนแถบเครื่องมือ · คีย์ลัด
- ยังไม่มีร้านปลั๊กอิน/การอัปเดตอัตโนมัติ — อัปเดต = ติดตั้งจากลิงก์เดิมทับ
- API ยังอยู่ในช่วง alpha: ของที่ระบุในเอกสารนี้จะพยายามคงไว้ แต่ชื่อภายในของโปรแกรม (คลาส CSS · โครง DOM · ตัวแปรบน `window`) เปลี่ยนได้ทุกรุ่น อย่าพึ่ง
