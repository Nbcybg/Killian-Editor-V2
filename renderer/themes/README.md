# ธีมสีของ Killian 2 — คู่มือนักพัฒนา

ธีมเปลี่ยนได้แค่ **เปลือกโปรแกรม** (แถบ · แผง · แท็บ · กล่อง) ผ่านตัวแปร CSS
ตัวหน้ากระดาษ (`--paper-*`) ห้ามแตะ ยกเว้น `--paper-surround` (พื้นรอบกระดาษ)

| ไฟล์ | หน้าที่ | แก้มือได้ไหม |
|---|---|---|
| `themes.json` | **ทะเบียนธีม — แหล่งความจริงเดียว** | ✅ แก้ที่นี่ |
| `<id>.css` | ตัวแปรสีของธีม | ❌ สร้างจาก themes.json (ยกเว้นธีม `handmade`) |
| `base.css` | ค่าสำรองก่อนใส่คลาสธีม | ✅ |
| `_template.css` | เทมเพลตตัวแปรครบทุกตัว + คำอธิบาย (ไม่ถูกโหลด) | — |
| `../../src/theme-gen.js` | สูตรคำนวณสีที่เหลือจากสีหลัก 5 สี | ✅ (มี unit test) |
| `../../tools/theme-build.cjs` | เขียน css · `<link>` ใน index.html · `src/generated/themes-data.js` · ป้ายชื่อใน CSV | — |

## เพิ่มธีมใหม่ (ทางปกติ — 1 นาที)

1. เปิด `themes.json` คัดลอกก้อนหนึ่งไปต่อท้าย แล้วแก้:

   ```json
   { "id": "ocean-night", "mode": "dark",
     "name": { "th": "ทะเลยามค่ำ", "en": "Ocean Night" },
     "colors": { "bg": "#0b1d2e", "fg": "#e6f1ff",
                 "accent": "#ff7a59", "accentHi": "#ffd166", "link": "#6ec1ff" } }
   ```

   - `id` — a-z 0-9 และขีด · ห้ามซ้ำ (ชื่อคลาสจะเป็น `body.theme-<id>`)
   - `mode` — `dark` หรือ `light` (สูตรคำนวณสีรองต่างกัน)
   - `colors` — **บังคับ 5 สี**: `bg` `fg` `accent` `accentHi` `link`
     ใส่เพิ่มได้: `side` `bar` `border` `dim` `sel`
   - `vars` — ทับตัวแปรทีละตัวแบบตรง ๆ เช่น `{ "--chip": "#334455" }` (ชื่อต้องอยู่ใน `_template.css`)
   - `palette` — สีดิบของจาน (ไม่บังคับ) ออกเป็น `--theme-<ชื่อ>`
   - `source` — ที่มาของจานสี (ไม่บังคับ ไว้อ้างอิง)

2. `node build.js` → ได้ `ocean-night.css` · `<link>` ใน index.html · รายชื่อใน THEMES ·
   ป้ายชื่อ `ui.themes.oceanNight` ในไฟล์ภาษาทุกไฟล์ (ภาษาที่ไม่มีใน `name` ใช้ไทยไปก่อน)
3. `node tools/run-unit.cjs theme` → ต้องผ่าน (ตรวจตัวแปรครบ · คอนทราสต์ · ไม่แตะกระดาษ · ไฟล์ตรงกับสเปก)
4. เปิดโปรแกรม → ตั้งค่า → ทั่วไป → ธีมสี

> สีที่เป็น **ตัวหนังสือ** (`fg` `dim` `accent` `accentHi` `link`) ถูกดันคอนทราสต์กับพื้นให้ผ่านเกณฑ์อัตโนมัติ
> (ดู `MIN_CONTRAST` ใน theme-gen.js) — ถ้าสีที่ออกมาไม่ตรงจานเป๊ะ แปลว่าสีเดิมอ่านไม่ออกบนพื้นนั้น

## ธีมเขียนมือ (คุมทุกสีเอง)

ดูขั้นตอนบนหัวไฟล์ `_template.css` — สรุป: คัดลอกเป็น `<id>.css` · ใส่สีครบทุกตัว ·
เพิ่ม `{ "id": "<id>", "mode": "…", "handmade": true, "labelKey": "ui.themes.<idCamel>" }` ใน themes.json ·
เพิ่มป้ายชื่อด้วย `node tools/i18n-add.cjs`

## แก้สีธีมที่มีอยู่

- ธีมที่สร้างอัตโนมัติ → แก้ใน `themes.json` แล้ว `node build.js` (**อย่าแก้ .css** — ถูกเขียนทับ)
- ธีม `k2` / `k2-light` (handmade) → แก้ `.css` ตรง ๆ ได้
- ชื่อธีมที่แสดง → แก้ใน `languages/k2_*.csv` (คีย์ `ui.themes.*`) — ตัวสร้างไม่เขียนทับคำแปลที่มีแล้ว

## กฎของกฎ CSS ใน style.css

ทุกพื้นผิวต้องอ้างตัวแปร **ห้ามเขียนเลข hex** · ต้องการพื้นผิวชนิดใหม่ =
เพิ่มตัวแปรใน `THEME_VARS` (theme-gen.js) + `base.css` + ธีม handmade ทุกไฟล์ แล้ว build ใหม่
