# ภาพประกอบของ Story Starter (แบบ setup wizard)

วางไฟล์ภาพลงโฟลเดอร์นี้แล้ว **เปิดโปรแกรมใหม่** — ไม่ต้อง build
ขนาด/ชื่อไฟล์ถูกกำหนดไว้ที่ `src/starter/starter-art.js` (แหล่งเดียว · มี unit test `starter-art`)

## ขนาด

| ตำแหน่ง | ขนาดไฟล์ | แสดงบนจอ (100%) | ใช้เมื่อ |
|---|---|---|---|
| `side` | **480 × 920 px** (แนวตั้ง) | 240 × 460 | เนื้อแผง Story Starter กว้าง ≥ 600px (แผงผนึกขนาดตั้งต้นก็ได้แล้ว) — แถบภาพข้างซ้ายของ wizard |
| `top`  | **1200 × 300 px** (แนวนอน 4:1) | เต็มความกว้างแผง | แผงแคบ และหน้ารวม — แถบภาพหัวหน้า |

- ไฟล์ใหญ่เป็นสองเท่าของที่แสดง เพื่อไม่เบลอบนจอ 150–200%
- รับ `.png` · `.jpg` · `.webp` (ลองตามลำดับนี้)
- ภาพถูกครอบแบบ `cover` (เต็มกรอบ ตัดส่วนเกิน) — วางจุดสำคัญไว้กลางภาพ
- ภาพ `top` ถูกแสดงเล็กมากในแผงแคบ (≈ 350 × 88) — อย่าใส่ตัวหนังสือเล็ก ๆ

## ชื่อไฟล์

`<ช่อง>-<ตำแหน่ง>.png`

| ช่อง | หน้า | ไฟล์ |
|---|---|---|
| `default` | ใช้แทนทุกช่องที่ไม่มีไฟล์ของตัวเอง | `default-side.png` · `default-top.png` |
| `home` | หน้ารวมเรื่อง | `home-top.png` |
| `tags` | ขั้นที่ 1 แนวเรื่อง | `tags-side.png` · `tags-top.png` |
| `intro` | ขั้นที่ 2 ชื่อเรื่อง + เรื่องย่อ | `intro-side.png` · `intro-top.png` |
| `cast` | ขั้นที่ 3 ตัวละคร | `cast-side.png` · `cast-top.png` |
| `w` | ขั้นที่ 4 4W | `w-side.png` · `w-top.png` |
| `cover` | ขั้นที่ 5 ปกเรื่อง | `cover-side.png` · `cover-top.png` |

**ทำน้อยที่สุด = 2 ไฟล์** (`default-side.png` + `default-top.png`) แล้วทุกหน้าใช้ภาพชุดเดียวกัน
ทำครบทุกขั้น = 11 ไฟล์

ไม่มีไฟล์ = โปรแกรมวาดกรอบเส้นประที่บอกขนาดกับชื่อไฟล์ที่ต้องวาง (placeholder)
