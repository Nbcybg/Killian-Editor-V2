ฟอนต์ไทยตระกูล Courier ที่ฝังมากับ Killian 2
=============================================

ไฟล์
  CourierThaiMono.ttf   ← ดัดแปลงจาก COURMON.TTF  (Courier MonoThai, 1998)
  CourierThaiProp.ttf   ← ดัดแปลงจาก courpro.ttf   (Courier ProportionalThai, 1998)

สิ่งที่แก้ (alpha.57a) — แก้อาการ "สระ/วรรณยุกต์ลอย"
----------------------------------------------------
ต้นฉบับวางสระบน/วรรณยุกต์ห่างจากพยัญชนะ ~7% ของ em
ขณะที่ฟอนต์อ้างอิง (Courier New / Leelawadee UI / Tahoma) ห่างแค่ ~3.5%
ตาเห็นเป็น "วรรณยุกต์ลอยหลุด" โดยเฉพาะขนาด 12pt ของบทภาพยนตร์

แก้โดย **ขยับเส้นร่าง (outline) ของ glyph มาร์กเท่านั้น**
  · สระบน + วรรณยุกต์ + รูปแบบ PUA ทุกตัว (F701–F717 ยกเว้น F70F) → ลง 74 หน่วย (em 2048)
  · สระล่าง (ุ ู ฺ)                                              → ขึ้น 36 หน่วย
รวม 38 glyph ต่อไฟล์ · ไม่แตะ advance / cmap / ตารางอื่นใดทั้งสิ้น
ผลวัดจริง: ช่องว่างเหลือ 3–4px ที่ 110px (เท่า Courier New) · สระล่างเหลือ 6px (เท่า Leelawadee UI)

สคริปต์ที่ใช้แก้อยู่ที่ tools/shiftmarks.py (ใช้ fonttools) — ทำซ้ำจากไฟล์ต้นฉบับได้

หมายเหตุ
--------
· ไม่ได้เติม GSUB/GPOS เข้าไป — ฟอนต์ชุดนี้ใช้กลไก PUA ของมาตรฐาน Windows Thai (F700–F717)
  ซึ่ง HarfBuzz ใน Chromium จัดการให้ถูกต้องอยู่แล้ว การเติม ccmp เองจะซ้อนกันแล้วเพี้ยนหนักกว่าเดิม
· ตัวอักษรละติน/เครื่องหมายวรรคตอนของฟอนต์ชุดนี้ไม่ครบและบางตัวผิดตำแหน่ง
  แนะนำให้ใช้ผ่าน "ตั้งค่า → ฟอนต์ตามภาษา" โดยจำกัดช่วงไว้ที่ U+0E00-0E7F
  แล้วปล่อยละตินให้เป็นหน้าที่ของ Courier Prime
· **สัญญาอนุญาตของฟอนต์ต้นฉบับยังไม่ทราบ** — ผู้ใช้เป็นผู้จัดหาไฟล์มาเอง
  ก่อนแจกจ่ายโปรแกรมออกสู่สาธารณะ ควรตรวจสอบสิทธิ์การดัดแปลง/แจกจ่ายซ้ำก่อน
