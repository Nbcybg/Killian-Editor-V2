## ใหม่ใน alpha.59 — ชุด PDF ครบวง · หน้าปก · หัวกระดาษ

รอบนี้เลิกพึ่ง "print-to-PDF ของ Chromium" อย่างเดียว — เพิ่ม **ตัวสร้าง PDF ในโปรแกรม**
ที่ทำสิ่งที่ CSS ทำไม่ได้ โดย **ทางเดิมยังอยู่ครบ** (เลือกได้ทั้งสองทาง)

- **🧾 ส่งออก PDF (ตัวสร้างในโปรแกรม)** — เมนู **ไฟล์** / **บท**
  ฝังฟอนต์ไทยลงไฟล์เอง · เลขหน้า/เลขฉาก/ระยะเยื้องตรงกับที่เห็นบนจอทุกจุด
- **📑 สารบัญในไฟล์ PDF** — หัวฉากทุกฉากกลายเป็น bookmark กระโดดได้ในโปรแกรมอ่าน PDF
  และเปิดไฟล์มาโชว์แถบสารบัญให้เลย
- **เปิดไฟล์แล้วเด้งไปหน้าที่กำลังเขียน** — ส่งบทให้คนอ่านแล้วเขาเปิดตรงหน้าที่คุยกันได้ทันที
- **📄 หน้าปก (Title Pages)** — หลายหน้าก็ได้ กล่องแก้ไข 3 คอลัมน์ (รายการหน้า / พรีวิวกระดาษจริง /
  คุณสมบัติข้อความ) · วางข้อความเป็น **นิ้วจากขอบกระดาษ** · ปุ่มเดียวสร้าง "หน้าปกมาตรฐาน"
  จากข้อมูลผลงาน · หน้าปกไม่นับรวมกับเลขหน้าของบท
- **📑 หัวกระดาษทุกหน้า (Page Headers)** — ซ้ายกลางขวาในบรรทัดเดียว
  ใช้ตัวแปร `${PAGE}` `${TITLE}` `${AUTHOR}` `${DRAFT}` ฯลฯ (พิมพ์ชื่อไทยได้: `${หน้า}`)
  · หัวกระดาษกินบรรทัดจริง จำนวนหน้าจึงตรงกับที่พิมพ์ออกมา
- **🧹 ไม่รวม element ตามประเภทตอนส่งออก** — ตัดโน้ต/สรุป/โครงออกจากบทที่ส่งให้คนอื่นอ่าน
  ทั้งในกล่องส่งออก PDF และเป็นขั้นตอนในเวิร์กโฟลว์ส่งออก · พรีเซ็ตใหม่ **"🎬 บทภาพยนตร์ → PDF"**
- **แก้บั๊กฟอนต์ที่เจอตอนเปิดไฟล์ดูด้วยตา** — ฟอนต์ไทยที่ฝังมา (ปี 1998) เอา `·` `©` `—` `…` `“ ”`
  ไปชี้ทับด้วยตัวอักษรไทย (`·` ออกมาเป็น "ท") → แก้ด้วยการวาดทีละช่วงตามฟอนต์

- **🔊 เสียงเครื่องพิมพ์ดีด** — สังเคราะห์เองด้วย WebAudio (ไม่มีไฟล์เสียงแนบ) เคาะแป้น/วรรค/ลบ/กระดิ่งตอนขึ้นบรรทัด

## ใหม่ใน alpha.57 — มุมมองบท · ตรวจข้อผิดพลาด · ส่งออก FDX/RTF/PDF ลายน้ำ

**เมนูใหม่ "บท"** รวมงานบทภาพยนตร์ไว้ที่เดียว

- **โหมดมุมมอง 5 แบบ** (แถบเครื่องมือ หรือ เมนู บท → มุมมองบท)

  - **ร่าง (Draft)** ข้อความล้วนบนพื้นว่าง เต็มความกว้าง · ตัวคั่นหน้าเป็นเส้นบาง ๆ มีเลขหน้า
  - **เรียงหน้าคู่ (Side-by-Side)** วางหน้ากระดาษจริงหลายหน้าเรียงกัน ย่อพอดีจออัตโนมัติ (สูงสุด 4 หน้า/แถว)
  - **ภาพรวม 1px / 4px ต่อตัวอักษร** เห็นรูปทรงของบททั้งเรื่องรวดเดียว
  - โหมดเรียงหน้า/ภาพรวมอ่านอย่างเดียว — **คลิกตรงไหนก็กลับไปแก้ตรงนั้นได้ทันที**
- **แสดงรูปแบบ** — เส้นฟ้าบอกขอบซ้าย-ขวาของแต่ละ element + เครื่องหมายท้ายบรรทัด (`¶` จบบล็อก · `·` ตัดบรรทัดเอง)
- **ไปที่หน้า/ฉาก `Ctrl+G`** — กรอกเลขหน้า หรือเลือกจากรายการหัวฉาก

  บรรทัดยาวเกิน · หัวฉากติดกัน · เนื้อบทก่อนหัวฉากแรก · บรรทัดว่างที่ไม่ควรว่าง)
  แถบสถานะบอกจำนวน (คลิกไปข้อถัดไป) · `Ctrl+Shift+U` ไล่ทีละข้อ · **ตรวจให้ก่อนส่งออกอัตโนมัติ**
- **ส่งออก Final Draft (.fdx)** — ชนิดย่อหน้าครบตามสคีมา FD + หน้าปกจากข้อมูลผลงาน
- **ส่งออก Rich Text (.rtf)** — **ภาษาไทยไม่เพี้ยน** (แปลงเป็น `\uNNNN?` ตามสเปก RTF) ·
  ระยะเยื้อง/กระดาษ/ระยะขอบตามค่าที่ตั้งไว้
- **PDF ลายน้ำรายคน** — ใส่รายชื่อผู้รับ ได้ PDF แยกไฟล์ต่อคน ลายน้ำต่างกัน → รู้ว่าบทหลุดจากสำเนาของใคร

## ใหม่ใน alpha.46 — จัดวางหน้าจอแบบ Photoshop

ทุกพื้นที่ของหน้าต่างกลายเป็น **"แผง"** ที่จัดวางเองได้ทั้งหมด (เดิมแถบข้างตายตัวอยู่ซ้ายเสมอ)

- **ลากหัวแผงไปวางที่ไหนก็ได้** — ลากเข้าใกล้ขอบแผงอื่นจะขึ้นแถบสีบอกว่าจะไปอยู่ตรงไหน
  (ซ้าย/ขวา/บน/ล่าง) · ปล่อยตรงกลาง = **รวมเป็นแท็บ** เดียวกัน · ปล่อยนอกโปรแกรม = **ลอยอิสระ**
- **แถบเครื่องมือกับแถบสถานะก็เป็นแผง** — ย้าย/จัดใหม่ได้เหมือนกัน
- **ลากเส้นคั่นระหว่างแผง** เพื่อปรับสัดส่วน (ดับเบิลคลิก = 50%)
- **ย่อกลุ่มแท็บเป็นแถบไอคอน** (ปุ่ม « บนแถบแท็บ) เพื่อคืนพื้นที่ให้หน้ากระดาษ
- **ปิดแผงแล้วเรียกกลับได้เสมอ** — มีปุ่มค้างไว้มุมล่างซ้าย หรือเมนู มุมมอง → แผง
- การจัดวางถูกจำไว้ให้อัตโนมัติ · รีเซ็ตได้ที่ มุมมอง → แผง → รีเซ็ตการจัดวางแผงทั้งหมด

## ใหม่ใน alpha.44 — เก็บงาน 7 ฟีเจอร์ปิดท้าย
ทั้ง 7 ข้อมีโค้ดและอยู่ในเมนูตั้งแต่ alpha.40 — รอบนี้คือทำให้ **ใช้ได้จริงครบทุกมุม**

- **โหมดโฟกัส (Ctrl+Shift+D)** — ปรับ**ความจางของบรรทัดอื่น**ได้เองที่ ตั้งค่า → การเขียน ·
  แก้ Esc ที่เคยแย่งกับกล่องโต้ตอบ/โหมดอ่าน (ตอนนี้ออกทีละชั้น)
- **โหมดเครื่องพิมพ์ดีด (Ctrl+Shift+T)** — ตัวแก้ไขใน**หน้าต่างลอย**ก็เลื่อนตามบรรทัดแล้ว (เดิมทำงานเฉพาะในช่องหลัก)
- **ส่งออกเป็น HTML สำหรับบล็อก (Ctrl+Shift+B)** — เลือก**ธีม** (Medium / เรียบ / มืด) · ใส่/ไม่ใส่ชื่อบท-ชื่อฉาก ·
  **ฝังรูปลงไฟล์เดียว (base64)** ก๊อปไปวางที่ไหนก็เห็นรูป
- **สถานะฉาก** — **มีสีแล้ว** (เลือกเองได้ทุกสถานะ) เห็นสีเดียวกันทั้ง Explorer · Kanban · ตารางฉาก ·
  **นำเข้า/ส่งออกชุดสถานะเป็น .json** ย้ายข้ามโปรเจกต์ได้
- **เปิดไฟล์ด่วน (Ctrl+Shift+O)** — จำผลสแกนไว้ (เปิดซ้ำเห็นทันที) แล้วสแกนซ้ำในพื้นหลังเสมอ
  → **ไฟล์ที่เพิ่งสร้างโผล่ทันที** (เดิมต้องรีสตาร์ตโปรแกรม) · มีแถบคำใบ้ปุ่มลัด + 🔄 สแกนใหม่
- **AI สรุปเนื้อหา** — มีแถบความคืบหน้า ("อ่านฉาก 12/40") · **รวมคลัง Wiki** เข้าไปในบริบท ·
  **แคชผลไว้** เนื้อเรื่องไม่เปลี่ยนก็ไม่เสีย token ซ้ำ
- **AI แนะนำชื่อ** — **คลิกขวาที่ฉาก/บทเพื่อขอชื่อ** (ส่งเนื้อฉากจริงไปเป็นบริบท) เดิมใช้ได้แต่ชื่อโปรเจกต์ ·
  **จำชื่อที่เคยแนะนำ** ไว้เลือกซ้ำได้ฟรี
- เทสเพิ่มเป็น **666 checks** (+ unit test 666 ข้อ)

- **🌿 ผังแตกสาย (Branch Tree)** — จากรายการการ์ด กลายเป็น**ผังภาพจริง**: กล่องฉากเรียงตามความลึกของเรื่อง
  เชื่อมด้วยเส้นโค้งมีลูกศรและป้ายข้อความทางเลือก · สีขอบบอกทันทีว่าฉากไหนเป็น **จุดเริ่ม / ตอนจบ /
  วนซ้ำ / เดินไปไม่ถึง** · คลิกกล่อง → แผงขวาแก้ทางเลือกได้ในตัว · ปุ่ม **⊞ เปิดคู่กับผัง** = ผังซ้าย ฉากขวา
  · ย่อ/ขยาย/พอดีจอ · เตือนทางเลือกที่ยังไม่ได้ระบุปลายทาง
- **📍 ผังพื้นที่ (Floor Plan)** — ปักได้แล้วว่าฉากไหนเกิดตรงไหนบนแผนที่ · หมุด **"คุณอยู่ที่นี่" เต้น**

- **🎮 ประวัติการตัดสินใจ** — ออกมาจากเมนูแล้ว: โผล่ใน **แดชบอร์ด** (พร้อมสรุป "เลือกบ่อยสุด")
  และใน **หน้า Wiki ตัวละคร** เฉพาะการตัดสินใจที่เกี่ยวกับคนนั้น
- **🏷 แท็บสี (Visual Tags)** — เห็นสี/ไอคอน/รูปทรงจริงใน **Explorer · แถบตัวกรอง · Planner · Story Network**

- **📝 โน้ตด่วน** — มี**ปุ่มบนแถบเครื่องมือ**แล้ว (คลิกขวา = ดูทั้งหมด) · ติ๊ก **"ไว้ทำภายหลัง"**

- **📊 ศูนย์รวม** — backlinks ใช้ **Auto-link Engine** ตัวเดียวกับหน้า Wiki (รู้จักชื่อรอง, ไม่จับผิดคำ)

## พัฒนาต่อ
```
npm install        # ครั้งแรก
npm test           # ทดสอบ markdown round-trip
npm run test:unit  # เทสโมดูลบริสุทธิ์ทั้งชุด (1,852 checks · ไม่ต้องเปิด electron)
npm run build      # bundle renderer (esbuild)
npm start          # รัน (dev)
npm run dist       # แพ็ก Windows portable (.exe)
npm run dist:mac   # แพ็ก macOS Intel DMG (x64)
```
Smoke test เต็มระบบ (e2e 1,567 checks): `KILLIAN_TEST=1 KILLIAN_TEST_PROJECT=<path> npm start`
ผลอยู่ที่ /tmp/k2result.txt (ต้องลงท้าย `ALL OK`) + ภาพ /tmp/k2.png
· **สร้าง fixture ใหม่ทุกครั้งก่อนรัน**: `node test/fixture.js /tmp/k2proj`

## ประกอบ macOS Intel (x64) เอง

```bash
npm run dist:mac
# → dist/Killian2-<version>-mac-intel.dmg (~127MB) + dist/mac/Killian 2.app
```
ยังไม่ได้เซ็นด้วยใบรับรองนักพัฒนา (`identity: null` ใน `build.mac`) →
**ครั้งแรกต้องคลิกขวาที่แอป → Open** ไม่งั้น Gatekeeper บล็อก
· ยังใช้ไอคอนมาตรฐานของ Electron (ยังไม่มีไฟล์ `.icns`)

## ประกอบ portable Windows เอง
ดาวน์โหลด electron-v<ver>-win32-x64.zip จาก GitHub releases ของ Electron →
แตก → ลบ resources/default_app.asar → วาง main.js, preload.js, package.json,
renderer/ ไว้ที่ resources/app/ → เปลี่ยนชื่อ electron.exe เป็น Killian2.exe
