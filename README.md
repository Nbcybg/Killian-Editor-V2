## alpha.66r12 — ความสูงตอนลอย + ตำแหน่งกล่องกลุ่ม

- **ลากแผงข้างออกมาลอย ได้กล่องขนาดพอดี ไม่สูงเต็มจอ** — เดิมความจำขนาดตอนลอยต้องมีครบทั้งกว้าง+สูง
  ถึงจะใช้ได้ มีแค่ด้านเดียวก็ทิ้งทั้งคู่ แล้วไปยกความสูงของคอลัมน์ที่มันผนึกอยู่มาแทน
- **ขนาดที่ผู้ใช้ปรับเองยังชนะทุกอย่างเหมือนเดิม** และรอดการ dock/undock ครบทั้งสองแกน
- **ลากกล่องกลุ่มไปปล่อยตรงที่ผนึกไม่ได้ = ย้ายกล่อง** ไม่ใช่ทิ้งตำแหน่ง — เดิมตำแหน่งไม่ถูกบันทึก
  แล้วเด้งกลับไปที่แผงฐานตอนวาดใหม่ (มีผลกับแผงลอยเดี่ยวด้วย)

## alpha.66r11 — กลุ่มแผงลอยจำที่อยู่ของตัวเองได้

- **แผงในกลุ่มลอยจำได้ว่าอยู่กลุ่มไหน** — ปิดแล้วเปิดใหม่กลับเข้ากลุ่มเดิม · ถ้ากลุ่มนั้นไม่เหลือแล้ว
  จะลอยที่ **ตำแหน่ง/ขนาดล่าสุดของกลุ่ม** ไม่ใช่เด้งไปกลางจอ
- **กลุ่มลอยไม่หายตอนเปิดโปรแกรมใหม่** — เดิมถูกลบทั้งก้อนทุกครั้งที่โหลดเลย์เอาต์
- **ลากหัวแท็บในกลุ่มแล้วกล่องไม่ย้ายที่ตาม** (เดิมตัวลากกล่องกับตัวลากแท็บทำงานพร้อมกัน)
- **ผนึกทั้งกลุ่มที่ขอบจอได้จริง** — เดิมไปเกาะข้างแถบเครื่องมือ
- แผงที่เคยลอย เรียกกลับจากถาดแล้วยังลอยเหมือนเดิม (เดิมกลายเป็นผนึก)

## alpha.66r10 — undock แล้วขนาดไม่กระโดด · กลุ่มแผงลอยใช้งานได้จริง

- **ตัวที่รอดจากการยุบกลุ่ม ยึดขนาดของกลุ่ม** — undock ออกใบหนึ่งแล้วใบที่เหลือกว้างเท่าเดิม
  และแผงอื่นในแถวที่ตั้งขนาดไว้แล้วไม่ถูกเปลี่ยนตาม
- **แผงลอยที่จับกลุ่มกันแล้ว ดึงออก/ปิด/พับ/สลับลำดับได้แล้ว** — ของเดิมทุกปุ่ม "กดแล้วเงียบ"
  เพราะทุกคำสั่งหาแผงจาก id ของกล่อง ซึ่งไม่มีวันตรงกับสมาชิกในกลุ่ม · กลุ่มลอยคลิกแล้วขึ้นบนสุดได้ด้วย
- **แผงลอยใบอื่นไม่หายตอนดึงแผงออกจากกลุ่ม** (ตัวกรองเก่าทิ้งกล่องลอยเดี่ยวทุกใบไปพร้อมกัน)

## alpha.66r9 — แก้ "canvas เปล่า" หลังรีเซ็ตแล้วขยับแผง + ส่งออกการจัดวางแผง

- **ขนาดของกลุ่มแท็บถูกใช้จริงแล้ว** — เดิมค่าที่ประทับตอนรีเซ็ตไปอยู่ที่แผงลูก แต่ตัววาดอ่านที่ตัวกลุ่ม
  เลยตกกลับไปแบ่งตามสัดส่วน แล้วโดนเกลี่ยใหม่ทุกครั้งที่เปิด/ผนึกแผงอื่น (ซ้าย 360 → 166 → 120 …)
- **ปล่อยแผงที่ขอบจอไม่แบ่งครึ่งหน้าต่างอีกแล้ว** — เดิมได้ dock 50/50 และไม่ตรึงขนาดให้แผงใหม่
  ปล่อยสองใบ พื้นที่เขียนเหลือ 1/4 จอ = อาการ "canvas เปล่า" ที่เห็น
- **ใหม่: 📤 ส่งออกการจัดวางแผงเป็นไฟล์ JSON** (มุมมอง → แผง) — เก็บเป็นเลย์เอาต์อ้างอิง
  หรือแนบตอนรายงานบั๊ก · มีทั้งต้นไม้ ขนาดจริงบนจอ และผลวินิจฉัยว่าค่าไหนถูกใช้จริง

## alpha.66r8 — แก้บั๊กชื่อแท็บกลายเป็นรหัส + split เคารพขนาดเดิม

- **แยกช่องทับแผงที่อยู่ในกลุ่มแท็บ = แยกทั้งกลุ่ม** (เดิมยัด dock เป็นแท็บ → ชื่อแท็บกลายเป็นรหัสและกดไม่ได้)
- **ช่องใหม่เคารพขนาดของตัวที่อยู่มาก่อน** — A กว้าง 450 เอา B มาแยกข้าง ทั้งคู่อยู่ใน 450 เดิม
- **รวมกลุ่มได้เหมือนเดิม** (พลาดมาจากรอบก่อน) · แถบไกด์ขอบจอแคบลงเหลือ 12px ไม่ไปแย่งโซนของแผง
- **รีเซ็ต = ประทับค่าอ้างอิงตั้งต้น** ไม่ใช่ลบขนาดทิ้ง

## alpha.66r7 — เปิดแผงเป็นแผงลอย · กฎกลุ่ม · กลุ่มลอย

- **เปิดแผงใหม่ = ลอยกลางจอ** ไม่ผนึกเอง → ไม่ไปเบียดขนาดแผงที่จัดไว้แล้วอีก
- **กฎกลุ่ม**: เข้ากลุ่มยึดขนาดแผงฐาน · แยกออกจากกลุ่มยึดขนาดของกลุ่ม
- **แผงลอยจับกลุ่มกันได้** — ปล่อยที่หัวกล่องลอยเพื่อรวม · ลากแถบแท็บย้าย/ผนึกทั้งก้อน · ลากแท็บออกเพื่อแยก
- ค่าตั้งต้นของแต่ละแผงแยกกัน ไม่ใช้เลขรวม · กวาด "แผงปลอม" ที่หลุดเข้าเลย์เอาต์ทิ้งอัตโนมัติ

## alpha.66r6 — ขนาดแผงแยก "โหมดลอย" กับ "โหมดผนึก"

- **ผนึกแผงเข้า dock แล้วได้ขนาดที่สมเหตุสมผลทันที** ไม่ถูกบีบจนแบนอีก (ค่าตั้งต้นแยกตามชนิดแผง —
  แผงข้าง 300px · กระดาน/ผัง 640px) แล้วเก็บค่าไว้ตั้งแต่วินาทีนั้น
- **ดึงออกมาลอย ได้ขนาดโหมดลอยที่เคยตั้งไว้** · ผนึกกลับก็ได้ขนาดโหมดผนึก — สองค่าไม่ทับกัน
- **รวมกลุ่มแท็บแล้วขนาดแผงฐานไม่ถูกแก้** · แต่ละแผงพกขนาดของตัวเองติดไปด้วย
- ผลพลอยได้: **ปิดบั๊กช่องว่างค้างฝั่งขวา** ที่เกิดจาก dock ในสภาพผสม px+สัดส่วน

## alpha.66r5 — กฎการลากปรับขนาด + ขนาด/ตำแหน่งเลื่อนที่หายตอน dock/undock

- **ลากขอบฝั่งหนึ่ง อีกฝั่งไม่ขยับเลย** — ผู้ที่ยอมเสียพื้นที่มีแค่ตรงกลาง และตรงกลางมีขั้นต่ำจริง (260px) ลากเบียดต่อไม่ได้
- **ลากแผงออกมาลอย ได้ขนาดเท่าตอนผนึกอยู่** (เดิมถูกรีเซ็ตเป็น 320×300 ตายตัว)
- **พับ/ปิด แล้วเปิดกลับ ตำแหน่งเลื่อนยังอยู่** — จำค่าต่อแผงไว้ข้ามสถานะที่กล่องหายไปจากจอ
- **โหมดโฟกัส/โหมดอ่าน จัดหน้ากระดาษกลางจอให้เอง** (เดิมค้างชิดซ้าย)
- ตัวตรวจ **ช่องว่างค้าง** ทำงานอัตโนมัติหลังวาดทุกครั้ง — เจอเมื่อไหร่ปิดรูให้ทันทีและจดโครงสร้างลงแผง "บันทึก"

## alpha.66r4 — แผงข้างกว้างคงที่แบบ Photoshop

- **ลากปรับความกว้างแผงครั้งเดียว = ตรึงไว้เลย** — ขยายหน้าต่างแล้ว **พื้นที่เขียนได้ที่เพิ่มไปคนเดียว**
  แผงที่ตรึงไว้กว้างเท่าเดิมเป๊ะ (เดิมยืดตามสัดส่วนไปด้วย)
- ปิดแล้วเปิดแผงกลับมา ได้ความกว้างเดิมเป๊ะ · วาดใหม่กี่รอบก็ไม่ดริฟต์
- แผงที่ยังไม่เคยลาก ทำงานเหมือนเดิมทุกอย่าง · จอแคบก็หนีบให้เอง · "รีเซ็ตการจัดวางแผง" ล้างการตรึงทิ้ง

## alpha.66r3 — ระบบแผงครบตามสเปก (Photoshop-style)

- **Drop Zone ครบ 4 แบบ** — ลากไปชนขอบจอ = ได้ dock ใหม่เต็มด้าน · ปล่อยบนหัวแท็บ = แทรกตรงตำแหน่งนั้น ·
  ขอบแผง = แทรกช่องใหม่ (เส้นน้ำเงินบอกด้าน) · กลางแผง = รวมเป็นแท็บ (กรอบเขียว) — โชว์โซนเดียวที่ดีที่สุดเสมอ
- **Workspace Presets** — เก็บการจัดวางทั้งชุดไว้สลับได้ในคลิกเดียว (ตำแหน่ง · ขนาด · กลุ่ม · ย่อ/ขยาย ·
  แผงลอย · เปิด/ปิด) · มีชุดสำเร็จรูป **Essentials / เขียน / วางแผน / ตรวจแก้** · บันทึกชุดของตัวเองได้
- **จัดพื้นที่ทันที** — `Ctrl+\` ซ่อนแผงทั้งหมดเหลือแต่หน้ากระดาษ · `Ctrl+Shift+[` ซ่อนเฉพาะฝั่งขวา · กดซ้ำคืนกลับ
- **ปุ่ม ☰ บนหัวแผงทุกใบ** — คำสั่งลึกของแผงอยู่ที่เดียวกันหมด

## alpha.66r2 — แผง: ตำแหน่งเลื่อนไม่หาย · ย่อแผงแล้วไม่เหลือรูโหว่

- **เลื่อนแผงไว้ตรงไหน ก็อยู่ตรงนั้น** — ทั้งตอนขยับ/ปรับสัดส่วนแผง และตอนกดรีเฟรชเนื้อแผง
  ครบทั้งแนวตั้ง**และแนวนอน** · เดิมระบบจำจากรายชื่อกล่องที่เขียนไว้ตายตัว ซึ่งตกไปครึ่งค่อนแอป
  และตัวที่จำได้ก็คืนค่าลงกล่องที่ถูกทิ้งไปแล้ว (ตัววาดสร้าง `.k-panel-body` ใบใหม่ทุกรอบ)
- **ย่อแผงฝั่งขวาแล้วไม่เหลือช่องว่างค้างอีก** — ต้นตอคือการแจก `flex-grow` ที่ยังนับโควตาของ
  แผงที่พับอยู่ ทำให้ผลรวมไม่ถึง 1 เบราว์เซอร์เลยแจกพื้นที่ว่างไม่หมด
- **พับแผงในแถวแนวนอน = รางไอคอนแคบแบบ Photoshop** (เดิมกว้างเท่าหัวแผง กลายเป็นแถบตายกลางจอ)

## alpha.66r — เก็บบั๊ก UI ของผังแตกสาย

- **เลิกกระพริบ** — เดิมล้างแผงทิ้งก่อนไปอ่าน `scenes.json` ทั้งโปรเจกต์ทุกครั้ง แม้แค่คลิกเลือกโหนด
  ตอนนี้สร้างของใหม่ให้เสร็จก่อนแล้วสลับทีเดียว · การวาดที่ไม่ได้แก้ข้อมูลไม่แตะดิสก์เลย
- **ผังไม่เด้งอีก** — จำตำแหน่งเลื่อนไว้ และดึงกลับไปหาโหนดที่เลือกเฉพาะตอน "เพิ่งเปลี่ยนตัวที่เลือก"
- **เนื้อแผงเต็มช่องแล้ว** — เลิกอิง `100vh` (แผงไม่ได้สูงเท่าหน้าต่าง) + ถอด padding/overflow
  ที่ `.k-panel-body` ครอบไว้ ทั้งผังและโหมดทดลองเล่น
- **ผังเลื่อนแนวตั้ง/แนวนอนได้เอง** และ **ลากผังด้วยปุ่มกลางเมาส์ได้**
- **"เปิดคู่กับผัง" แยกจอจริง** — ผนึกผังไว้ข้างแผงเอกสาร (ผังซ้าย · ฉากขวา)
- แก้บั๊กพ่วง: แผงเคยยืมคลาส `k-dlg-input` ของกล่องโต้ตอบ → เนื้อแผงที่ปิดอยู่ (ยังคาใน DOM)
  ไปแย่งคิวรีของกล่องจริง ทำให้กล่อง "เพิ่มฉาก/เปลี่ยนชื่อเล่ม" พัง · แยกเป็น `.k-field-input` แล้ว

## alpha.66 — ยกเครื่องระบบเรื่องแตกสาย (Non-linear) ทั้งชุด

**ผังแตกสายเป็นแผงแล้ว** (`branch`) เลิกแย่งแถบแท็บกับฉากที่กำลังเขียน · เปิดคู่กับต้นฉบับได้

- **แถบเพิ่มทางเลือกขึ้นมาอยู่บน ผังอยู่ล่าง** · ตัวหนังสือทุกจุดใหญ่เท่า UI หลัก (ผูกกับ `--ui-scale`)
- **ป้ายทางเลือกมีแถบรองพื้น ไม่จมกับเส้นอีก** และวางที่ **กึ่งกลางเส้นโค้งจริง** (จุด t=0.5 ของเส้น Bézier)

## alpha.65r4 — บันทึกการทำงาน + แถบบันทึกที่อ่านย้อนได้

### 📜 แถบบันทึก (Log) ไม่ดีดหนีอีกแล้ว
เดิมรีเฟรชทุก 2 วินาทีแล้ว `scrollTop = scrollHeight` ทุกครั้ง → เลื่อนขึ้นไปอ่านบรรทัดเก่าไม่ได้เลย
ตอนนี้ **ตามบรรทัดล่าสุดเฉพาะตอนที่อยู่ล่างสุดอยู่แล้ว** · เลื่อนขึ้นเมื่อไหร่ = ล็อกอยู่ตรงนั้น
มีปุ่ม **⤓ ตามบรรทัดล่าสุด** โผล่มุมล่างขวาให้กดกลับ (เหมือน console/แชท)

### 🔍 บันทึกละเอียดของ Planner
เปิดแผง **บันทึก** แล้วใช้งานกระดาน จะเห็นทุกจังหวะ:
- `planner: tool=shape selection=false objectsEvented=false` — เปลี่ยนเครื่องมือ
- `planner: create/start … canvasOffset / rect / vt` — กดเมาส์เริ่มลากสร้าง (มีพิกัดจอ · offset ของ canvas · viewport)
- `planner: create/guide เกิดกรอบนำ 220x140 ที่ 300,700` — กรอบนำโผล่จริงไหม ที่ไหน
- `planner: create/end …` — ปล่อยเมาส์แล้วได้ขนาดเท่าไร
- `planner: โหลด/บันทึกกระดาน` · `planner: _fit …` (พร้อม offset)
- `planner/tree: สร้างหมวดกระดาน N ใบ` · `planner/tree: markRow rows=… hit=… blankName=…`
- `planner/tree ตรวจสภาพ: หมวด=มี แถว=1 ซ่อน=0 ว่าง=0 หมวดพับ/ซ่อน=false` + รายละเอียดทุกแถว

### 🐞 ที่แก้ได้จากรอบนี้
| บั๊ก | ต้นตอ | แก้แล้ว |
|---|---|---|
| กรอบนำตอนลากสร้างไม่ขึ้น จนกว่าจะสร้างกระดานใหม่ | `fit()` ที่ผมใส่ optimization "ขนาดเท่าเดิมไม่ต้องทำอะไร" ดัน **ข้าม `calcOffset()`** ไปด้วย → ปิดแผงแล้วเปิดใหม่ canvas ย้ายที่ใน DOM แต่ fabric ยังจำพิกัดเดิม กรอบนำเลยไปวาดนอกจอ | `calcOffset()` ทุกครั้งใน `fit()` + ตอนเปิดแผงซ้ำ + ตอนกดเมาส์ · และเกณฑ์ "ขยับพอจะถือว่าลาก" คิดเป็นพิกเซลบนจอแทนหน่วยกระดาน (ซูมเข้ามาก ๆ ไม่ต้องลากไกลกว่าปกติ) |
| แถวกระดานใน Explorer โผล่เป็นบรรทัดว่าง (หัวข้อขึ้น `(1)` แต่ไม่เห็นอะไร) | `markPlannerRow()` อ่านชื่อจาก `data-search` ที่โมดูลอื่นเขียนทับได้ · ถ้าชื่อว่างก็เขียนทับข้อความเดิมเป็นค่าว่าง | อ่านชื่อจาก `data-planner-name` ของตัวเอง · **ชื่อว่าง = ไม่แตะข้อความเดิม** แล้วสั่งสร้างต้นไม้ใหม่ + เขียน log บอกว่าเกิดอะไรขึ้น |

## ใหม่ใน alpha.46 — จัดวางหน้าจอแบบ Photoshop

- การจัดวางถูกจำไว้ให้อัตโนมัติ · รีเซ็ตได้ที่ มุมมอง → แผง → รีเซ็ตการจัดวางแผงทั้งหมด

- **โหมดโฟกัส (Ctrl+Shift+D)** — ปรับ**ความจางของบรรทัดอื่น**ได้เองที่ ตั้งค่า → การเขียน ·
  แก้ Esc ที่เคยแย่งกับกล่องโต้ตอบ/โหมดอ่าน (ตอนนี้ออกทีละชั้น)
- **โหมดเครื่องพิมพ์ดีด (Ctrl+Shift+T)** — ตัวแก้ไขใน**หน้าต่างลอย**ก็เลื่อนตามบรรทัดแล้ว (เดิมทำงานเฉพาะในช่องหลัก)
- **ส่งออกเป็น HTML สำหรับบล็อก (Ctrl+Shift+B)** — เลือก**ธีม** (Medium / เรียบ / มืด) · ใส่/ไม่ใส่ชื่อบท-ชื่อฉาก ·
  **ฝังรูปลงไฟล์เดียว (base64)** ก๊อปไปวางที่ไหนก็เห็นรูป
- **สถานะฉาก** — **มีสีแล้ว** (เลือกเองได้ทุกสถานะ) เห็นสีเดียวกันทั้ง Explorer · Kanban · ตารางฉาก ·
  **นำเข้า/ส่งออกชุดสถานะเป็น .json** ย้ายข้ามโปรเจกต์ได้
- **เปิดไฟล์ด่วน (Ctrl+Shift+O)** — จำผลสแกนไว้ (เปิดซ้ำเห็นทันที) แล้วสแกนซ้ำในพื้นหลังเสมอ
  → **ไฟล์ที่เพิ่งสร้างโผล่ทันที** (เดิมต้องรีสตาร์ตโปรแกรม) · มีแถบคำใบ้ปุ่มลัด + 🔄 สแกนใหม่
- **AI สรุปเนื้อหา** — มีแถบความคืบหน้า ("อ่านฉาก 12/40") · **รวมคลัง Wiki** เข้าไปในบริบท ·
  **แคชผลไว้** เนื้อเรื่องไม่เปลี่ยนก็ไม่เสีย token ซ้ำ
- **AI แนะนำชื่อ** — **คลิกขวาที่ฉาก/บทเพื่อขอชื่อ** (ส่งเนื้อฉากจริงไปเป็นบริบท) เดิมใช้ได้แต่ชื่อโปรเจกต์ ·
  **จำชื่อที่เคยแนะนำ** ไว้เลือกซ้ำได้ฟรี
- เทสเพิ่มเป็น **666 checks** (+ unit test 666 ข้อ)

## ใหม่ใน alpha.43 — รอบแก้บั๊กจากการทดสอบด้วยคนจริง (16 ข้อ)

- **โหมดอ่าน + โหมดหน้ากระดาษ** ใช้ด้วยกันแล้วอ่านไม่ออก (หมึกดำบนพื้นดำ) — แก้ให้คงกระดาษไว้ครบ
- **วงกลมรูปตัวละครใน Wiki** ใส่รูปไม่ได้เลย (โค้ดอ่านฟิลด์ผิดชนิด) — ตอนนี้ **คลิกวงกลม = เลือกรูป**
  และเลือกได้ด้วยว่าจะใช้รูปไหนเป็นรูปประจำตัว (☆/★ บนรูปในคลังของตัวละคร)
- **เมนู/ปุ่มที่เป็นสวิตช์มีเครื่องหมายถูกจริง** — โหมดหน้ากระดาษ · โหมดอ่าน · โฟกัส · เครื่องพิมพ์ดีด ·
  เลขบรรทัด · แยกจอ · นิยาย/บทหนัง · แผงแต่ละอัน (ปุ่ม toolbar มีจุดบอกสถานะด้วย)
- **ย่อแผงแล้วแผงหายถาวร** — ตอนนี้ปุ่มบนหัวแผงเรียงมาตรฐาน **[—] ย่อ · [▾] พับ · [📌] ปักตำแหน่ง · [✕] ปิด**
  และ "ย่อ" จะเก็บแผงเป็น**ปุ่มลอยมุมล่างซ้าย** คลิกเรียกกลับได้เสมอ
- **เหตุการณ์บนเส้นเวลาอ้างอิงเอกสาร/โน้ตได้** — ชิปอ้างอิงบนการ์ด คลิกเปิดไฟล์นั้นทันที
- **Explorer: หมวด 🖼 คลังรูป** (ภาพย่อ · ลากไปวางในฉาก · แทรกลงฉากจากคลิกขวา) + **ปุ่ม 🔄 รีเฟรช**
- **แยกจอ/เทียบเวอร์ชันด้านขวา** เลิกหลุดเวลาคลิกแท็บฝั่งขวา (สลับข้างแทน) · มีเส้นคั่นลากได้ทุกเส้นทาง ·
  หน้ากระดาษหดตามช่องที่แคบลง · เพิ่มปุ่ม **⇋ เทียบด้านขวา** ในกล่องประวัติเวอร์ชัน
- **"ย้ายออกไปที่ MEMO" มีทางกลับแล้ว** (↩ ย้ายกลับเข้าบท… / 📄 กลับเป็นฉากปกติ)
- **FAB ไม่ถูกแผงลอยบัง** และ **สร้างฉาก/บทถามก่อนว่าจะลงเล่มไหน บทไหน** (เดิมลงบทแรกเสมอ)
- **Wiki มีระบบเวอร์ชันเหมือนฉาก** — 🕘 ประวัติเวอร์ชัน · 📸 บันทึกเวอร์ชัน · สำรองอัตโนมัติตอนบันทึก
- **Story Network เลื่อนได้แล้ว** — ลากพื้นหลัง = เลื่อนผัง · ผังไม่ถูกบีบเหลือ 300px อีก · ปุ่มรีเซ็ตมุมมอง
- **แผงคุณสมบัติบันทึกอัตโนมัติ** (ไม่ต้องกดปุ่มแล้ว) และ**เลิกซ้ำรายการ**เวลาเลือกฉากรัว ๆ
- **ผังแตกสายผูกกับเนื้อเรื่องจริง** — พิมพ์ `[ไปตลาด]` ในฉากตรงจุดที่เรื่องแตกสาย แล้วกดผูกเป็นทางเลือก
  (มีปุ่ม 🔎 สแกนทั้งโปรเจกต์ และคำสั่งในเมนูใช้ได้ระหว่างเขียนโดยไม่ต้องเปิดผัง)
- **tooltip ลอยเหนือเคอร์เซอร์** ไม่บังแถวถัดไปในต้นไม้อีก

## ใหม่ใน alpha.42 — Advanced Storytelling UI
รอบ alpha.40 ทำให้ฟีเจอร์ชุดใหม่ "เปิดได้จากเมนู" — รอบนี้ทำให้ **ใช้เขียนงานได้จริง**

- **🌿 ผังแตกสาย (Branch Tree)** — จากรายการการ์ด กลายเป็น**ผังภาพจริง**: กล่องฉากเรียงตามความลึกของเรื่อง
  เชื่อมด้วยเส้นโค้งมีลูกศรและป้ายข้อความทางเลือก · สีขอบบอกทันทีว่าฉากไหนเป็น **จุดเริ่ม / ตอนจบ /
  วนซ้ำ / เดินไปไม่ถึง** · คลิกกล่อง → แผงขวาแก้ทางเลือกได้ในตัว · ปุ่ม **⊞ เปิดคู่กับผัง** = ผังซ้าย ฉากขวา
  · ย่อ/ขยาย/พอดีจอ · เตือนทางเลือกที่ยังไม่ได้ระบุปลายทาง
- **📍 ผังพื้นที่ (Floor Plan)** — ปักได้แล้วว่าฉากไหนเกิดตรงไหนบนแผนที่ · หมุด **"คุณอยู่ที่นี่" เต้น**
  บอกตำแหน่งฉากที่กำลังเขียน · **แถบเส้นเวลาของสถานที่นั้น** (ฉากทั้งหมดที่เกิดที่นี่ เรียงตามเวลาในเรื่อง)
  · สิ่งที่เห็น/ได้ยิน/พบ ลบทีละรายการได้แล้ว
- **🎮 ประวัติการตัดสินใจ** — ออกมาจากเมนูแล้ว: โผล่ใน **แดชบอร์ด** (พร้อมสรุป "เลือกบ่อยสุด")
  และใน **หน้า Wiki ตัวละคร** เฉพาะการตัดสินใจที่เกี่ยวกับคนนั้น
- **🏷 แท็บสี (Visual Tags)** — เห็นสี/ไอคอน/รูปทรงจริงใน **Explorer · แถบตัวกรอง · Planner · Story Network**
  (เดิมมีแค่ในตารางฉาก) · คลิกชิปในต้นไม้ = กรองด้วยแท็กนั้นทันที
- **📝 โน้ตด่วน** — มี**ปุ่มบนแถบเครื่องมือ**แล้ว (คลิกขวา = ดูทั้งหมด) · ติ๊ก **"ไว้ทำภายหลัง"**
  แล้วโน้ตจะไปค้างอยู่**บนหน้าเส้นเวลา** จนกว่าจะติ๊กว่าทำแล้ว
- **📊 ศูนย์รวม** — backlinks ใช้ **Auto-link Engine** ตัวเดียวกับหน้า Wiki (รู้จักชื่อรอง, ไม่จับผิดคำ)
  · อัปเดต**อัตโนมัติทุกครั้งที่บันทึก** · ชื่อฉากคลิกเปิดได้ · บอกด้วยว่าตัวละคร/สถานที่ไหน
  **"ยังไม่ถูกกล่าวถึงเลย"**
- เทสเพิ่มเป็น **550 checks** (+ unit test 101 ข้อ)
