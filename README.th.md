## ข้อควรทราบ

- **Killian 2 เป็นซอฟต์แวร์ที่ไม่มีวันเสร็จ** อยู่ระหว่างพัฒนาต่อเนื่องและไม่มี "รุ่นสุดท้าย": ฟีเจอร์ถูกเพิ่ม ปรับ และบางครั้งถูกถอด และมีบั๊กได้เสมอ งานที่เสียไม่ได้ให้สำรองไว้เองด้วย — ประวัติเวอร์ชัน ถังขยะ และเครื่องมือสำรองในโปรแกรมช่วยได้ แต่ไม่ใช่สิ่งทดแทน
- **ยืนเดี่ยวโดยตั้งใจ** K2 เป็นโปรแกรมเดสก์ท็อปที่ครบในตัว ไม่ต้องมีบัญชี ไม่มีเซิร์ฟเวอร์ ไม่มีบริการคลาวด์ โปรเจกต์คือโฟลเดอร์ธรรมดาบนดิสก์ของคุณเอง
- **เกิดมาเพื่องานเขียนเนื้อเรื่องเกมก่อน** K2 ถูกสร้างเป็นเครื่องมือเขียนเนื้อเรื่องของเกม — เรื่องแบบแตกสาย ตัวละคร และคัมภีร์โลกในตัว ภายหลังจึงขยายไปถึงนิยายและบทภาพยนตร์ แต่งานเขียนเกมยังเป็นจุดตั้งต้นและกำหนดรูปร่างของเครื่องมือหลายตัว
- **เปิดรับการร่วมพัฒนา** ทุกคน fork โปรเจกต์แล้วเปิด **pull request** ได้ — ดู [สนับสนุนโปรเจกต์](#สนับสนุนโปรเจกต์)
- **ซอฟต์แวร์นี้ให้ "ตามสภาพ" โดยไม่มีการรับประกันใด ๆ** คุณรับผิดชอบงานและไฟล์ของคุณเอง
- **ฟีเจอร์ AI เป็นทางเลือก และใช้คีย์ของคุณเอง** Killian 2 ไม่มีบริการ AI มาด้วย เมื่อคุณตั้งผู้ให้บริการ ข้อความที่คุณเลือกส่งจะไปถึง *ผู้ให้บริการรายนั้น* ภายใต้เงื่อนไข *ของเขา* ไม่มีคีย์ก็ยังใช้การตรวจแบบออฟไลน์ได้
- **ใช้เน็ตเฉพาะสิ่งที่คุณสั่ง:** เรียก AI · ตรวจ/ดาวน์โหลดอัปเดต · ส่งหรือดูรายงานบั๊กและคำขอฟีเจอร์ การเขียนทำงานออฟไลน์ได้ทั้งหมด
- **ไม่มีความเกี่ยวข้องกัน** Final Draft, Celtx, Scrivener, Adobe Story, Fade In และชื่อผลิตภัณฑ์อื่นเป็นเครื่องหมายการค้าของเจ้าของแต่ละราย Killian 2 เพียงอ่านและเขียนรูปแบบไฟล์สาธารณะ/แลกเปลี่ยนของโปรแกรมเหล่านั้น
- ตัว macOS ยัง **ไม่ได้ลงนาม (code-sign)** macOS จึงเตือนในครั้งแรกที่เปิด

## K2 คืออะไร

**Killian 2** (K2) คือสภาพแวดล้อมสำหรับงานเขียนบนเดสก์ท็อปแบบยืนเดี่ยว สำหรับ **เนื้อเรื่องเกม นิยาย และบทภาพยนตร์** — สร้างเพื่อนักเขียน *และ* คนที่ทำงานอยู่ข้างหลังนักเขียน: นักออกแบบเนื้อเรื่อง ผู้ควบคุมความต่อเนื่อง ผู้กำกับ บรรณาธิการเรื่อง คนสร้างโลก

K2 ทำงานบน **Windows, macOS และ Linux**

ต้นฉบับ คัมภีร์ของเรื่อง กระดานวางแผน และบันทึกงานกองถ่าย อยู่ในที่เดียวกัน และทั้งหมดเก็บเป็น **ไฟล์ Markdown + JSON ธรรมดา** ในโฟลเดอร์ที่คุณเป็นเจ้าของ ไม่มีฐานข้อมูล ไม่มีไฟล์รูปแบบเฉพาะ ไม่ผูกมัด: ถ้าพรุ่งนี้ K2 หายไป เรื่องของคุณยังเปิดอ่านได้ด้วยโปรแกรมแก้ไขข้อความตัวไหนก็ได้

- **การเขียนมาก่อน** สร้างบน [ProseMirror](https://prosemirror.net/) (เอนจินข้อความที่อยู่เบื้องหลังตัวแก้ไขสมัยใหม่จำนวนมาก) ให้ความลื่นระดับโปรแกรมประมวลผลคำ จัดหน้าตามกระดาษจริง รูปแบบบทภาพยนตร์มาตรฐาน และ Undo ที่ย้อนได้ทุกอย่าง
- **ไฟล์ของคุณ โฟลเดอร์ของคุณ** เล่ม → บท → ฉาก เป็นไฟล์ธรรมดา เปลี่ยนชื่อหรือย้ายจากระบบปฏิบัติการได้ แล้ว K2 ปรับโปรเจกต์ให้ตรงเมื่อคุณกลับมา
- **พกพาและยืนเดี่ยว** บน Windows เป็น `.exe` ไฟล์เดียว ไม่ต้องติดตั้ง ไม่ต้องมีบัญชี ไม่มีคลาวด์
- **ข้ามแพลตฟอร์ม** Windows, macOS และ Linux (ดู [ความต้องการของระบบ](#ความต้องการของระบบ))
- **หลายภาษา ไทยมาก่อน** ทั้งหน้าจอมี 7 ภาษา (ไทย อังกฤษ เยอรมัน ฝรั่งเศส ญี่ปุ่น โปรตุเกส จีน) และคีย์ลัดผูกกับ *ปุ่มกายภาพ* จึงใช้ได้กับทุกแป้นพิมพ์

| **หน้าจอ** | 1366 × 768 | 1920 × 1080 ขึ้นไป |
| **การ์ดจอ** | ไม่บังคับ | รองรับ WebGL (Story Network โหมด 3D และโมเดล 3 มิติ) |

- **ตัวที่แจก:** Windows x64 (portable `.exe` ~92 MB ไม่ต้องติดตั้ง) · macOS **Intel x64** และ **Apple Silicon arm64** (`.dmg` แยกกัน · ตัว Intel ~143 MB · ~330 MB เมื่อคัดลอกลง Applications) · Linux **x64** (`.AppImage`) ไม่มีรุ่น 32-bit
- **Linux:** ตัว AppImage ต้องมี `libfuse2` ในบางดิสโทร หรือรันจากซอร์สก็ได้ (ดู [การ build](#การ-build))
- ตัวพกพาแตกตัวเองลงโฟลเดอร์ชั่วคราวทุกครั้งที่เปิด (~380 MB) จึงควรเผื่อที่ว่างของไดรฟ์ที่เก็บ `%TEMP%`
- Windows 7 / 8 / 8.1 **ไม่รองรับ** (Electron 43 เลิกรองรับแล้ว)
- ใช้เน็ตเฉพาะการเรียก AI ตรวจอัปเดต และรายงานบั๊ก/คำขอฟีเจอร์ — การเขียนทำงานออฟไลน์ได้ทั้งหมด
- ตัวเลขข้างบนเป็นค่าประมาณจากการวัดหน่วยความจำจริงขณะเปิดโปรเจกต์ขนาดเล็ก — ราว 460 MB บน Windows และราว 400 MB บน macOS — ยังไม่ได้ทดสอบบนเครื่องสเปกต่ำหรือโปรเจกต์ขนาดใหญ่มาก

## ฟีเจอร์

### พื้นที่ทำงาน

- **ระบบแผงแบบผนึกได้** — ผนึก ชิดขอบ รวมกลุ่มแท็บ ลอย พับ หรือฉีกแผงออกเป็นหน้าต่างของตัวเอง บันทึกและสลับ **เวิร์กสเปซ** ได้
- **แยกจอ** — แก้สองอย่างเคียงกัน
- **Explorer** — ต้นไม้ เล่ม → บท → ฉาก ใช้คีย์บอร์ดได้ เปลี่ยนชื่อในแถว (F2) ดาว หมุด ล็อก สี และเมนูคลิกขวาครบ
- **แผง Navigation** — โครงของเอกสารที่เปิดอยู่ พร้อมค้นหา ตัวกรอง และเครื่องหมายสี/ดาว
- **มุมมองหน้ากระดาษ** — เห็นข้อความบนขนาดกระดาษและระยะขอบจริง ซูม พอดีความกว้าง โหมดโฟกัส และโหมดเครื่องพิมพ์ดีด
- **เปิดไฟล์ด่วน** สวิตช์บนแถบสถานะ ตัวนับคำ "เป้าหมายวันนี้" และ **แดชบอร์ด** สถิติการเขียน
- **ความรู้สึกแบบ native** — ปุ่มหน้าต่างของระบบ (รวม Snap Layouts ของ Windows) ลากไฟล์และโฟลเดอร์โปรเจกต์เข้าโปรแกรม เปิดโปรเจกต์จากบรรทัดคำสั่ง แถบความคืบหน้าบนแถบงาน เมนูระบบตามธีม
- **การช่วยการเข้าถึง** — ธีมคอนทราสต์สูงและธีมสำหรับตาบอดสี แสดงปุ่มที่กด แถบบรรทัดช่วยอ่าน ทางลัดแป้นพิมพ์บนจอ รองรับการลดการเคลื่อนไหว

### เครื่องมือเขียน

- **ตัวแก้ไขนิยาย** — หัวข้อ รายการ คำพูดยกมา สีตัวอักษร รูปกลางย่อหน้า การจัดหน้า การเยื้อง รูปแบบย่อหน้าและหน้ากระดาษที่ติดไปถึงไฟล์ที่ส่งออก
- **ตัวแก้ไขบทภาพยนตร์** — รูปแบบบทมาตรฐาน เลขฉาก CONTINUED/MORE หัวกระดาษ หน้าปก และ **ตัวตรวจบท** ที่ชี้ปัญหารูปแบบ
- **SmartType ตรวจคำผิด คำพ้อง** — เพิ่มพจนานุกรมของตัวเองได้
- **แผงบทพูด** — บทพูดทุกบรรทัดของโปรเจกต์ในที่เดียว: กรอง กระโดด แก้ในแถว
- **ห้องซ้อมบท** — ให้ AI สวมบทตัวละครในสารานุกรมทีละตา แล้วหยิบบรรทัดที่ชอบลงบท (ทางเลือก · ใช้คีย์ของคุณเอง)
- **คอมเมนต์และโน้ต** — คอมเมนต์แบบมีเธรด ผูกกับข้อความ
- **ผู้ช่วย AI (ทางเลือก · ใช้คีย์ของคุณเอง)** — แชทกับเรื่อง ขยาย/สรุป/เขียนใหม่ส่วนที่เลือก สร้างบทสนทนา ตรวจปมและความคงเส้นคงวาของตัวละคร และการ์ด "ตรวจบท" ห้าใบ (บทสนทนา จังหวะ ตรรกะ หลุดคาแรกเตอร์ โทน) รองรับ Agent และ system prompt ของผู้ใช้

### โครงเรื่องและไฟล์

- **เล่ม → บท → ฉาก** มีหลายร่างต่อเล่ม และ **ตัวจัดการเล่ม / ห้องสมุด** สำหรับเรียงลำดับและทำงานทีละหลายรายการ
- **คุณสมบัติฉาก** — สถานะ มุมมอง อารมณ์ ความขัดแย้ง เรื่องย่อ แท็ก เวลาในเรื่อง ธงย้อนอดีต/กระโดดไปอนาคต — เก็บใน frontmatter ของไฟล์ฉากแต่ละไฟล์
- **สถานะและสีของฉากตั้งเองได้**
- **รูปแบบโปรเจกต์เป็นไฟล์ธรรมดา** — `project.khn.json`, `section.json`, `draft.json`, `scenes.json` และไฟล์ฉากแบบ Markdown
- **ชื่อไฟล์ตรงกับชื่อเรื่อง** — เปลี่ยนชื่อเล่ม บท หรือฉากใน K2 แล้วไฟล์/โฟลเดอร์ตาม เปลี่ยนจากระบบปฏิบัติการ K2 ก็ตรวจเจอและปรับให้
- **ตรวจสุขภาพโปรเจกต์** — หาและซ่อมไฟล์ที่ไม่มีใครอ้าง รายการที่หาย และชื่อที่ไม่ตรงกัน

### คัมภีร์โลกและตัวละคร

- **สารานุกรม / Codex** — ตัวละคร สถานที่ สิ่งของ และหมวดที่ตั้งเอง พร้อมรูป ชื่ออื่น และช่องข้อมูลกำหนดเอง
- **ลิงก์อัตโนมัติ** — ชื่อที่ถูกเอ่ยในเนื้อเรื่องลิงก์กลับไปที่รายการ พร้อมลิงก์ย้อนกลับและมุมมอง "ฉากที่กล่าวถึง"
- **ความสัมพันธ์และ Story Network** — ผังโต้ตอบได้ (2D และ 3D) ของตัวละคร สถานที่ และฉาก พร้อมโฟกัส เส้นทางสั้นสุด และข้อสังเกตของเรื่อง
- **รายชื่อตัวละคร** ประจำเล่ม
- **ตัวสร้างโลก** — เทมเพลต AI (ทางเลือก) ที่สร้างรายการสารานุกรมให้

### วางแผนเรื่องและกระดานภาพ

- **Kanban** — ฉากตามสถานะ ลากเพื่อเปลี่ยนสถานะ ค้นหาและเรียงได้
- **เส้นเวลา** — กระดานแนวนอนของเวลาในเรื่อง: ลากและยืดการ์ด ลูกศร "นำไปสู่" ตรวจจับลิงก์ที่ย้อนเวลา
- **กระดานวางแผน** — ผืนอิสระของโน้ต การ์ด และเส้นเชื่อม
- **ผังแตกสาย** — ผังเรื่องแบบแตกสาย/โต้ตอบได้ พร้อมทางเลือก
- **แผนที่** — รูปของคุณเองพร้อมหมุด โซน เส้นทาง แผนที่ซ้อนชั้น มาตราส่วนจริงและเวลาเดินทาง ส่งออก GeoJSON
- **ผังพื้นที่** — ผังกองถ่าย/การวางตำแหน่งมุมบน พร้อมกล้อง เลนส์ ไฟ นักแสดงที่เคลื่อนตามจังหวะ และการสร้าง prompt ของช็อตด้วย AI
- **กระดานอารมณ์** — การ์ดของตัวละคร ฉาก ชุดสี และภาพอ้างอิง

### ของอ้างอิงและสื่อ

- **คลังรูป** พร้อมเมทาดาทา ผูกกับรายการสารานุกรม
- **Memo และไฟล์อ้างอิง** — เก็บโน้ตและเอกสารต้นทางไว้กับโปรเจกต์ ข้อความอ้างอิงป้อนเป็นบริบทให้ AI ได้
- **โมเดล 3 มิติและพาโนรามา** เป็นฉากหลังของ Story Network
- **เปรียบเทียบ "ฉากมีปัญหา"** — เก็บฉบับเดิมหน้ากองถ่ายของฉากไว้ แล้วเทียบกับฉบับที่แก้

### ส่งออก นำเข้า และพิมพ์

- **ศูนย์รวมการส่งออก** — ที่เดียวสำหรับส่งออกเป็น **PDF** (บทภาพยนตร์และนิยาย) **DOCX** **RTF** **HTML** **EPUB** **FDX** **Fountain** **TXT** และ **ZIP** พร้อมช่องตัวอย่างหน้าแบบสด
- **ของเสริมของ PDF** — หน้าปก หัว/ท้ายกระดาษ เลขหน้า สารบัญ ลายน้ำ (รวมสำเนาลายน้ำรายผู้รับ)
- **เวิร์กโฟลว์ส่งออก** — สายการประกอบไฟล์ที่บันทึกและใช้ซ้ำได้ ชื่อไฟล์ส่งออกตั้งเป็นแม่แบบได้
- **ส่งออกจากแผง** — เส้นเวลา แผนที่ กระดาน และผัง เป็น PNG/HTML/CSV/Markdown
- **นำเข้า** — Scrivener, Final Draft (FDX), Celtx, Adobe Story, Fade In และ Fountain
- **พิมพ์** เอกสารได้ตรงจากตัวแก้ไข

### ประวัติ สำรอง และกู้คืน

- **ประวัติเวอร์ชัน** รายไฟล์ — ดูตัวอย่าง กู้คืน และเปรียบเทียบได้
- **เปรียบเทียบบท** — ผลต่างแบบแยกสีระหว่างบทสองฉบับ
- **ถังขยะ** — ฉาก บท เล่ม และรายการที่ลบแล้วกู้คืนได้
- **สำรองข้อมูล** และ **ทะเบียนงานที่ยังไม่บันทึก** — K2 แสดงทุกอย่างที่จะหายก่อนคุณปิดหรือสลับโปรเจกต์
- **กันเขียนทับ** — ไฟล์ที่ถูกแก้นอก K2 ถูกตรวจเจอก่อนจะถูกเขียนทับ

> เครื่องมือเวอร์ชันของ K2 อยู่ในตัวและทำงานกับไฟล์ จะวางโฟลเดอร์โปรเจกต์ไว้ใต้ Git ด้วยก็ได้

### ค้นหาและแทนที่

- **ค้นหาและแทนที่ในเอกสาร**
- **ค้นหาเต็มข้อความทั้งโปรเจกต์** — ผลเรียงตามความเกี่ยวข้อง พร้อมข้อความตัวอย่างที่ไฮไลต์และกระโดดไปจุดที่เจอ ไม่รวมถังขยะ ประวัติ และสำเนาสำรอง
- **แทนที่ทั้งโปรเจกต์**
- **ตัวกรองฉาก** — ค้นตามสถานะ แท็ก มุมมอง และอื่น ๆ พร้อมชิปตัวกรองใน Explorer

### ปรับให้เป็นของคุณ

- **ธีม** — ธีมสีหลายสิบชุด (มืด สว่าง ปลอดภัยสำหรับตาบอดสี คอนทราสต์สูง ขาวดำ และอื่น ๆ) เปลี่ยนเปลือกโปรแกรมโดยไม่แตะสีของหน้ากระดาษหรือไฟล์ที่ส่งออก
- **คีย์ลัดตั้งใหม่ได้** — ทุกคำสั่งผูกปุ่มใหม่ได้ คีย์ลัดตามปุ่มกายภาพ
- **เลย์เอาต์** — เลย์เอาต์ของแผง เวิร์กสเปซ และแถบเครื่องมือที่ปรับได้
- **รูปแบบ** — ขนาดกระดาษ ชุดระยะขอบ ฟอนต์ และรูปแบบบทภาพยนตร์ราย element (ระยะเยื้อง ความกว้าง ระยะเว้น)
- **ภาษา** — ภาษาของหน้าจอ 7 ภาษาในไฟล์ CSV ที่แก้ได้ พร้อมคำแปลเฉพาะโปรเจกต์
- **ขอบเขตของการตั้งค่า** — บอกชัดว่าค่าไหนเป็นของผู้ใช้ ค่าไหนเป็นของโปรเจกต์

### ปลั๊กอินและการต่อขยาย

- **ปลั๊กอิน** — โฟลเดอร์ที่มี `plugin.json` กับไฟล์ JavaScript หนึ่งไฟล์ API `k2` ให้ปลั๊กอินลงทะเบียนคำสั่ง คีย์ลัด แผง และฟังเหตุการณ์ของโปรแกรม **โหลดใหม่ได้ทันที** และปลั๊กอินที่มากับโปรเจกต์ต้องได้รับอนุญาตจากคุณก่อนจึงจะรัน
- **พจนานุกรมของตัวเอง** สำหรับตรวจคำผิดและคำพ้อง
- **ไฟล์ภาษาและเวิร์กโฟลว์ส่งออก** เป็นไฟล์ข้อมูลธรรมดา แก้และแบ่งปันได้
- เริ่มที่ **[คู่มือส่วนขยาย](docs/extension/th/README.md)**

## การ build

Killian 2 เป็นโปรแกรม **[Electron](https://www.electronjs.org/)** (Electron 43 + ProseMirror) ฝั่ง renderer รวมไฟล์ด้วย esbuild ไม่มีขั้น build ของเฟรมเวิร์กแยกต่างหาก

```bash
# 1. เอาซอร์สมาแล้วติดตั้ง dependency
git clone https://github.com/Nbcybg/Killian-Editor-V2.git
cd Killian-Editor-V2
npm install

# 2. รวม src/*.js เป็น renderer/bundle.js (รันหลังแก้ซอร์สทุกครั้ง)
npm run build

# 3. รันแบบพัฒนา
npm start     # เหมือนกันทั้ง Windows, macOS และ Linux
```

แพ็กเป็นตัวแจก:

```bash
npm run dist        # Windows x64 portable .exe  → dist/
npm run dist:mac    # macOS .dmg — Intel x64 + Apple Silicon arm64 (ต้องรันบน Mac) → dist/
npm run dist:linux  # Linux x64 AppImage        → dist/
npm run dist:dir    # ตัว Windows แบบไม่แพ็ก สำหรับลองเร็ว ๆ ในเครื่อง
```

ทดสอบ:

```bash
npm run test:unit   # unit test (โมดูลตรรกะล้วน)
```

ยังมีชุดทดสอบ end-to-end ที่รันในตัวโปรแกรมเอง (`KILLIAN_TEST=1`) ดูคำสั่งและกติกาของโปรเจกต์ใน [AGENTS.md](AGENTS.md) ก่อนร่วมพัฒนา
